# 科目笔记模板

本目录提供各科重点笔记模板，不属于教材目录，不计入教材数量和网页清单。

## 使用规则

1. 复制对应科目模板，改成教材名称和年级。
2. 目录必须使用：`## 二、目录与章节重点` → `### 单元/章/模块` → `#### 课/节/课程`。
3. 每个 `####` 下面必须写确定知识，不能只写“本节重点”或“请完成练习”。
4. 每本笔记都要保留：`必备知识点`、`必备公式/定理`、`必备单词/术语`、`背诵内容`、`易错点`。
5. 无公式或无英语单词的科目，要明确写“本册无独立公式/无传统英语单词”，并改列本学科规则或术语。
6. **独立可学是重中之重**：单独打开一份笔记，读者必须能够说清对应教材教了哪些单元、每课教了什么知识、需要掌握哪些结论/方法/字词和背诵内容；不能用目录、提问句、学习任务或“本节核心包括……”等套话代替具体知识。
7. 生成完成后检查全文：删除无人作答的提问式任务、未完成句、模板占位符、重复套话和无法指向本教材的泛化内容；每个章节都要形成“内容—知识—证据/例子—易错边界”的完整语义。英语问句和附完整解答的例题属于有效知识，不机械删除。
8. 学科模板中的“使用原则”和编写验收只约束生成过程，不复制到成品。新笔记从“本册学习地图”开始，按真实目录展开，附完整示例和实际资料依据。
9. 数学、英语、道德与法治、思想政治、科学、历史、地理、物理、化学、生物学模板均采用“脱离教材独立学习”的标准，并分别约束本学科的公式、词汇、实验、史实、区域或案例内容。篇幅以知识完整为准。
10. 学期及高中阶段汇总必须在单本笔记完成后重建，直接汇总对应册次的具体知识、公式、术语和易错结论。基础阶段仅纳入必修，方向阶段仅纳入选择性必修，综合阶段再关联两者；不沿用旧汇总中的通用学科口号。
