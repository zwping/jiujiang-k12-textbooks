# 五年级下册语文重点笔记

> 对应教材：义务教育教科书·语文五年级下册
> 版本：人教统编版　|　学段：小学五年级下学期

## 一、本册学习地图

### 本册到底教什么

- **教材主线**：本册围绕童年、古典名著、汉字、家国英雄、人物描写、思维策略、世界文化和幽默表达，训练把一件事写具体、从细节分析人物、理解古典语言和根据图表提取信息。
- **八个单元**：童年往事；古典名著；遨游汉字王国；家国情怀；人物描写；思维与策略；异域风情和文化遗产；幽默、讽刺与启示。
- **表达任务**：那一刻我长大了、课本剧、读后感、人物描写、探险之旅、文化遗产、漫画启示和口语讲笑话。

| 单元 | 主要内容 | 本单元教会的知识 | 学完后的明确能力 |
|---|---|---|---|
| 第一单元 | 童年诗文和回忆 | 从细节体会童年感情 | 能把一件成长经历写具体 |
| 第二单元 | 四大名著片段 | 梳理人物、冲突、动作和语言 | 能写读后感并演课本剧 |
| 第三单元 | 汉字综合性学习 | 了解汉字音形义、演变和书法 | 能搜集资料并形成研究结论 |
| 第四单元 | 古诗、英雄和军人 | 通过行动表现忠诚、坚强、清贫 | 能写清人物的典型事例 |
| 第五单元 | 刷子李和人物片段 | 用外貌、动作、语言写人物 | 能写出有特点的人 |
| 第六单元 | 寓言、田忌赛马、跳水 | 从条件和策略分析结果 | 能写清解决问题的过程 |
| 第七单元 | 威尼斯、牧场、金字塔 | 观察顺序和资料说明 | 能介绍世界文化遗产 |
| 第八单元 | 文言文、手指、发现 | 用幽默和对比表达启示 | 能从漫画或生活现象写观点 |

## 二、目录与章节重点

- **第一单元：童年与成长**

  - **1 古诗三首**

    - **四时田园杂兴（其三十一）**：写农村男女白天耕作、夜晚纺织，儿童也学种瓜，表现乡村劳动生活。
    - **稚子弄冰**：写儿童早晨取冰、穿丝、敲冰，冰碎后“当、当”声消失，表现天真和快乐。
    - **村晚**：写池塘、落日、山衔落日和牧童横牛背，动静相间，画面闲适。
    - 三首均按全诗收录；教材练习明确要求背诵，且默写《四时田园杂兴（其三十一）》。“耘田、供、稚子、磬、陂”等字词见诗句注释。

  - **2 祖父的园子**

    - **本课教了什么**：萧红回忆祖父的园子，写花鸟虫草、劳动和玩耍，表现自由、快乐和祖孙情深。
    - **表达方法**：反复“愿意……就……”表现自由；景物与童年事件交织，园子成为精神乐园。

  - **3 月是故乡明**

    - 以故乡的月色、水边生活和童年趣事为记忆线索，再写离乡后看到的月亮，表达对故乡的眷恋。

  - **4 梅花魂**

    - 通过墨梅图、梅花手绢和临别落泪写外祖父珍爱梅花的原因；梅花象征不屈品格，也寄托思乡与爱国之情。

  - **口语交际与习作**

    - 走进他人的童年岁月要会提问和倾听；“那一刻我长大了”要写事件前后自己的认识或责任变化。

- **第二单元：古典名著**

  - **5 草船借箭**

    - **本课教了什么**：周瑜设难题要求诸葛亮造箭，诸葛亮利用大雾和曹军多疑借得十万支箭，表现足智多谋。
    - **结构与证据**：提出任务—准备草船—江上受箭—交箭验收；“大雾、擂鼓呐喊、曹操不出兵”构成行动依据。

  - **6 景阳冈**

    - **本课教了什么**：武松饮酒、上冈、遇虎、打虎，连续动作展现勇敢和力量，也写出人物的警惕与自信。
    - **表达方法**：动作描写密集，动词推动节奏；环境和酒量铺垫打虎冲突。

  - **7 猴王出世**

    - 石猴从石头中诞生，凭勇气发现水帘洞并被拥立为王；动作、语言和众猴反应共同塑造其勇敢、机敏的形象。

  - **8 红楼春趣**

    - 宝玉与姐妹们在大观园放风筝；人物语言和放风筝的细节呈现各自性格与春日游玩的热闹。

  - **读后感与快乐读书吧**

    - 读后感结构：概括内容 → 选择感受最深的部分 → 联系生活/阅读 → 得出启示；不能只复述故事。

- **第三单元：遨游汉字王国**

  - **汉字真有趣**：通过字谜、歇后语、谐音和故事认识汉字音形义的联系与趣味。
  - **我爱你，汉字**：汉字专题研究可聚焦文字演变、书法字体或规范使用；结论应由分类整理的资料和明确来源支持。
  - **研究报告**：问题、方法、资料、结论和引用来源要对应，不能把猜想写成结论。

- **第四单元：家国与人物精神**

  - **9 古诗三首**：《从军行》写边塞将士以身许国；《秋夜将晓出篱门迎凉有感》写中原遗民盼望收复失地；《闻官军收河南河北》写听到胜利消息后的狂喜与归乡计划。
  - **10 青山处处埋忠骨**：毛泽东面对爱子牺牲，在个人亲情与国家责任之间作出艰难决定；人物动作、语言和沉默呈现内心冲突。
  - **11 军神**：刘伯承拒绝使用麻醉剂完成手术；沃克医生的态度变化从侧面突出刘伯承的坚强意志。
  - **12 清贫**：方志敏面对搜身和威逼仍坚持清白；“清贫”不是没有信念，而是物质简朴、精神坚定。
  - **习作：他____了**：抓住人物情绪变化，选取动作、语言、神态和环境细节表现转变过程。

- **第五单元：人物描写**

  - **13 人物描写一组**：《摔跤》用连续动作呈现小嘎子和胖墩儿的较量；《他像一棵挺脱的树》以外貌细节写祥子的健壮；《两茎灯草》以严监生临终仍惦记灯草的细节刻画吝啬。
  - **14 刷子李**：先写刷墙规矩和技艺传闻，再写曹小三观察白点、产生怀疑并发现真相；观察者心理推动情节，结尾白点揭开悬念。
  - **习作：形形色色的人**：选取最能代表人物特点的事件，细节要服务于同一人物特征。

- **第六单元：思维与行动**

  - **15 自相矛盾**：楚人同时夸盾坚不可破、矛无物不陷，回答“以子之矛陷子之盾”时暴露逻辑冲突；判断语言要看条件能否同时成立。
  - **16 田忌赛马**：孙膑根据马匹等级调整出场顺序，以己方下等马对对方上等马，再用上等、中等马取胜；策略依赖相对次序，不是马匹绝对能力变化。
  - **17 跳水**：孩子因猴子挑逗走上桅杆，船长迅速判断危险、命令跳水；事件链和水手、风浪、甲板等环境共同构成危急情境。
  - **习作：神奇的探险之旅**：设定环境、人物装备和危险，安排连续困难及解决办法，情节变化要有因果。

- **第七单元：异域风光**

  - **18 威尼斯的小艇**：介绍小艇形状、船夫驾驶技术及小艇与居民生活的联系；小艇停泊后城市转静，结构形成首尾呼应。
  - **19 牧场之国**：从牛、马、羊和夜晚描写荷兰牧场；拟人和反复营造安静、悠闲的氛围，景物描写服务“牧场之国”的印象。
  - **20 金字塔**：阅读《金字塔夕照》和《不可思议的金字塔》，前者以景物描写呈现色彩与壮美，后者用图表、数据和说明介绍位置、结构及建造信息；两种文本不能混为同一种表达方式。
  - **口语交际：我是小小讲解员**：按参观路线和听众需要筛选资料，讲解时说明地点、特点和依据。

- **第八单元：语言与童年**

  - **21 杨氏之子**：孔君平以“杨梅”调侃杨氏子，孩子以“孔雀”对应作答；机智来自抓住“杨”与“孔”的姓氏类比，且回应有礼。
  - **22 手指**：大拇指、食指、中指、无名指和小指各有形态与功能；结尾从各有所长归纳出团结合作的价值。
  - **23 童年的发现**：费奥多罗夫从梦境、观察和想象形成关于胚胎发育的猜想；课文还写他因发现被老师误解后的窘境，幽默来自成人与儿童理解角度的差异。
  - **口语交际：我们都来讲笑话**：讲述重点在铺垫、停顿和包袱，不能提前解释笑点。
  - **习作：漫画的启示**：先准确描述画面，再说明由画面引出的现象和启示；观点必须能由画面细节支持。

## 三、知识要点

- **古典名著阅读**：人物身份、目标、冲突、策略、结果；评价人物要有具体行动。
- **人物描写**：外貌写形象，动作写过程，语言写性格，神态/心理写内心变化，环境写背景或烘托。
- **研究性学习**：问题要明确，资料要可靠，分类要有标准，结论要由资料支持。
- **策略阅读**：比较条件、顺序和资源；改变顺序常会改变结果。
- **读后感**：内容概括只能服务于观点，中心必须是自己的感受和理由。

## 四、阅读与表达方法

- **人物分析规则**：描写细节 + 行为选择 + 结果影响 = 人物品质。
- **策略分析规则**：双方条件 + 资源排序 + 出场/行动顺序 + 结果。
- **研究报告规则**：研究问题 + 资料来源 + 分类整理 + 结论 + 局限。
- **读后感规则**：内容概括 + 感受观点 + 文本证据 + 生活联系。

### 默写标准

- 古诗词、文言文：写对篇名、作者或出处、原文、标点和易错字；文言句要能解释关键词。
- 现代文：严格按教材指定自然段背诵，能够复述段落内容、句间关系和关键表达作用。
- 每篇完成“背诵—遮挡默写—逐字核对—订正再写”四步；不会写的字单独列入错字表。


## 七、易错点与掌握边界
- 《草船借箭》重点是诸葛亮利用天气、敌我心理和水上条件完成任务，不是简单的“借”字游戏。
- 读后感不能把课文复述当作感受；必须有“我认为……因为……”的观点和证据。
- 研究报告中的资料来源和结论不能混写，不能把网络传闻当作已证实事实。
- 《田忌赛马》不是任何比赛都能以弱胜强，策略建立在具体实力排序和出场规则上。
- 童话、寓言和文言故事的文学想象，不能改写成无证据的历史或科学事实。
