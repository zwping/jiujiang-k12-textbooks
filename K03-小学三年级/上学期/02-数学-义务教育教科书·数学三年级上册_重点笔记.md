## 二、目录与章节重点

### 数学好玩

#### 1. 搭配中的学问

有序列举，做到不重复、不遗漏。可以先固定一种选择，再逐一搭配另一种选择；也可以画树状图或列表。

#### 2. 时间与数学

把作息时间记录下来，比较不同活动的开始、结束和经过时间。解决实际问题时，既要计算正确，也要判断安排是否合理。

#### 第八单元：认识小数

#### 1. 小数的读写

小数点左边是整数部分，右边是小数部分。读小数时，小数点读作“点”，小数部分的数字依次读出；写小数时，小数点写在整数部分和小数部分之间。

例如：`3.45`读作“三点四五”，不能读成“三点四十五”。

#### 2. 生活中的小数

- `1元=10角=100分`，`1角=0.1元`，`1分=0.01元`。
- `1米=10分米=100厘米`，`1分米=0.1米`，`1厘米=0.01米`。
- 小数的整数部分相同，比较小数部分；比较时可以先比较十分位，再比较百分位。

#### 3. 小数大小比较

先比较整数部分，整数部分大的数大；整数部分相同，再比较小数部分，从十分位开始逐位比较。末尾添0或去掉0，小数大小不变，如 `0.5=0.50`。

#### 4. 小数加减

小数点对齐，也就是相同数位对齐；从末位算起；结果的小数点要和原式小数点对齐。必要时在末尾补0帮助计算。

```text
  3.60
- 1.25
------
  2.35
```

## 十一、常用数量关系与单位

| 类型 | 数量关系 |
|---|---|
| 总数 | 部分 + 部分 |
| 剩余 | 总数 - 用去的 |
| 相差 | 较大数 - 较小数 |
| 总价 | 单价 × 数量 |
| 路程 | 速度 × 时间 |
| 周长 | 封闭图形一周的长度 |
| 经过时间 | 结束时刻 - 开始时刻 |

常见长度单位：千米、米、分米、厘米、毫米。常见质量单位：吨、千克、克。常见时间单位：年、月、日、时、分、秒。解题前先判断数量和单位是否匹配。

## 十三、应用题通用解法

1. 圈出已知条件，画出问题关系。
2. 判断求的是总数、剩余、相差、每份数还是份数。
3. 先列分步算式，再列综合算式。
4. 写清单位和答语。
5. 用估算、逆运算或代回题意检查。

## 必备公式/定理

> 公式、定理或规则必须结合适用条件使用；没有独立计算公式的学科已明确标注。

- 求总数：部分 + 部分 = 总数。
- 求剩余：总数 - 用去的 = 剩余。
- 长方形周长：C=(长+宽)×2。

- 已知周长求正方形边长：边长=周长÷4。
- 1元=10角=100分，1角=0.1元，1分=0.01元。
