# 六年级上册语文重点笔记

> 对应教材：义务教育教科书·语文六年级上册
> 版本：人教统编版　|　学段：小学六年级上学期

## 一、本册学习地图

### 本册到底教什么

- **教材主线**：本册训练在自然、革命、文学、小说、人物和艺术中提炼主题，重点学习阅读时有目的地阅读、找中心意思、体会场面和人物、读小说和写倡议书。
- **八个单元**：草原与多彩自然；革命岁月；阅读策略；小说；围绕中心意思写；科学与生命；艺术魅力；走近鲁迅。
- **表达任务**：变形记、演讲、笔友、倡议书、围绕中心意思写、我的拿手好戏、有你真好和有创意地表达。

| 单元 | 主要内容 | 本单元教会的知识 | 学完后的明确能力 |
|---|---|---|---|
| 第一单元 | 草原、丁香结、古诗词、花之歌 | 想象画面，体会物我相融 | 能写自然景物和个人感受 |
| 第二单元 | 七律、战争、演讲、灯光 | 场面描写与革命精神 | 能按场面写事件和感受 |
| 第三单元 | 宇宙、故宫、阅读策略 | 有目的地阅读，提取关键信息 | 能根据任务快速筛选内容 |
| 第四单元 | 小说、桥、穷人、在柏林 | 关注环境、人物、情节和主题 | 能分析小说人物和冲突 |
| 第五单元 | 夏天里的成长 | 围绕中心意思组织材料 | 能用不同事例证明中心 |
| 第六单元 | 浪淘沙、地球、青山、三黑 | 借物写环保和劳动 | 能写倡议书并说明理由 |
| 第七单元 | 月光曲、京剧、书法绘画 | 通过联想和细节体会艺术 | 能写自己的拿手好戏 |
| 第八单元 | 鲁迅作品 | 通过人物、场景和语言理解形象 | 能写人与人之间的真情 |

## 二、目录与章节重点

- **第一单元：自然与感受**

  - **1 草原**

    - **本课教了什么**：写草原天空、地面、羊群、蒙古包和蒙古族同胞，按初见草原—欢迎远客—联欢话别写景与人情。
    - **知识与结论**：景物描写与人物活动共同表现“蒙汉情深”；“一碧千里、翠色欲流”等词写色彩和空间。

  - **2 丁香结**

    - **本课教了什么**：写城里、校园和斗室的丁香花，联想到人生中的结，说明生活既有芬芳也有不顺，结也能孕育诗意。
    - **表达方法**：由花及人、由景入理；比喻“丁香结”把生活困难具体化。

  - **3 古诗词三首**

    - **宿建德江**写暮夜泊舟和羁旅愁绪；**六月二十七日望湖楼醉书**写骤雨来去和西湖变化；**西江月·夜行黄沙道中**写乡村夜景、蛙声和丰收预兆。
    - 三首均按全诗收录；教材练习明确要求背诵三首并默写《西江月·夜行黄沙道中》。

  - **4 花之歌**

    - 以花自述，把花写成自然的使者和生命的象征；“从苍穹坠落、又起草原”表现循环、奉献和生命之美。

- **第二单元：革命历史与场面描写**

  - **5 七律·长征**：五岭、乌蒙、金沙、大渡和岷山组成长征路线意象；“细浪、泥丸”把艰险化小，表达红军乐观豪迈。
  - **6 狼牙山五壮士**：按接受任务、诱敌上山、引上绝路、顶峰歼敌、英勇跳崖推进；动作与选择构成英雄形象的证据。
  - **7 开国大典**：写会场布置、典礼、阅兵和群众游行；场面描写兼有整体气氛与人物局部行动。
  - **8 灯光**：郝副营长在战斗间隙看孩子读书的灯光图，随后为后续部队照明而牺牲；灯光连接理想、回忆和现实。
  - **习作：多彩的活动**：先确定活动中心场面，再选代表性人物和动作细写，其他过程作必要交代。

- **第三单元：阅读策略与民间玩具**

  - **9 竹节人**：制作、玩耍、观战和老师没收后也入迷构成童年故事；说明性步骤与人物趣事交错，读时可按任务定位制作方法或情节。
  - **10 宇宙生命之谜**：由“宇宙中是否有生命”逐步筛选星球条件与探测信息；阅读时先明确问题，再按证据排除不合条件的对象。
  - **11 故宫博物院**：四则材料分别提供参观路线、建筑介绍、历史信息和开放安排；根据任务选择材料，不必把所有材料按同一顺序通读。
  - **习作：____让生活更美好**：确定主题词，围绕它写不同经历及其影响，说明观点与事例的联系。

- **第四单元：小说中的人物与抉择**

  - **12 桥**：洪水来临时老支书组织村民依次过桥，最后把生的机会留给群众和儿子；短句、环境描写和结尾身份揭示形成强烈冲击。
  - **13 穷人**：桑娜擅自抱回邻居孩子，渔夫得知后主动承担；屋内环境、桑娜的心理和夫妻对话呈现贫困中的善良与责任。
  - **14 在柏林**：车厢里老兵、老妇人和孩子的对话逐步揭示家庭创伤；结尾把个人遭遇指向战争对普通人的伤害。
  - **习作：笔尖流出的故事**：先确定人物处境和冲突，再安排行动、转折与结尾；细节须服务人物变化。

- **第五单元：围绕中心选材料**

  - **15 夏天里的成长**：以“夏天是万物迅速生长的季节”为中心，按生物、山河、道路、孩子等方面举例；材料共同支撑中心句。
  - **16 盼**：围绕“盼穿新雨衣”写得到雨衣、盼下雨、盼出门等连续心理与行动；反复愿望推动情节，细节呈现儿童心理。
  - **习作：围绕中心意思写**：先写明中心，再选不同方面的材料；重点材料展开，旁支材料略写，全文不能偏离中心。

- **第六单元：人与土地**

  - **17 古诗三首**：《浪淘沙（其一）》写黄河奔腾入海并联想到银河；《江南春》以春景和烟雨楼台构成画面；《书湖阴先生壁》借庭院与山水写居者品格。
  - **18 只有一个地球**：说明地球适于人类生存、资源有限且目前难以移居，结论是珍惜资源、保护地球；“唯一”由文中条件推导。
  - **19 青山不老**：老人带领乡亲植树造林，改变晋西北恶劣环境；“青山不老”既指生态成果，也指生命价值延续。
  - **20 三黑和土地**：三黑得到土地后翻地、播种并憧憬未来；土地意象连接农民的现实生活与希望。
  - **口语交际、习作**：即兴发言先提出观点，再给理由和例子；材料围绕中心意思组织。

- **第七单元：艺术与知音**

  - **21 文言文二则**：《伯牙鼓琴》写伯牙以琴声表达志趣、钟子期能听出“高山”“流水”，子期死后伯牙破琴绝弦；《书戴嵩画牛》写牧童指出画中斗牛尾巴错误，说明观察和常识能检验作品。
  - **22 月光曲**：贝多芬为盲姑娘弹琴后即兴创作；皮鞋匠听琴时看到的月夜画面属于音乐引发的联想，需与现实场景区分。
  - **23 京剧趣谈**：《马鞭》解释虚拟道具如何替代真实物件，《亮相》说明静态亮相、动态亮相的舞台表现作用。
  - **口语交际、习作**：讲故事注意顺序、节奏和听众；拿手好戏习作详写准备、展示或意外中的关键细节。

- **第八单元：鲁迅作品与人物**

  - **24 少年闰土**：看瓜刺猹、雪地捕鸟、海边拾贝等片段写闰土的见识与行动；“我”与闰土的对照显出童年经验差异。
  - **25 好的故事**：现实昏暗与梦中明净、生动的水乡画面形成对照，梦境寄托对美好生活的向往。
  - **26 我的伯父鲁迅先生**：谈《水浒传》、谈碰壁、救助车夫、关心女佣等事件，共同证明鲁迅关心他人、敢于批评旧社会。
  - **27 有的人——纪念鲁迅有感**：以两类人“活着/死了”的对照评价人生价值，反复句加强褒贬；理解诗句需联系具体行为。
  - **习作：有你，真好**：写清对方做过的一件事、当时情境及其对自己的影响，用事实呈现“好”。

## 三、知识要点

- **中心意思**：先提炼中心，再选择不同方面、不同事例共同证明；中心句不等于全文所有句子。
- **小说阅读**：环境渲染氛围，情节制造冲突，人物行动体现性格，结尾揭示主题。
- **有目的阅读**：明确任务 → 圈画关键词 → 跳读相关段 → 整理信息 → 回答任务。
- **场面描写**：整体氛围 + 代表性人物/局部动作 + 关键声音或画面 + 主题感受。
- **联想与想象**：实景触发联想，联想要有感官、情感和上下文依据。

## 四、阅读与表达方法

- **中心作文规则**：中心意思 + 不同方面材料 + 详略安排 + 首尾照应。
- **小说分析规则**：环境 + 情节冲突 + 人物选择 + 结局意义。
- **目的阅读规则**：任务关键词 + 文本定位 + 信息筛选 + 结构化回答。
- **场面描写规则**：总体氛围 + 典型细节 + 动静声音 + 主题效果。

### 默写标准

- 古诗词、文言文：写对篇名、作者或出处、原文、标点和易错字；文言句要能解释关键词。
- 现代文：严格按教材指定自然段背诵，能够复述段落内容、句间关系和关键表达作用。
- 每篇完成“背诵—遮挡默写—逐字核对—订正再写”四步；不会写的字单独列入错字表。


## 七、易错点与掌握边界
- “有目的阅读”不是只读标题，必须根据任务找到相关段落和证据。
- 小说的结尾揭示主题，但主题不能脱离人物行动和情节发展。
- “中心意思”不是一句空泛口号，材料必须共同支撑中心。
- 《只有一个地球》中的数据和结论要按文章范围理解，不能扩展成所有环境问题的完整答案。
- 《月光曲》的海面和月光既有现实描写，也有盲姑娘听琴后的联想，阅读时要区分两层。
