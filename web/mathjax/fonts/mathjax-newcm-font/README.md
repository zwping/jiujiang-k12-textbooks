# MathJax New Computer Modern web fonts

- Source package: `@mathjax/mathjax-newcm-font` version `4.1.3`
- Upstream: <https://www.npmjs.com/package/@mathjax/mathjax-newcm-font>
- Included assets: CommonHTML `chtml/dynamic` and `chtml/woff2`, used by the local MathJax 4 renderer.
- License: Apache-2.0; see [`../../LICENSE`](../../LICENSE).

These local assets keep extended mathematical glyphs available when the reader is served locally without an internet connection.
