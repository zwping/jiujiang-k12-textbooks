# 八年级上册语文重点笔记

> 对应教材：义务教育教科书《语文》八年级上册（人教统编版）
> 编排依据：篇目、单元按仓库现有教材目录核对；正文知识及明确的背诵要求据仓库现有教材文本整理。

## 一、本册学习地图

本册从新闻事实和现场报道出发，继而学习人物传记、山水诗文、回忆性散文、说明文和古典议论/叙事。核心进阶是：阅读时区分事实与评价，概括信息时不丢掉限定条件，说明事物时用结构和证据支撑结论，写作时让材料与中心对应。

- **阅读能力**：提取新闻六要素；辨析传记材料与作者评价；结合景物顺序和关键词理解情感；辨认说明对象、特征、顺序与方法；解释文言实词、句式和论证关系。
- **表达能力**：采访、写消息和传记；写出人物特点；说明熟悉的事物；表达观点并用证据证明。
- **六单元主线**：新闻 → 人物与传记 → 山川景物和唐诗 → 父爱与生命 → 说明文 → 古典论说、史传与诗歌。

## 二、目录与章节重点

- **第一单元：新闻与现场**
  - **活动·探究**：新闻阅读 → 新闻采访 → 新闻写作，最终产出新闻作品。
  - **1《消息二则》**：《我三十万大军胜利南渡长江》用短消息概括渡江战果；《人民解放军百万大军横渡长江》按中路、西路、东路展开，导语先交代总体战况，主体补足各路进展。
  - **2《首届诺贝尔奖颁发》**：消息用导语呈现获奖事实，主体交代奖项、获奖者和诺贝尔生平；新闻信息须核对时间、地点、人物、事件和来源。
  - **3*《“飞天”凌空》**：特写聚焦吕伟跳水夺冠的短暂过程，以动作分解、比喻和侧面反应放大瞬间，表现动作准确和现场氛围。
  - **4《一着惊海天》**：通讯按航母舰载机着舰过程呈现准备、关键动作与成功后的现场反应；动作细节和环境描写服务于紧张感与科技主题。
  - **5《国行公祭，为佑世界和平》**：新闻评论围绕公祭与历史记忆提出立场，以事实反驳否认史实的言论，论证目标是铭记历史、维护和平。
  - **写作与口语活动**：采访问题围绕主题、对象和可核实事实设计；消息导语先写最重要信息，主体按逻辑补充；讲述应面向听众、层次清楚。
- **第二单元：人物与传记**
  - **6《藤野先生》**：鲁迅回忆仙台求学期间藤野先生改讲义、订解剖图等事件；匿名信和看电影经历写出作者弃医从文的思想转折，人物形象由具体行为建立。
  - **7《回忆我的母亲》**：朱德以时间和生活阶段组织材料，写母亲勤劳、坚忍、善良及对子女的影响；平实叙述中穿插评价，母亲的品格由家务劳动和家庭选择体现。
  - **8*《列夫·托尔斯泰》**：先写外貌的粗犷甚至不合常规，再突出眼睛的洞察力；欲扬先抑形成外表与精神世界的反差。
  - **9*《美丽的颜色》**：通过居里夫妇在简陋环境中提炼镭的过程呈现科学工作的艰苦；“美丽”既指镭的光彩，也关联发现过程中的热情与坚毅。
  - **写作《学写传记》**：核实生平资料，按时间线选典型事件；事实与评价分开，评价由事例支撑，避免编造心理和对话。
- **第三单元：山水、诗文与观察**
  - **10《三峡》**：先写两岸连山和遮天蔽日，再按夏、春冬、秋写水势与景色；季节转换带来水态和氛围变化，需结合“襄陵”“素湍绿潭”“猿鸣”等词句读景。
  - **11《短文二篇》**：《答谢中书书》从山川总貌写到晨昏变化，以动静结合表现清丽；《记承天寺夜游》以月光、竹柏影和“闲人”呈现贬谪中的旷达与孤清。
  - **12《与朱元思书》**：由富春江奇山异水写到水清、流急、山高、树密；骈句节奏和视线移动共同表现山水之美，末段由景转向厌弃尘俗、向往自然。
  - **13《唐诗五首》**：《野望》写秋野与隐逸心境；《黄鹤楼》以登楼见闻引出乡愁；《使至塞上》用“征蓬”“归雁”自况并以“大漠孤烟直，长河落日圆”绘边塞；《渡荆门送别》写出蜀入楚的视野变化；《钱塘湖春行》按早春湖岸景物呈现生机。
  - **写景阅读法**：先标出观察位置和顺序，再看色彩、声音、动静和视线变化如何形成画面；景物作用要结合上下文情感。
- **第四单元：回忆、生命与写人**
  - **14《背影》**：父亲送别、照料和买橘子的行动集中表现父爱；“背影”反复出现，承接作者从不理解到怀念的情感变化。
  - **15《白杨礼赞》**：由白杨树的外形、挺立姿态和生长环境写到象征意义；排比、反问和先抑后扬强化对白杨及其所象征精神的赞颂。
  - **16《散文二篇》**：《永久的生命》从生命个体的有限写生命整体的延续；《我为什么而活着》分述三种追求及其带来的痛苦与幸福，结构清楚、判断有个人经验支撑。
  - **17*《昆明的雨》**：以雨季为线索串联菌子、杨梅、缅桂花和人物交往；生活片段共同构成地方记忆，闲笔和细节形成温润的抒情语调。
  - **写作《语言要连贯》**：确定叙述对象和时间/空间线索，安排指代、连接词与句序；连贯不仅是加“于是”，还要确保信息前后承接。
- **第五单元：说明对象与说明方法**
  - **18《中国石拱桥》**：以赵州桥、卢沟桥为例说明石拱桥形式优美、结构坚固、历史悠久；数据、比较和举例各自说明不同特征，说明需保留准确限定。
  - **19《苏州园林》**：总说园林追求图画美，再从亭台轩榭布局、假山池沼、花草树木和近景远景说明；先总后分，细节服务于“图画美”的中心特征。
  - **20*《蝉》**：以观察和实验解释蝉的生长、脱壳和习性；科普说明把现象、观察过程和结论相连，避免把拟人化表达当作科学结论。
  - **21《梦回繁华》**：围绕《清明上河图》说明作品内容、绘画特点和历史价值；由画面对象到艺术与史料意义，引用细节证明判断。
  - **写作《说明事物要抓住特征》**：先确定说明对象，再选择能区分它的性质、结构、用途或变化；说明方法必须帮助读者理解特征。
- **第六单元：古典思想、史传与诗歌**
  - **22《〈孟子〉三章》**：《得道多助，失道寡助》由战争条件推出民心的重要；《富贵不能淫》界定大丈夫操守；《生于忧患，死于安乐》由个人磨炼推到国家忧患意识。
  - **23《愚公移山》**：愚公与智叟围绕移山是否可行争论；愚公以子孙延续、山体不增高论证长期行动的可能，寓意由人物论辩和结局共同形成。
  - **24《周亚夫军细柳》**：文帝巡营时细柳军军纪严整，与霸上、棘门形成对照；周亚夫不因皇帝到来而破例，细节证明其治军严明。
  - **25《诗词五首》**：陶渊明《饮酒》写远离尘俗后的心境；杜甫《春望》以花鸟反衬战乱忧思；李贺《雁门太守行》以色彩和典故写战斗；杜牧《赤壁》借史论英雄机遇；李清照《渔家傲》以梦境写理想与现实冲突。

## 三、必备知识点

- **新闻**：消息以事实为核心，标题/导语/主体层次不同；特写聚焦瞬间，通讯呈现较完整过程，评论明确立场并论证。不同体裁不可混称。
- **传记**：事实可核实，时间线清楚，事件有代表性；引用和评价须与人物经历相符。
- **说明文**：说明对象、特征、顺序、方法、语言准确性五项相互关联；删去“大约、主要、之一”等限定词可能改变事实范围。
- **诗歌与写景散文**：抓视角、意象、动静、节奏及情感变化；鉴赏结论要指向具体词句。
- **文言文**：结合语境掌握通假、古今异义、一词多义、词类活用和句式；人物观点要从论证过程得出。

## 四、表达方法与结构

- **消息**：标题概括主题 → 导语先报最重要事实 → 主体按时间/空间/重要性展开 → 必要背景补足理解。
- **说明文**：对象 → 关键特征 → 合适顺序 → 有针对性的说明方法 → 结论和范围限定。
- **人物传记**：可核实资料 → 时间线 → 典型事件 → 由证据支持的评价。
- **景物分析**：观察点 → 顺序 → 景物特征 → 描写手法 → 情感或主题作用。

## 五、必备字词与术语

| 字词/术语 | 读音 | 含义与本册用法 |
|---|---|---|
| 溃退 | kuì tuì | 被打败后迅速退却；新闻中说明战场态势。 |
| 翘首 | qiáo shǒu | 抬起头盼望；《“飞天”凌空》写观众关注比赛。 |
| 镌刻 | juān kè | 雕刻；常指把文字或图案刻在材料上。 |
| 匿名 | nì míng | 不写真实姓名；《藤野先生》的匿名信以此为线索。 |
| 踌躇 | chóu chú | 犹豫不决；理解《背影》时要联系叙述者情感变化。 |
| 轩榭 | xuān xiè | 轩，有窗的廊子或小屋；榭，建在台上的敞屋；见《苏州园林》。 |
| 骈句 | pián jù | 结构相似、字数相近、常成对出现的句子；《与朱元思书》多用骈句。 |
| 说明对象 / 特征 | shuō míng duì xiàng / tè zhēng | 被说明的事物及其区别于其他事物的性质；分析说明文时必须区分。 |

### 背诵原文与范围

#### 《三峡》
背诵范围：全文背诵。

> 自三峡七百里中，两岸连山，略无阙处。重岩叠嶂，隐天蔽日，自非亭午夜分，不见曦月。
> 至于夏水襄陵，沿溯阻绝。或王命急宣，有时朝发白帝，暮到江陵，其间千二百里，虽乘奔御风，不以疾也。
> 春冬之时，则素湍绿潭，回清倒影，绝𪩘多生怪柏，悬泉瀑布，飞漱其间，清荣峻茂，良多趣味。
> 每至晴初霜旦，林寒涧肃，常有高猿长啸，属引凄异，空谷传响，哀转久绝。故渔者歌曰：“巴东三峡巫峡长，猿鸣三声泪沾裳。”

### 默写标准

- 古诗词、文言文：写对篇名、作者或出处、原文、标点和易错字；文言句要能解释关键词。
- 现代文：严格按教材指定自然段背诵，能够复述段落内容、句间关系和关键表达作用。
- 每篇完成“背诵—遮挡默写—逐字核对—订正再写”四步；不会写的字单独列入错字表。


## 七、易错点与掌握边界

- 新闻的导语和标题不是一回事；标题可以概括，导语需交代最重要的事实。
- 传记中的作者评价不等于所有历史事实；评价应由具体经历支撑。
- 说明文中的举例、列数字和打比方作用不同，分析时要说清各自解释了什么特征。
- 《与朱元思书》的“鸢飞戾天者”是借景写心境，不是写真实鸟类飞翔的说明文。
- 文言翻译不能把古今同形词直接按现代义套用；要逐词结合上下文核义。
