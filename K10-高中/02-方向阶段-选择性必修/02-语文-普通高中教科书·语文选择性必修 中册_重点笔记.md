# 普通高中语文选择性必修中册重点笔记

> 对应教材：普通高中教科书·语文选择性必修中册
> 版本：统编版　|　学段：高中方向阶段

## 一、本册学习地图

### 本册到底教什么

- **教材主线**：本册以理论文章、革命文学、古代史传、外国戏剧和古典诗歌为主，训练概念阅读、论证分析、历史叙事、人物评价和诗歌比较。
- **四个单元**：理论与实践；革命文学与社会批判；史传与历史观；戏剧与诗歌。

| 单元 | 主要内容 | 本单元教会的知识 | 学完后的明确能力 |
|---|---|---|---|
| 第一单元 | 恩格斯、毛泽东、哲学伦理 | 概念、论点、论证和语言严密 | 能分析理论文章的概念链 |
| 第二单元 | 鲁迅、夏衍、孙犁 | 革命记忆、报告文学、小说 | 能从细节理解社会意义 |
| 第三单元 | 屈原、苏武、过秦论 | 史传、人物和历史论证 | 能比较历史人物与作者立场 |
| 第四单元 | 玩偶之家、诗歌 | 戏剧冲突、象征和抒情 | 能分析台词、意象和主题 |

## 二、目录与章节重点

### 第一单元：理论与实践

- **社会历史的决定性基础**：恩格斯说明经济关系是社会历史发展的根本制约，同时强调政治、法律、思想文化与经济相互作用；不能把经济决定论理解成其他因素没有作用。
- **改造我们的学习**：毛泽东批评主观主义、教条主义和党八股，提出实事求是、理论联系实际、调查研究的学风。
- **人的正确思想是从哪里来的？**：正确思想来自社会实践，并经过从感性认识到理性认识、再回到实践的循环。
- **实践是检验真理的唯一标准**：以实践检验认识是否符合客观实际，强调思想解放和实事求是。
- **修辞立其诚、怜悯是人的天性、人应当坚持正义**：分别从诚实表达、同情心和正义原则讨论人格与伦理；阅读哲学文章要找概念定义、推论和前提。

### 第二至第四单元

- **记念刘和珍君**：鲁迅悼念学生运动中的青年，反思沉默与勇敢；“我没有亲见”及“真的猛士”构成复杂的悲痛、激励和批判。
- **为了忘却的记念**：以友人回忆和现实处境纪念柔石等，写作中“忘却”反而成为更深的记忆和战斗。
- **包身工**：报告文学以真实调查揭露包身工制度，按一天生活和社会背景组织材料，数字、细节和议论共同构成批判力量。
- **荷花淀、小二黑结婚、党费**：以战争和乡村生活写普通人的成长、爱情、革命信念和集体关系；小说通过日常细节表现时代变化。
- **屈原列传、苏武传、过秦论、五代史伶官传序**：司马迁和班固写忠贞、气节与命运，贾谊分析秦亡原因，欧阳修从后唐兴亡提出“忧劳可以兴国，逸豫可以亡身”的历史警戒。
- **玩偶之家**：娜拉发现婚姻中人格不平等，最终出走；戏剧冲突来自家庭角色、法律道德和自我觉醒。
- **迷娘、致大海、自己之歌、树和天空**：诗歌通过异域、海洋、自我和自然意象表现乡愁、自由、生命和存在。
- **古诗词诵读**：燕歌行写边塞战争和将士处境，李凭箜篌引写音乐想象，锦瑟写追忆和迷惘，书愤写报国无门。

## 三、必备知识点

- **理论文章**：概念界定、论点、论据、推理、限定词和反驳；注意“归根到底”“同时”“并非”等逻辑范围。
- **报告文学**：新闻事实、文学细节和作者议论结合，真实性是底线。
- **史传文**：人物言行、史家叙事、评价语和历史因果；既要理解人物，也要辨析作者立场。
- **戏剧**：冲突、台词、潜台词、舞台行动、象征和结局。
- **诗歌**：意象组合、通感、用典、对比、节奏和情感转折。

## 四、必备公式/定理

- **理论阅读规则**：核心概念 + 观点命题 + 论据 + 推理关系 + 适用范围。
- **报告文学规则**：事实来源 + 典型细节 + 数据/场景 + 叙述立场 + 社会意义。
- **史传阅读规则**：人物处境 + 关键选择 + 结果 + 叙述评价 + 历史启示。
- **戏剧规则**：角色目标 + 关系矛盾 + 潜台词/行动 + 冲突高潮 + 结局意义。
- **诗歌规则**：意象链 + 画面/声音 + 手法 + 情感/哲思。

### 默写标准

- 古诗词、文言文：写对篇名、作者或出处、原文、标点和易错字；文言句要能解释关键词。
- 现代文：严格按教材指定自然段背诵，能够复述段落内容、句间关系和关键表达作用。
- 每篇完成“背诵—遮挡默写—逐字核对—订正再写”四步；不会写的字单独列入错字表。


## 七、易错点与掌握边界
- 理论文章不能只摘口号，要还原概念关系和论证链。
- 报告文学有文学表达，但事实不能虚构；数字和细节承担证据功能。
- 史传人物评价要区分作者叙述、人物言行和读者推断。
- 戏剧潜台词必须由上下文、关系和行动支持，不能随意心理化。
- 诗歌的“通感”不是所有感觉词都能互换，必须产生跨感官的具体效果。

## 八、独立学习验收

- 能用概念、论据和推理关系分析一篇理论文章。
- 能从报告文学细节说明其真实性和批判力量。
- 能比较《屈原列传》和《苏武传》中的人物选择与作者态度。
- 能分析戏剧冲突或古诗意象，并写出证据链。
