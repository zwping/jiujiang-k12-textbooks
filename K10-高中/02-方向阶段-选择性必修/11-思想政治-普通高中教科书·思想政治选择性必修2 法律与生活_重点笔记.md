## 一、本册学习地图

## 二、目录与章节重点

### 第一单元 民事权利与义务

#### 第一课 在生活中学民法用民法

- **认真对待民事权利与义务**：民事法律关系由主体、客体和内容构成。自然人、法人和非法人组织可依法成为民事主体；客体可以是物、行为、智力成果或人身利益；内容是主体享有的权利和承担的义务。民事活动遵循平等、自愿、公平、诚信、守法和公序良俗等原则。
- 自然人具有民事权利能力；民事行为能力决定其能否独立实施民事法律行为。现行《民法典》规定：成年人一般为完全民事行为能力人；16周岁以上未成年人以自己的劳动收入为主要生活来源的，视为完全民事行为能力人；8周岁以上未成年人为限制民事行为能力人，可独立实施纯获利益或与其年龄、智力相适应的行为；不满8周岁未成年人为无民事行为能力人，由法定代理人代理。能否独立订约须依行为能力和具体行为判断，不能仅凭当事人“未成年”一概认定合同无效。
- 民事权利与民事义务相对应。权利人可依法请求义务人实施或不实施一定行为；义务人应按法律或约定履行。权利行使不得违反法律、损害国家利益、社会公共利益或他人合法权益。
- **积极维护人身权利**：生命权、身体权、健康权保护人格尊严和身心完整；姓名权、名称权、肖像权、名誉权、荣誉权、隐私权和个人信息权益等保护人格利益。未经同意公开他人私密信息、侮辱诽谤或非法使用肖像可能构成侵权，具体要结合行为、过错、损害和法律规定判断。

#### 第二课 依法有效保护财产权

- **保障各类物权**：物权是权利人依法对特定物享有直接支配和排他的权利，包括所有权、用益物权和担保物权。所有权包括占有、使用、收益、处分；动产与不动产物权的设立、变更规则不同，交易时要核实权属及登记、交付等法定要件。
- 用益物权使权利人在他人所有的物上依法占有、使用和收益；担保物权为债权实现提供优先受偿保障。抵押通常不转移占有，质押通常移转特定财产或权利的占有/控制，具体设立要件依现行法规定。
- **尊重知识产权**：知识产权保护智力成果，包括著作权、专利权、商标权等。著作权保护具有独创性的表达，不垄断思想、事实或方法本身；专利权保护依法授权的发明创造，须在权利有效范围内；商标权保护注册商标识别商品或服务来源的功能。学习、引用和转载须检查许可、法定例外、署名及合理使用条件，不能仅因网络可访问就任意复制。

#### 第三课 订约履约 诚信为本

- **订立合同学问大**：合同是民事主体之间设立、变更、终止民事法律关系的协议。合同成立通常经历要约与承诺；要约内容应具体确定并表明经承诺即受约束，承诺须在有效期内作出并与要约内容一致。实际成立时间、形式和例外依合同类型及现行法律判断。
- 订立合同应遵循平等、自愿、公平、诚信和守法原则。重要条款通常包括当事人、标的、数量、质量、价款或报酬、履行期限地点方式、违约责任和争议解决方法；遗漏或约定不明时法律可能提供补充规则，但不代表所有口头约定都容易举证。
- **有约必守 违约有责**：合同依法成立后对当事人具有约束力。履行应按约定全面、诚信；发生违约时，责任形式可包括继续履行、采取补救措施、赔偿损失、支付违约金等，适用方式取决于约定、损失、因果关系和法律规定。不可抗力等免责事由须依法判断，不是只要“遇到困难”就自动免责。

#### 第四课 侵权责任与权利界限

- **权利保障 于法有据**：侵害民事权益造成损害的，应依法律承担侵权责任。一般过错责任关注侵害行为、损害、因果关系和过错；法律对特定情形规定过错推定或无过错责任时，适用相应特别规则。责任方式可包括停止侵害、排除妨碍、消除危险、返还财产、恢复原状、赔偿损失、赔礼道歉等，须与侵害类型相适应。
- **权利行使 注意界限**：正当防卫、紧急避险、不可抗力、受害人故意等情形可能影响责任承担，但构成条件须逐项核实。公平责任不是一般过错责任的替代品，只有在法律规定的条件下适用。
- 处理侵权争议要保存合同、付款凭证、沟通记录、照片/视频、鉴定材料等证据，并注意来源合法、内容真实和关联性；网络截图要尽可能留存原始载体、时间和完整上下文。

#### 综合探究 财产制度助力经济社会发展

财产权保护既维护权利人利益，也为交易和创新提供预期。讨论产权争议要先识别权利类型及权属证据，再确认他人行为是否落入受保护范围，最后判断法定例外和救济；不能把所有资源都简单称为个人所有权。

### 第二单元 家庭与婚姻

#### 第五课 在和睦家庭中成长

- **家和万事兴**：家庭成员之间应依法互相扶养、赡养、抚养并履行相应义务。父母对未成年子女负有抚养、教育和保护义务；成年子女对父母负有赡养扶助义务；家庭暴力不是家庭内部私事，受害人可依法求助并寻求保护。
- **薪火相传有继承**：继承包括法定继承和遗嘱继承等方式。遗产是自然人死亡时遗留的个人合法财产；继承开始后须先区分遗产与他人财产、清偿依法应处理的债务，再按有效遗嘱或法定顺序处理。遗嘱须符合法定形式和能力要求，不能处分他人财产或剥夺依法应保留的必要份额。
- 法定继承顺序、遗嘱效力、继承份额可能受家庭关系和现行法律细节影响；处理现实继承事项需查现行《民法典》继承编并核验事实证据。

#### 第六课 珍惜婚姻关系

- **法律保护下的婚姻**：结婚应由男女双方完全自愿，达到法定条件并依法办理登记；婚姻关系受法律保护。婚姻自由包括结婚自由和离婚自由，但任何一方不得以暴力、胁迫或违法方式干涉。
- 离婚涉及身份关系和未成年子女利益，协议离婚与诉讼离婚有不同程序。判断子女抚养和财产处理，须依据现行法律和具体事实，保护未成年人利益；教材概括不等于个案结论。
- **夫妻地位平等**：夫妻在婚姻家庭中地位平等。夫妻共同财产、个人财产和共同债务的认定依财产来源、约定及法律规定；不能因为债务发生在婚姻期间就一律认定为夫妻共同债务。

#### 综合探究 家庭生活 法律守护

处理家庭纠纷时，先确认家庭成员关系和当事人真实意愿，再区分身份义务、财产权属和未成年人利益；涉及暴力或紧急人身安全风险时，应优先寻求公安、民政、司法等有权机构帮助。

### 第三单元 就业与创业

#### 第七课 做个明白的劳动者

- **立足职场有法宝**：劳动者依法享有平等就业、取得劳动报酬、休息休假、劳动安全卫生保护、社会保险和福利等权利，同时负有完成劳动任务、遵守规章和职业道德等义务。劳动合同确立劳动关系，订立和履行应遵循合法、公平、平等自愿、协商一致、诚实信用原则。
- 劳动合同应采用法定形式并明确工作内容、工作地点、劳动报酬、工作时间和休息休假、劳动保护等重要事项。求职者应核实用人单位主体、岗位、薪酬及合同文本，不要将招聘宣传等同于已签订合同。
- **心中有数上职场**：劳动者可通过协商、调解、劳动仲裁及诉讼等法定渠道处理劳动争议；劳动仲裁是劳动争议处理的重要前置程序之一，但适用范围和后续诉讼条件依现行劳动法律规定。保留合同、工资记录、考勤、工作指令和沟通证据有助于证明劳动关系与争议事实。

#### 第八课 自主创业与诚信经营

- **自主创业 公平竞争**：创业者应依法选择经营主体和经营范围，办理必要登记许可，遵守市场准入和公平竞争规则。经营决策须评估市场需求、成本、资金与合规风险；不能以虚假宣传、商业贿赂、侵犯商业秘密或滥用市场优势获取不正当竞争利益。
- **诚信经营 依法纳税**：经营者应保障消费者安全保障、知情、自主选择、公平交易、依法求偿等权利，尊重消费者人格尊严和个人信息，依法履行真实告知、质量保障、售后服务等义务。经营者不得作虚假或引人误解的宣传；消费者也应依法、诚信行使权利。
- 纳税义务依税种、纳税主体、应税事项和现行规定确定；经营主体应依法申报并保存账簿凭证。具体税率、优惠和申报期限具有时效性，须以税务机关现行正式规则为准，本笔记不编列动态数字。

#### 综合探究 企业创办之旅

创办企业的基本核对链：确定主体和业务 → 查询准入与许可要求 → 订立合同、保护知识产权 → 建立财务和税务合规流程 → 依法用工并保护消费者权益。具体登记材料、审批范围和税务政策需按所在地与业务类型查询政府部门当前办事指南。

### 第四单元 社会争议解决

#### 第九课 纠纷的多元解决方式

- **认识调解与仲裁**：调解由中立第三方促使当事人自愿协商解决；人民调解协议依法具有相应效力，特定条件下可申请司法确认。仲裁以当事人约定和法律授权为基础，由仲裁机构依规则裁决；商事仲裁与劳动争议仲裁适用制度不同，不可混称。
- **解析三大诉讼**：民事诉讼处理平等主体间民事权利义务争议；行政诉讼审查行政行为合法性及相关争议；刑事诉讼解决犯罪追诉和刑罚适用。判断诉讼类型看争议法律关系、当事人身份及请求，不只看案件名称。
- 诉讼以事实为根据、以法律为准绳。选择争议解决方式时，应考虑是否可处分、是否有仲裁约定、证据保存、时效和管辖等因素；诉讼时效、上诉期限和管辖规则须以现行法律为准。

#### 第十课 诉讼实现公平正义

- **正确行使诉讼权利**：当事人依法享有起诉、答辩、委托诉讼代理人、申请回避、举证质证、辩论、上诉等程序权利；具体权利因诉讼类型和诉讼地位不同而异。依法行使权利也须遵守程序、履行相应义务。
- **严格遵守诉讼程序**：民事诉讼通常经历起诉受理、审理、裁判及依法申请执行等阶段；行政和刑事诉讼有各自程序。不能因一方提出主张就认定法院已确认事实；裁判结果以生效法律文书为准。
- **依法收集运用证据**：证据用于证明案件事实，应具有真实性、合法性和关联性。民事案件常见证据包括当事人陈述、书证、物证、视听资料、电子数据、证人证言、鉴定意见和勘验笔录等。负举证责任一方须依法提供证据；证据不足可能承担不利后果，特殊举证规则按法律适用。

#### 综合探究 感受司法公正

审视一场诉讼，分别检查程序是否依法、双方是否有平等参与和举证机会、裁判是否说明事实与法律依据、救济渠道是否明确。不能仅凭当事人输赢判断司法是否公正。

## 三、必备知识点

- 民事法律关系由主体、客体、内容构成；权利、义务和责任相互关联。
- 人身权、物权、知识产权保护的客体不同，认定侵权须回到具体权利和法定要件。
- 合同通过要约、承诺等规则成立，依法成立后应诚信履行；违约责任按约定和法律确定。
- 家庭扶养义务、继承规则、婚姻关系及夫妻财产须分别依据身份关系、财产归属和法定条件判断。
- 劳动关系受劳动法律保护；创业经营须守公平竞争、消费者保护、知识产权和纳税义务规则。
- 调解、仲裁和诉讼机制不同；民事、行政、刑事诉讼按争议性质区分；证据影响事实认定和责任承担。

## 四、必备公式/定理

本册无数学公式。民事责任分析框架：权利及义务关系 → 行为是否违反法定义务/约定义务 → 损害与因果关系 → 过错及特别责任规则 → 可适用责任方式。该框架用于梳理问题，具体构成要件依案件适用法律确定。

## 五、必备单词/术语

| 术语 | 确切含义 | 易混边界 |
|---|---|---|
| 民事主体 | 依法参与民事法律关系、享有民事权利并承担民事义务的人或组织 | 与民事法律关系客体不同 |
| 物权 | 权利人依法对特定物直接支配和排他的权利 | 与债权的请求权性质不同 |
| 要约 | 希望与他人订立合同的意思表示，内容具体确定并表明承诺即受约束 | 与要约邀请不同，须看内容和表达 |
| 违约责任 | 合同一方不履行或不符合约定时依法承担的责任 | 与侵权责任的发生依据不同 |
| 侵权责任 | 因侵害他人民事权益依法承担的民事责任 | 归责原则因一般规则与法定特殊规则而异 |
| 夫妻共同财产 | 依据婚姻关系、财产来源、约定和法律确定的共同财产 | 婚姻存续期间取得不必然全部属于共同财产 |
| 劳动争议仲裁 | 处理劳动者与用人单位劳动争议的法定程序 | 不等同于商事仲裁 |
| 举证责任 | 当事人对其主张提供证据并承担证明不能后果的程序责任 | 不同案件和事项有不同分配规则 |

## 六、熟记内容

- 民事法律关系由主体、客体和内容构成；处理民事活动要遵循平等、自愿、公平、诚信、守法和公序良俗原则。
- 物权包括所有权、用益物权和担保物权；知识产权包括著作权、专利权和商标权等。
- 合同依法成立后对当事人具有法律约束力；违约责任依法律和约定承担。
- 调解、仲裁、诉讼是不同纠纷解决机制；民事、行政、刑事诉讼处理的法律关系不同。

## 七、易错点与掌握边界

| 易错理解 | 正确结论 |
|---|---|
| 网络上能看到的图片和文章可自由使用 | 著作权通常仍受保护，使用需满足授权或法定例外条件 |
| 合同只有书面签字才可能成立 | 合同形式因法律规定和交易情形而异，但书面证据更利于证明约定 |
| 一方违约就必然按对方主张金额赔偿 | 责任方式和范围要看约定、损失、因果关系和法律规定 |
| 夫妻婚后所有债务均为共同债务 | 需依共同意思表示、家庭日常生活需要及法律规则认定 |
| 调解、商事仲裁、劳动仲裁可以互换 | 三者依据、程序和适用争议不同 |

## 八、综合应用示例

消费者网购电器，商家页面承诺某项功能，收货后商品不具备该功能且商家拒绝处理。先保存订单、商品页面、付款记录、沟通记录和商品检测情况；再判断页面承诺是否构成合同内容、商品是否符合约定、是否存在质量问题；随后可与经营者协商或向消费者组织、监管部门寻求帮助，必要时依法诉讼。是否可退换、赔偿以及举证责任，取决于现行消费者保护规则、合同内容、缺陷证据和具体交易事实，不能仅凭“网购”推断固定赔偿结果。
