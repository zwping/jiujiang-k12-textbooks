## 一、本册学习地图

本册依次学习思维和科学思维、概念判断推理的形式规则、辩证思维、创新思维。前两单元保证思维形式清晰、推理有效；第三单元处理整体与部分、量变与质变、肯定与否定等动态关系；第四单元用联想、发散聚合、逆向和超前思维解决新问题。逻辑形式有效不等于前提事实真实，论证结论仍需证据支持。

| 单元 | 学习内容 | 学完能做到 |
|---|---|---|
| 树立科学思维观念 | 思维特征、思维形态、逻辑要求、科学思维 | 区分思维形式并判断基本逻辑错误 |
| 遵循逻辑思维规则 | 概念、判断、演绎、归纳、类比推理 | 准确界定概念并检验推理结构 |
| 运用辩证思维方法 | 分析综合、质量互变、辩证否定、认识发展 | 处理整体与部分及变化阶段关系 |
| 提高创新思维能力 | 联想、发散聚合、逆向和超前思维 | 生成方案并用事实条件筛选 |

## 二、目录与章节重点

### 第一单元 树立科学思维观念

#### 第一课 走进思维世界

- **思维的含义与特征**：思维是人脑对客观事物的间接、概括反映。思维具有间接性、概括性和能动性；思维依赖社会实践和语言表达，但思维内容仍受客观对象制约。通过推断观察不到的原因属于间接性；从多个事例概括共同规律属于概括性。
- **思维形态及其特征**：从思维方向看，有发散思维和聚合思维；从思维对认识对象的反映方式看，有抽象思维和形象思维；从思维运行基本单元看，有综合思维和分析思维等。抽象思维以概念、判断、推理反映对象，形象思维以感性形象为基本单元；二者在实际思维中相互补充。

#### 第二课 把握逻辑要义

- **“逻辑”的多种含义**：“逻辑”可指客观事物的规律、思维规律、逻辑学或某种论证方式。讨论时须根据语境辨认词义，不能把“某人的逻辑”与形式逻辑学科混为一谈。
- **逻辑思维的基本要求**：同一思维过程中概念和论题须保持确定，遵循同一律；不能同时肯定互相矛盾的判断，遵循矛盾律；对于互相矛盾的判断不能同时否定，遵循排中律。形式逻辑规则要求概念、判断和推理符合规则，但规则本身不能证明前提事实真实。
- 偷换概念或转移论题违反同一律；自相矛盾违反矛盾律；对互相矛盾的选项既不承认也不否认违反排中律。辨析时须先确认语境和判断是否确属同一时间、同一方面。

#### 第三课 领会科学思维

- **科学思维的含义与特征**：科学思维是符合认识规律、遵循逻辑规则、能够达到正确认识结果的思维。其结果具有客观性，过程体现预见性和可检验性；推断必须建立在可靠材料和有效推理上。
- **学习科学思维的意义**：科学思维有助于提高思维素养、把握客观规律、提高决策和实践能力。实践中要结合证据、逻辑和具体条件，不能把“科学”用作未经论证的权威标签。

#### 综合探究 学会科学思维 提升思维品质

科学思维需要可靠前提、明确概念、有效推理和实践检验。观察一个结论时，应追问证据来源、样本范围、推理规则和适用条件；结论与证据不匹配时，应降低结论强度或补充验证。

### 第二单元 遵循逻辑思维规则

#### 第四课 准确把握概念

- **概念的概述**：概念反映事物本质属性。概念的内涵是其反映的本质属性，外延是其指称的对象范围；内涵与外延具有反向关系，内涵增加时外延通常缩小。概念须明确、恰当并保持同一语境。
- 概念外延关系包括全同、属种、种属、交叉和全异等。辨别外延关系要比较对象范围，不能只看词语相似。例如“学生”和“运动员”可能交叉：有些学生是运动员，但两类并不完全相同。
- **明确概念的方法**：定义揭示概念内涵，应遵循相称原则，避免循环定义、定义过宽或过窄；划分揭示概念外延，应遵循同一标准、子项互斥并穷尽母项。按“颜色”把书分为“红色书”和“教材”就混用了标准，且子项可能重叠。

#### 第五课 正确运用判断

- **判断的概述**：判断是对认识对象有所断定的思维形式，有真假之分。性质判断断定对象具有或不具有某性质；关系判断断定对象之间具有某种关系。判断真假取决于内容与事实是否相符，表达形式不自动保证真实。
- **正确运用简单判断**：性质判断按量项和联项可区分全称/特称、肯定/否定形式；使用时要准确限定对象范围。关系判断须说明关系方向和对象次序，“甲大于乙”与“乙大于甲”表达不同关系。
- **正确运用复合判断**：联言判断断定多个支判断同时成立，只有各支判断都真时联言判断才真；选言判断分相容选言和不相容选言，前者至少一支为真即可，后者只能有一支为真；假言判断表示条件关系，其真假须结合联结词含义和事实条件判断。充分条件假言判断“如果P那么Q”只在P真而Q假时为假；必要条件判断“只有P才Q”在Q真而P假时为假；充要条件要求P、Q互为充分必要条件。

#### 第六课 掌握演绎推理方法

- **推理与演绎推理概述**：推理由前提推出结论。演绎推理从一般性前提推出个别性结论；若前提真实且推理形式有效，结论必然真实。形式有效不保证前提为真。
- **简单判断的演绎推理方法**：性质判断换质、换位要遵守规则，不能扩大词项外延。三段论含大项、小项和中项：中项至少周延一次；前提中不周延的词项不能在结论中周延；两个否定前提不能推出结论；有一否定前提则结论为否定。例：“所有哺乳动物都是动物；鲸是哺乳动物；所以鲸是动物”，中项“哺乳动物”在前提中周延，推理有效。
- **复合判断的演绎推理方法**：联言推理可由整体推出部分，也可由各部分推出整体；相容选言推理不能由否定一个选言支推出肯定另一个选言支，除非选言支穷尽且不相容；不相容选言推理可由否定一支推出肯定另一支。充分条件假言推理有效式为肯定前件式和否定后件式；必要条件假言推理有效式为否定前件式和肯定后件式。把“如果P则Q”由Q反推P属于肯定后件，形式无效。

#### 第七课 学会归纳与类比推理

- **归纳推理及其方法**：归纳从个别性前提推出一般性结论。完全归纳考察某类全部对象，结论具有必然性；不完全归纳考察部分对象，结论具有或然性。提高不完全归纳可靠度需扩大样本、保证代表性并排除反例。
- 求因果联系可用求同、求异、共变等方法，但观察到共同变化并不自动证明因果；还需控制其他变量并检查机制。统计样本存在选择偏差时，不能推广到总体。
- **类比推理及其方法**：类比根据两个对象在若干属性上的相似，推出它们在其他属性上可能相似，结论是或然的。相似属性越多、越本质，结论通常越可靠；若关键条件不同，类比会失效。类比可以启发假设，仍须实验或事实检验。

#### 综合探究 把握逻辑规则 纠正逻辑错误

检查论证时依次确认核心概念是否前后一致、前提是否有证据、推理规则是否有效、结论是否超出前提范围。只指出结论错误而不说明概念或推理问题，论证仍不完整。

### 第三单元 运用辩证思维方法

#### 第八课 把握辩证分合

- **辩证思维的含义与特征**：辩证思维用联系、发展和全面的观点认识对象，动态把握整体与部分、现象与本质、原因与结果等关系。它不排斥分析，而是要求分析之后综合，并在整体中重新理解部分。
- **分析与综合及其辩证关系**：分析把整体分解为部分或把复杂对象分解为要素，以认识结构和作用；综合把认识到的部分联系起来，形成对整体的理解。分析是综合的基础，综合是分析的升华，二者应相互配合。把一项政策的单个指标当成整体效果，属于以偏概全。

#### 第九课 理解质量互变

- **认识质量互变规律**：量变是事物数量增减和场所变更，质变是事物根本性质变化。量变是质变必要准备，质变是量变必然结果；新质基础上又发生新的量变。量变与质变区分须看是否改变根本性质，不仅看数值大小。
- **把握适度原则**：度是保持事物质的稳定性的数量界限；关节点是度的边界。适度原则要求把量控制在保持所需性质的范围内；当条件成熟、需要突破旧质时，应促成质变。不能把适度理解为永远维持现状。

#### 第十课 推动认识发展

- **不作简单肯定或否定**：辩证否定是事物自身的否定，是联系和发展的环节；既克服旧事物中过时消极内容，又保留其中合理积极因素。扬弃不是全盘保留或全盘抛弃。
- **体会认识发展的历程**：认识从感性具体上升到思维抽象，再由思维抽象上升到思维具体。思维抽象应抓住对象某一方面的本质规定，思维具体则在多种规定的综合中再现对象整体。抽象若脱离材料和整体关系，会造成片面认识。

#### 综合探究 领悟辩证精髓 处理复杂问题

处理复杂问题时先把对象分解、识别关键关系，再综合不同因素并检查结论是否适用于全部条件；发现新证据后应修正原有认识。

### 第四单元 提高创新思维能力

#### 第十一课 创新思维要善于联想

- **创新思维的含义与特征**：创新思维以实践为基础，综合多种思维方法，力求形成新颖、有价值的认识或方案。新颖不等于有效；方案必须接受事实、可行性和实践结果检验。
- **联想思维的含义与方法**：联想是由一事物想到与之有联系的另一事物，包含时间、空间、因果、相似、对比等联系。联想具有跨越性和连续性；迁移可把已知方法用于相似问题，想象可在已有材料基础上形成新形象。类比迁移须检查关键条件是否相同。

#### 第十二课 创新思维要多路探索

- **发散思维与聚合思维的方法**：发散思维围绕问题从不同方向寻找多种设想，可用检核表、列举、信息交合法等方式扩展方案；聚合思维依据标准和证据筛选、整合方案。先发散再聚合能兼顾数量与质量；发散不是随意联想，聚合标准须与目标相关。
- **逆向思维的含义与作用**：逆向思维从相反方向或对立角度思考，帮助突破固定思路。逆向方案仍须满足问题条件、资源限制和因果规律；反着说不等于创新。

#### 第十三课 创新思维要力求超前

- **超前思维的含义与特征**：超前思维依据事物发展规律和现实条件，对未来趋势作有根据的预测。预测具有不确定性，应区分事实、假设与推论，并说明条件。
- **超前思维的方法与意义**：可通过矛盾分析、推理和调查研究识别趋势，再构造不同情景、比较风险并制定预案。超前思维有助于规划和风险防范，但预测不是确定事实，须随着新证据更新。

#### 综合探究 结合社会实践 勇于开拓创新

面对实践问题，明确目标和约束，发散提出方案，聚合筛选，利用类比或逆向视角拓展可能性，再以证据和测试检验，并根据结果迭代。

## 三、必备知识点

- 思维是人脑对客观事物的间接、概括反映；概念、判断、推理是抽象思维的基本形式。
- 同一律要求思维对象和概念保持同一；矛盾律排斥同一时间同一方面的互相矛盾判断并真；排中律要求互相矛盾判断不能同假。
- 概念以内涵和外延界定；定义须相称，划分须标准统一、子项互斥并穷尽母项。
- 演绎推理在前提真实且形式有效时保证结论真实；归纳和类比推理通常为或然推理，需要证据检验。
- 充分条件推理可肯定前件或否定后件；必要条件推理可否定前件或肯定后件，不能倒置有效式。
- 分析与综合相互依赖；量变积累到一定程度引起质变，质变开启新的量变；辩证否定是扬弃。
- 发散用于拓展候选方案，聚合按目标和证据筛选；超前思维是有条件的预测而非确定预言。

## 四、必备公式/定理

### 条件推理有效式

| 推理类型 | 有效式 | 无效的常见倒置 |
|---|---|---|
| 充分条件假言推理：若P则Q | 肯定P，推出Q；否定Q，推出非P | 肯定Q不能推出P；否定P不能推出非Q |
| 必要条件假言推理：只有P才Q | 否定P，推出非Q；肯定Q，推出P | 肯定P不能推出Q；否定Q不能推出非P |

符号P、Q代表命题；判断推理是否有效时，先确认“如果/只有”等连接词真实表达充分条件还是必要条件。

## 五、必备单词/术语

| 术语 | 含义 | 使用提醒 |
|---|---|---|
| 内涵 | 概念所反映的本质属性 | 定义须揭示内涵且与外延相称 |
| 外延 | 概念指称对象的范围 | 划分概念时检查是否遗漏、重叠 |
| 周延 | 判断主项或谓项断定了其全部外延 | 三段论中中项至少周延一次 |
| 演绎推理 | 从一般性前提推出个别性结论的推理 | 前提真且形式有效，结论才必真 |
| 完全归纳 | 考察某类全部对象后概括一般结论 | 范围有限且穷尽时可得必然结论 |
| 类比推理 | 根据对象间相似属性推测其他属性相似 | 结论或然，关键条件须核验 |
| 度 | 事物保持自身质的稳定性的数量界限 | 关节点是度的边界，不是任意数值 |
| 辩证否定 | 事物自身的否定，既克服又保留 | 扬弃不等于全盘否定 |
| 发散思维 | 围绕问题向不同方向扩展设想 | 产生候选方案，不负责最终证明 |
| 聚合思维 | 按目标和标准筛选、整合信息和方案 | 标准须清楚，结论须有证据 |

## 六、熟记内容

- 逻辑思维基本要求：同一律、矛盾律、排中律。
- 定义须遵循相称原则；划分须使用同一标准、子项互斥并穷尽母项。
- 充分条件假言推理的有效式是肯定前件式、否定后件式；必要条件假言推理的有效式是否定前件式、肯定后件式。
- 分析是综合的基础，综合是分析的升华；量变是质变的必要准备，质变是量变的必然结果。
- 辩证否定是扬弃；创新方案须经实践和证据检验。

## 七、易错点与掌握边界

| 易错理解 | 正确结论 |
|---|---|
| 只要结论碰巧正确，推理形式就有效 | 有效性检查推理结构，真实性检查命题与事实是否相符 |
| “如果P则Q”且Q成立，所以P成立 | 肯定后件是无效式，其他原因也可能导致Q |
| 概念定义越长越准确 | 定义须揭示本质属性且范围相称，冗长并不保证正确 |
| 部分样本归纳可证明全部对象都如此 | 不完全归纳结论具有或然性，须检验样本代表性和反例 |
| 类比对象相似就能推出结论必真 | 类比只提供可能性，关键相似点和因果机制要核实 |
| 适度就是保持现状、不发生改变 | 适度是把握质量界限；条件成熟时需要促成质变 |
| 逆向思维就是与常识唱反调 | 逆向方案仍须符合事实、逻辑和约束条件 |

## 八、综合应用示例

论证：“如果一种产品通过安全检测，它就符合该检测项目的标准；这款产品符合该检测项目的标准；所以它通过了安全检测。”该推理肯定后件，形式无效，因为符合标准也可能由其他证据或条件支持。有效论证可以改为：“若产品通过该检测，则符合该项目标准；检测记录显示它通过检测；因此它符合该项目标准。”此结论仍只涉及该检测项目，不代表产品在所有安全方面都无问题。
