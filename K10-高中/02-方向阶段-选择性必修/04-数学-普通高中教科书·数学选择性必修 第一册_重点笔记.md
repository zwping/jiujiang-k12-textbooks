## 二、目录与章节重点

### 第一章 直线与圆

#### 1.1 一次函数的图象与直线的方程

一次函数图象是直线。直线上每一点的坐标都满足其方程，反之，方程的解对应直线上的点。已知直线上两点可先求斜率，再用点斜式写方程；若直线竖直，斜率不存在，应写成 `x=x₀`。

例：过 `(1,2)`、`(3,6)` 的直线斜率 `k=(6−2)/(3−1)=2`，方程为 `y−2=2(x−1)`，即 `y=2x`。

#### 1.2 直线的倾斜角、斜率及其关系

直线向上的方向与 `x` 轴正方向所成的角 `α∈[0,π)` 为倾斜角；当 `α≠π/2` 时斜率 `k=tan α`。斜率表示横坐标每增加1时纵坐标的变化率。竖直直线没有有限斜率。

两条非竖直直线斜率相等且截距不同则平行；斜率乘积为 `−1` 则垂直。垂直关系公式仅适用于两条斜率均存在的直线；含竖直线时按方向单独判定。

#### 1.3 直线的方程

- 点斜式：`y−y₁=k(x−x₁)`，适用于斜率为 `k` 且过 `(x₁,y₁)` 的非竖直直线。
- 斜截式：`y=kx+b`，`b` 为纵截距。
- 两点式：可由两点坐标建立比例式；两点横坐标相同时应改写为竖直线方程。
- 一般式：`Ax+By+C=0`，其中 `A、B` 不同时为0；法向量为 `(A,B)`，方向向量可取 `(B,−A)`。

例：直线过 `(2,−1)`，斜率为3，点斜式为 `y+1=3(x−2)`，化为一般式 `3x−y−7=0`。

#### 1.4 两条直线的平行与垂直

对一般式直线 `A₁x+B₁y+C₁=0` 与 `A₂x+B₂y+C₂=0`，平行要求法向量成比例，即 `A₁B₂−A₂B₁=0`；重合还需常数项也按同一比例。垂直可用方向向量点积为0，等价于 `A₁A₂+B₁B₂=0`。

#### 1.5 两条直线的交点坐标

联立两个直线方程解二元一次方程组。系数行列式不为0时有唯一交点；行列式为0时两线平行或重合，须再比较常数项。

#### 1.6 平面直角坐标系中的距离公式

两点 `P₁(x₁,y₁)`、`P₂(x₂,y₂)` 的距离为 `√[(x₁−x₂)²+(y₁−y₂)²]`。点 `(x₀,y₀)` 到直线 `Ax+By+C=0` 的距离为 `|Ax₀+By₀+C|/√(A²+B²)`，其中 `A、B` 不同时为0。

#### 2.1—2.4 圆的方程与位置关系

圆心 `(a,b)`、半径 `r>0` 的标准方程为 `(x−a)²+(y−b)²=r²`；展开后一般式 `x²+y²+Dx+Ey+F=0` 的圆心为 `(-D/2,-E/2)`，半径平方为 `(D²+E²−4F)/4`，只有半径平方大于0时表示实圆。

判断直线与圆的位置关系，比较圆心到直线的距离 `d` 与半径 `r`：`d>r` 相离，`d=r` 相切，`d<r` 相交。也可把直线代入圆方程，按二次方程判别式正、零、负判断两、一个、零个交点。

两圆圆心距为 `d`、半径分别为 `r₁,r₂`：`d>r₁+r₂` 外离；`d=r₁+r₂` 外切；`|r₁−r₂|<d<r₁+r₂` 相交；`d=|r₁−r₂|` 内切；`d<|r₁−r₂|` 内含（同心重合需另行判定）。

### 第二章 圆锥曲线

#### 2.1 椭圆及其标准方程

椭圆是到两个定点（焦点）的距离之和等于常数的点集。当常数大于两焦点间距时形成椭圆。中心在原点、长轴沿 `x` 轴时，标准方程为 `x²/a²+y²/b²=1 (a>b>0)`，`c²=a²−b²`，焦点为 `(±c,0)`，离心率 `e=c/a∈(0,1)`。长轴沿 `y` 轴时交换 `x、y` 对应的分母与焦点方向。

#### 2.2 椭圆的简单几何性质

椭圆顶点为 `(±a,0)`、`(0,±b)`（长轴沿 `x` 轴时）；长轴长 `2a`、短轴长 `2b`。离心率越接近0，椭圆越接近圆；越接近1，形状越扁长。识别参数前先看分母大小，较大的分母对应长轴方向。

#### 2.3 双曲线及其标准方程

双曲线是到两个焦点距离之差的绝对值为定值的点集。中心在原点、实轴沿 `x` 轴时，方程为 `x²/a²−y²/b²=1`，`c²=a²+b²`，焦点 `(±c,0)`，离心率 `e=c/a>1`，渐近线 `y=±(b/a)x`。实轴沿 `y` 轴时方程中正项改为 `y²/a²`。

渐近线用于描述曲线远处趋近的直线，不是曲线上的有限交点。由一般标准式辨认方向，依据是正项所在坐标轴，不是先出现的变量。

#### 2.4 双曲线的简单几何性质

双曲线顶点在实轴上，实轴长 `2a`、虚轴长 `2b`。由 `c²=a²+b²` 得 `e>1`。焦点距中心 `c`，顶点距中心 `a`。当方程含 `xy` 项或中心不在原点时，不能直接套用上述标准坐标结论，需先完成坐标变换或配方。

#### 2.5 抛物线及其标准方程

抛物线是到定点（焦点）与定直线（准线）距离相等的点集。顶点在原点、开口向右时 `y²=2px (p>0)`，焦点 `(p/2,0)`，准线 `x=−p/2`；向左只改变 `x` 的符号。开口向上时 `x²=2py`，焦点 `(0,p/2)`，准线 `y=−p/2`；向下同理。教材若采用 `y²=4ax` 记号，则焦点参数为 `a`，需按方程约定辨认，不能混用 `p` 与 `4a`。

#### 2.6 抛物线的简单几何性质

抛物线对称轴经过顶点和焦点。标准式中一次项所在变量方向决定开口方向：`y²` 对应水平开口，`x²` 对应竖直开口。由点在曲线上可代入方程检验；焦点弦、准线性质须确认题目采用的标准方程参数。

#### 3—4 直线与圆锥曲线的位置关系

联立直线方程与圆锥曲线方程，消元得到关于一个变量的二次方程。判别式大于0表示两个不同交点，等于0表示相切，低于0表示无实交点。求弦长时，可用两交点坐标距离；若交点横坐标为 `x₁,x₂` 且直线斜率为 `k`，弦长为 `√(1+k²)|x₁−x₂|`。须排除竖直线另行处理。

### 第三章 空间向量与立体几何

#### 3.1 空间直角坐标系与两点距离

点 `P(x,y,z)` 到原点距离为 `√(x²+y²+z²)`；两点距离为 `√[(x₁−x₂)²+(y₁−y₂)²+(z₁−z₂)²]`。坐标轴互相垂直且单位长度一致时，三维距离公式来自勾股定理的两次应用。

#### 3.2 空间向量及其运算

向量由大小和方向确定。若 `a=(a₁,a₂,a₃)`、`b=(b₁,b₂,b₃)`，则 `a±b` 按对应坐标相加减，`λa=(λa₁,λa₂,λa₃)`，数量积 `a·b=a₁b₁+a₂b₂+a₃b₃=|a||b|cosθ`。非零向量垂直当且仅当数量积为0。

#### 3.3 空间向量基本定理及坐标表示

空间中三个不共面的向量 `e₁,e₂,e₃` 构成一组基底，任一向量可唯一表示为 `x e₁+y e₂+z e₃`。空间直角坐标系的三个单位基向量两两垂直且长度为1，因此坐标运算可逐分量进行。零向量没有确定方向，不可作为方向向量使用。

#### 3.4 向量在立体几何中的应用

直线方向向量可表示其方向；平面法向量垂直于平面内所有方向。直线方向向量与平面法向量点积为0时直线方向平行于平面；若方向向量与法向量平行，则直线垂直于平面。两个平面法向量平行可判定平面平行或重合，还需结合点的位置区分。

空间角与距离计算：直线夹角由方向向量求；两平面夹角由法向量求锐角；点到平面距离若平面方程为 `Ax+By+Cz+D=0`，则为 `|Ax₀+By₀+Cz₀+D|/√(A²+B²+C²)`。夹角使用绝对值取锐角时，要按题意区分方向角与无向角。

### 第四章 数学建模活动（三）

建模过程包括明确问题与目标、选择变量并作合理假设、建立数学关系、求解、将结果还原到情境检验、解释模型误差和适用范围。结论必须附带变量定义、单位和假设；模型预测超出数据区间时属于外推，可靠性通常低于观测范围内的插值。

### 第五章 计数原理

#### 5.1 分类加法与分步乘法

完成一件事有互斥的若干类别时，把各类方法数相加；完成一件事须连续完成若干步骤时，把每步方法数相乘。先辨认“分类完成”还是“分步骤完成”，不能仅看题目出现“或者/并且”字面。

例：从3种饮料或4种点心中任选一种，有 `3+4=7` 种；先选1种饮料再选1种点心，有 `3×4=12` 种搭配。

#### 5.2 排列与排列数公式

从 `n` 个不同元素中取 `m` 个并按顺序排列，排列数 `A(n,m)=n!/(n−m)!`，其中 `0≤m≤n`、`0!=1`。顺序不同算不同结果。

#### 5.3 组合与组合数公式

从 `n` 个不同元素中取 `m` 个，不考虑顺序，组合数 `C(n,m)=n!/[m!(n−m)!]`。有 `A(n,m)=C(n,m)m!`；`C(n,m)=C(n,n−m)`。

#### 5.4 二项式定理

`(a+b)^n=Σ[k=0..n] C(n,k)a^(n−k)b^k`，适用于非负整数 `n`。第 `k+1` 项系数为 `C(n,k)`；展开前检查指数和是否为 `n`，并注意一般项中 `a` 的指数递减、`b` 的指数递增。

### 第六章 概率

#### 6.1 条件概率

在事件 `B` 已发生且 `P(B)>0` 的条件下，事件 `A` 的概率为 `P(A|B)=P(A∩B)/P(B)`。条件改变了样本空间，分母应为条件事件 `B` 的概率，不是原总体结果数。

#### 6.2 事件的独立性

事件 `A、B` 独立当且仅当 `P(A∩B)=P(A)P(B)`。独立不等于互斥：若两个正概率事件互斥，则它们不独立。重复试验只有在每次试验相互独立且概率保持不变时，才能直接使用二项分布。

#### 6.3 全概率公式

若 `B₁,…,Bₙ` 两两互斥且并为样本空间，且 `P(Bᵢ)>0`，则 `P(A)=ΣP(Bᵢ)P(A|Bᵢ)`。分组事件必须穷尽且互斥，避免漏项或重复计算。

#### 6.4 离散型随机变量及其分布列

随机变量 `X` 把随机试验结果对应为实数。分布列列出各取值 `xᵢ` 与概率 `pᵢ`，满足 `pᵢ≥0` 且 `Σpᵢ=1`。期望 `E(X)=Σxᵢpᵢ`，方差 `D(X)=Σ[xᵢ−E(X)]²pᵢ`。

#### 6.5 二项分布与超几何分布

若 `X~B(n,p)`，表示 `n` 次独立伯努利试验中成功次数，`P(X=k)=C(n,k)p^k(1−p)^(n−k)`，`k=0,…,n`；期望 `np`，方差 `np(1−p)`。不放回抽样会使各次结果相关，不能把超几何问题直接当二项分布。

#### 6.6 正态分布

正态分布 `N(μ,σ²)` 的密度曲线关于 `x=μ` 对称，`μ` 决定中心位置，`σ` 决定离散程度。标准化 `Z=(X−μ)/σ` 后服从标准正态分布 `N(0,1)`。曲线下总面积为1；连续型随机变量在单点处概率为0，区间概率由对应面积表示。

### 第七章 统计案例

#### 7.1 一元线性回归

样本点近似呈线性趋势时，可用 `ŷ=a+bx` 拟合，其中 `b` 表示 `x` 每增加1单位时预测的 `y` 变化量，`a` 为截距。最小二乘法选择使残差平方和 `Σ(yᵢ−ŷᵢ)²` 最小的直线。回归是基于样本的预测，不能证明因果关系。

#### 7.2 成对数据的线性相关性

相关系数 `r` 衡量线性相关方向和强弱，`−1≤r≤1`。正负号表示方向，绝对值越接近1表示线性相关越强；`r≈0` 只表示线性相关弱，仍可能存在非线性关系。相关不等于因果。

#### 7.3 独立性检验

列联表记录两个分类变量的联合频数。卡方统计量通过观察频数与独立假设下期望频数的差异判断关联证据强弱。检验结论是基于样本和显著性水平的统计判断，不是绝对证明；期望频数过小时，近似检验的可靠性会下降。

## 三、必备知识点

- 直线方程的选择由已知信息决定；竖直线单独写 `x=x₀`，不可使用有限斜率公式。
- 圆的一般式通过配方读出圆心、半径；半径平方非正时不表示实圆。
- 椭圆满足 `c²=a²−b²`，双曲线满足 `c²=a²+b²`；先识别正项与长/实轴方向。
- 抛物线焦点与准线由所用标准方程参数约定决定，`2p` 与 `4a` 形式不可混套。
- 空间向量坐标运算逐分量进行；数量积为0判垂直，方向向量与法向量关系判直线面垂直/平行。
- 计数先判断分类还是分步，再判断是否考虑顺序；有序选取用排列，无序选取用组合。
- 条件概率的分母是条件事件概率；二项分布要求独立且同概率；不放回抽样一般非独立。
- 统计关联只说明样本中的关联证据，不自动推出因果。

## 五、必备单词/术语

| 术语 | 准确含义与使用边界 |
|---|---|
| 斜率 | 直线方向变化率；竖直直线斜率不存在 |
| 焦点、准线、离心率 | 圆锥曲线定义中的定点、定线及比例参数；不同曲线的参数关系不同 |
| 方向向量、法向量 | 分别沿直线方向、垂直平面；零向量不能确定方向 |
| 排列、组合 | 排列考虑顺序，组合不考虑顺序 |
| 条件概率 | 已知某事件发生后的条件样本空间上的概率 |
| 独立事件 | 联合概率等于边缘概率乘积；与互斥含义不同 |
| 随机变量期望、方差 | 分别表示概率加权平均和围绕期望的平方偏差平均 |
| 相关、回归 | 相关刻画线性联系，回归用于拟合预测；二者均不能单独证明因果 |

## 六、熟记内容

- 椭圆：`c²=a²−b²`；双曲线：`c²=a²+b²`；离心率均为 `e=c/a`，但椭圆 `0<e<1`、双曲线 `e>1`。
- 平面向量垂直：点积为0；空间点到平面的距离：代入平面一般式后取绝对值并除以法向量长度。
- `A(n,m)=C(n,m)m!`；`C(n,m)=C(n,n−m)`。
- 条件概率乘法关系：`P(A∩B)=P(B)P(A|B)`；独立时等于 `P(A)P(B)`。
- 二项分布的均值为 `np`，方差为 `np(1−p)`。

## 七、易错点与掌握边界

| 易错点 | 正确边界 |
|---|---|
| 把斜率公式套到竖直直线 | 竖直线写 `x=x₀`，斜率不存在 |
| 将圆锥曲线的焦距关系互换 | 椭圆用差，双曲线用和：`c²=a²−b²` vs. `c²=a²+b²` |
| 把双曲线渐近线当作曲线交点 | 渐近线描述趋近方向，通常不与双曲线相交 |
| 认为空间向量平行即可推出直线重合 | 还需检验两直线是否有公共点；法向量平行也只能说明平面平行或重合 |
| 不分顺序套排列或组合 | 先定义一个结果是否因顺序不同而不同 |
| 将互斥事件理解为独立事件 | 正概率互斥事件不独立；独立看概率乘积条件 |
| 无放回重复抽样套用二项分布 | 二项分布需要独立同概率，非独立抽样应考虑超几何模型 |
| 把相关性解释为因果关系 | 相关/回归只反映样本关系；因果需额外设计或证据支持 |

## 八、综合应用示例

**例：**从编号 `1,2,3,4,5` 的5张卡片中不放回抽取2张，组成一个两位数。求组成偶数的概率，并说明为什么不能直接使用二项分布。

**解：**先确定基本结果等可能且有序。总结果数为 `A(5,2)=5×4=20`。偶数个位只能是2或4，有2种选法；确定个位后，十位从其余4张中选，故有利结果数 `2×4=8`。概率为 `8/20=2/5`。两次抽取不放回，第二张可选号码受第一次结果影响，试验不独立，因此不能把“每位为偶数”的事件按独立伯努利试验处理。
