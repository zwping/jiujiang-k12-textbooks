# 高中综合复习阶段全年学习汇总

本篇不把基础阶段和方向阶段的内容重复抄成第三套笔记，而是说明两者的依赖关系，并选取需要贯通使用的知识、条件和易错边界。基础阶段包含22册必修，方向阶段包含27册选择性必修；教材及单本笔记配对清单分别见[基础阶段汇总](<./01-基础阶段-全年汇总.md>)和[方向阶段汇总](<./02-方向阶段-全年汇总.md>)。

## 一、复习范围与阶段衔接

| 科目 | 基础阶段必修形成的工具 | 方向阶段选择性必修的推进 | 复习时要贯通的主线 |
|---|---|---|---|
| 语文 | 现代文、古诗文、文言、实用阅读与表达方法 | 革命/理论文本、制度与文化专题、古典诗歌源流、科学论述 | 观点和主题必须由原文证据、结构和语境支撑 |
| 数学 | 集合逻辑、不等式、函数、三角、向量、统计概率 | 解析几何、空间向量、计数概率统计、数列与导数 | 定义条件→表示/运算→性质推导→模型解释 |
| 英语 | 句子结构、词汇语法、主题读写与基础交际 | 复杂句、科学/环境/职业等议题，综合读写和正式文体 | 语法结构服务语义，词汇搭配和证据决定表达精度 |
| 思想政治 | 社会主义发展、经济制度、政治制度、哲学与文化 | 国际关系、法律生活、逻辑与创新思维 | 先辨主体及权责，再用概念解释材料事实和制度关系 |
| 历史 | 中国与世界通史的时序、制度变化和重大转折 | 政治治理、经济生活、文化传播的专题比较 | 通史提供时空背景，专题史比较机制并以史实作证 |
| 地理 | 自然地理过程与人口、城镇、产业等人文基础 | 自然地理深化、区域发展、资源环境与国家安全 | 从过程机制转向区域差异、联系和治理方案 |
| 物理 | 运动、相互作用、能量、电场、电路和电磁感应初步 | 动量、振动波光、电磁深入、热学、量子与原子核 | 选系统、定方向、识别模型边界，再守恒或列方程 |
| 化学 | 物质分类、离子氧化还原、元素周期、反应和基础有机 | 反应原理、微观结构、系统有机合成 | 结构/反应事实→守恒与模型→条件控制→实验验证 |
| 生物学 | 细胞、分子、代谢、遗传与进化 | 稳态调节、生态系统、生物技术工程 | 结构功能与遗传信息是分析调节、生态和工程的根基 |

## 二、必备知识点：把基础工具用于专题

### 语文

阅读综合题先准确界定文本对象和问题，再从具体词句、叙述顺序、论证材料或舞台行动取证。基础阶段的文言词义和古诗意象能力，在方向阶段转为比较《论语》《大学》《老子》《兼爱》等思想命题、史传人物与作者评价，以及《诗经》《楚辞》至唐宋诗词的体式和情感差异。理论文章要复原“概念—前提—推论—结论”；报告文学的数据和细节承担事实依据；文学作品的象征、留白和叙述视角不能脱离全文任意发挥。答题结论须能指出原文证据及其作用。

### 数学

基础阶段的函数、三角、向量和概率语言分别延伸为：导数研究函数局部变化与最优化；向量坐标和数量积发展为空间位置关系与距离角度；平面坐标方法进入直线、圆、圆锥曲线；样本空间和独立性进入计数、条件概率、随机变量分布和统计推断。数列描述离散序列，函数描述一般变量对应，两者可在递推和建模中联系但不可混称。统计的样本关联不能直接证明因果，需说明抽样和推断条件。每题书写顺序为确定对象/定义域、列明已知条件、选公式或定理、推导并核验边界。

### 英语

基础阶段的句子成分、定语从句、被动语态和非谓语，是选择性必修复杂读写的结构基础。综合阅读时先定位主句谓语、从句边界及逻辑连接，再辨认事实、观点、推测和限制语；写作按受众选文体：科学报道交代数据和因果，议论文安排主张—证据—解释—限制，求职信逐项回应职位要求。`The evidence suggests ...`表示证据提示而非绝对证明；`must`可表达强义务或有把握推断，语气需由上下文判断。过去完成时和过去完成时被动须有过去参照点，完成进行时强调过程延续。

### 思想政治

必修建立的经济、政治和哲学概念在选择性必修中用于更精确地分析国际事务、民事生活和推理。国际关系题分别识别国家主体、主权/国家利益、共同利益及制度规则；法律案例依“法律关系主体—事实行为—权利义务—责任/救济”分析；逻辑题则把概念界定、判断真假、推理形式和论证前提分开。材料中出现“政府、人大、政协、法院、基层自治组织”时先核对主体法定职权，避免把建言、自治协商、行政决定和司法裁判混为一类。

### 历史

通史时间线定位事件的时代背景，专题史再比较制度和社会机制。分析官员选拔、法律教化、赋税或基层治理时，须指出谁制定规则、谁执行、影响哪些群体；分析工业技术和交通时，区分技术出现、规模应用及其对生产劳动和日常生活的后续影响；分析文化传播时，追踪载体、传播路线、接受者与本地改造。史料结论应标明史料类型、形成时间及其能证明的范围；后来的结果不能反向当作行动者当时已知的必然结局。

### 地理

基础自然地理中的能量、水分和地貌过程，为选择性必修的天气气候、水体、地表形态和自然环境整体性提供机制；人文地理的人口、产业、城镇和交通概念进一步用于区域发展。答区域题依次查位置与自然基础、人口/产业、交通联系、资源环境约束，再评估方案的受益者、代价及时间尺度。资源安全不等于“本地有资源”，还要看供给稳定、技术可得、运输通道、替代能力和生态承载力；区域治理需说明跨区域影响与协作机制。

### 物理

基础力学的系统和受力图贯通动量、碰撞及振动；能量方法可对照热力学第一定律，但力学机械能与热力学内能不是同一物理量。电场、电路和磁场基础延伸到洛伦兹力、感应、电磁波和交流电：磁力可改变运动方向，不能改变粒子动能；磁通量改变才产生感应电动势。实验先确定研究对象、控制变量和测量误差，再解释斜率/截距的物理意义。微观部分连接温度与分子运动、光子能量、原子能级和核结合能；用理想气体、光电效应等模型时保留各自假设。

### 化学

必修阶段的元素价态、离子反应和守恒律支撑选择性必修的热化学、电离平衡和电化学定量；物质结构专题解释元素周期性、键型、空间构型和晶体宏观性质；有机专题则从官能团和碳骨架预测反应，再以实验现象验证。化学平衡题先写反应方程式和计量数，再列$Q/K$、温度和浓度条件；电化学题先判断装置类型和氧化还原，再定位电极反应；有机合成需检查原子守恒、官能团转化、反应条件及副产物。

### 生物学

细胞膜运输、酶、ATP、呼吸和光合作用构成能量与物质基础；遗传信息从DNA复制、转录、翻译进入性状，再由基因频率和自然选择解释群体演化。选择性必修把此基础扩展到稳态反馈、神经/体液/免疫调节、种群群落生态和工程技术。实验分析应区分处理变量、响应变量、无关变量和对照；相关变化不能直接证明因果。工程题沿“生物原理—操作流程—筛选/检测—功能证据—安全与伦理”解释，PCR条带、标记基因或产量变化均需说明各自证据能力边界。

## 三、必备公式/定理与条件

| 学科 | 关系式/规则 | 条件和解题边界 |
|---|---|---|
| 数学 | $f'(x)=\lim_{h\to0}\frac{f(x+h)-f(x)}h$；若区间内$f'(x)>0$则$f$递增 | 导数存在的区间内使用；极值还需比较临界点与定义域边界。 |
| 数学 | 椭圆$c^2=a^2-b^2$；双曲线$c^2=a^2+b^2$ | 标准方程参数定义下使用，勿互换；渐近线不等于双曲线交点。 |
| 数学 | $P(A\mid B)=P(A\cap B)/P(B)$；独立时$P(A\cap B)=P(A)P(B)$ | $P(B)>0$；独立需要独立性证据/模型前提，不能由互斥推出。 |
| 物理 | $\sum\vec p_{初}=\sum\vec p_{末}$ | 系统合外力冲量为零或可忽略；动能只在弹性碰撞中守恒。 |
| 物理 | $\lvert\mathcal E\rvert=N\lvert\Delta\Phi/\Delta t\rvert$；$P_{损}=I^2R$ | 前式由磁通量变化率决定；后式表示线路焦耳损耗，升压降低电流可减小损耗。 |
| 物理 | $pV/T=常量$；$\Delta U=Q+W$ | 一定质量理想气体，$T$用K；$W$正负依明确约定，本套单本笔记取外界对系统做功为正。 |
| 化学 | $Q<K$反应向正向推进，$Q>K$向逆向推进；$Q=K$为平衡 | 反应商和平衡常数表达式使用一致；温度变化会改变$K$，催化剂不会。 |
| 化学 | $\Delta G=\Delta H-T\Delta S$ | 恒温恒压方向判断；$\Delta G<0$表示正向自发，不表示反应速率快。 |
| 化学 | $K_w=[H^+][OH^-]$；$pH=-\lg[H^+]$ | 稀水溶液近似；$K_w$随温度改变，不能把pH=7当作任意温度中性的定义。 |
| 生物学 | $N\approx Mn/m$；能量传递效率$=下一营养级同化量/本级同化量\times100\%$ | 标记重捕需近似封闭和等捕获机会；能量比值同单位、同时间口径。 |
| 生物学 | $p+q=1$，$p^2+2pq+q^2=1$ | 双等位基因群体满足理想平衡条件时使用，不作为任意现实种群的必然比例。 |

语文、英语、思想政治和历史没有统一计算公式；其核心规则分别是文本证据与论证关系、语言结构和语义、主体权责与推理有效性、史实与时序因果。地理综合分析以具体区域过程和条件为依据，不用脱离区域的通用公式替代解释。

## 四、必备单词/术语

| 术语 | 中文释义 | 两阶段贯通时的用法 |
|---|---|---|
| 论证链 | 论点、证据、推理和结论的连接 | 语文理论文本、英语议论文、政治材料和历史解释都需检查证据是否支持结论。 |
| 定义域 | 函数允许输入的自变量集合 | 基础函数题先确立；导数最值和实际建模仍受原定义域约束。 |
| 离心率 | 圆锥曲线焦距与长半轴/实半轴之比 | $0<e<1$对应椭圆，$e>1$对应双曲线。 |
| 主体/职权 | 行使权利或承担职责的法律/制度主体及其权限 | 政治、法律生活题需区分党、人大、政府、政协、司法机关和自治组织。 |
| 史料实证 | 用可考察史料支撑历史结论的方法 | 结论不可超过史料形成背景、作者立场和材料覆盖范围。 |
| 区域整体性 | 区域自然、人文要素相互作用的特征 | 资源开发需把就业、交通、生态和上下游/周边影响一并考虑。 |
| 系统边界 | 分析中纳入的物体/过程集合 | 力学动量守恒、能量守恒和电路分析都先明确系统及外界作用。 |
| 反应商$Q$ | 任一时刻按平衡表达式计算的组成比 | 与$K$比较判断方向；不是平衡时才有的量。 |
| 负反馈 | 结果反向减弱引起变化的信号 | 血糖、甲状腺轴及生态调节需标出信号、效应和被调变量。 |
| 功能验证 | 检查遗传材料/技术操作是否产生预期生物学作用 | PCR阳性只能说明扩增到相关片段，仍需表达或功能实验。 |

## 五、熟记内容

- **语文**：经典篇目按单本笔记的背诵清单直接背诵原文及指定范围；复习理论文时复述核心概念及论据推导，小说/戏剧用“细节—人物选择—结构作用—主题证据”解释，禁止只背空泛主题标签。
- **数学**：圆锥曲线焦距关系、排列组合、条件概率、数列通项与求和、导数定义和单调性判据，全部连同条件记忆；复习函数题时主动核对定义域、端点和可行域。
- **英语**：主句与从句结构、被动时态、分词和非谓语功能按句义辨析；科学/环境观点表达采用“可核事实—解释—限定语”；正式申请材料逐条对应职位要求，避免只罗列形容词。
- **思想政治**：材料分析前标记行为主体、法定职责、权利义务、制度渠道和论证前提；国际关系以国家利益和国际规则分析，民事案件以事实—法律关系—责任分析。
- **历史**：能按通史时序定位方向阶段的制度、经济和文化专题；熟记“背景、制度机制、受影响群体、历史结果”四项比较维度，保留关键史料证据。
- **地理**：复述资源安全评价链“资源禀赋—供需—运输/技术—替代—生态代价—治理”；区域方案说明作用范围、短期/长期结果和跨区协作。
- **物理**：动量守恒、楞次定律、法拉第定律、理想变压器关系、热力学第一定律、光电方程和核反应质量数/电荷数守恒；每式都能说出物理量、单位、系统和适用条件。
- **化学**：平衡的动态本质、$Q/K$判向、温度与催化剂对平衡的区别、酸碱/溶度积条件、电极反应氧化还原方向；有机反应按结构、官能团、条件和产物闭合核对。
- **生物学**：反射弧和免疫基本路径、种群到生态系统层级、能量单向流动和物质循环、组织培养与基因工程流程；所有实验流程记住对照、无菌/变量控制和结果验证。

## 六、易错区分与综合自检

- “基础→方向”表示概念和方法逐步深化，不是所有学生必须完成每一本选择性必修；按学校选科及进度确定适用范围。
- 数学中相关与因果、驻点与极值、排列与组合、椭圆与双曲线参数式均须区分；不得只看符号外形套公式。
- 英语中的事实与推断、非限制性与限制性从句、过去参照与现在参照不能互换；语法形式应由时间和语义决定。
- 政治的制度目标、法定主体和材料事实不是同一层次；历史时间先后、相关关系和因果关系也不是同义词。
- 地理区域优势同时受环境承载力和联系条件制约；单项资源丰富不能推出可持续发展或国家安全。
- 物理守恒定律必须指定系统；功、热量是过程量，内能是状态量；洛伦兹力不做功，动量守恒不等于机械能守恒。
- 化学自发性不等于速率；中性定义是$[H^+]=[OH^-]$；阳极氧化是共同规则，但原电池阳极为负、电解池阳极接电源正极。
- 生物稳态是动态相对稳定；生态$K$随环境变化；能量不循环；遗传比例和生态模型均受前提约束；检测到基因不等于证明功能。

检查一份综合答案时，逐条确认：对象和系统说清了吗？公式/概念的条件完整吗？证据来自可核内容吗？结论范围有没有超出证据？单位、时间、空间和法律主体是否一致？只要其中一项缺失，就补充条件或收窄结论。
