# 普通高中语文必修上册重点笔记

> 对应教材：普通高中教科书·语文必修上册
> 版本：统编版　|　学段：高中基础阶段

## 一、本册学习地图

### 本册到底教什么

- **教材主线**：本册从青春诗歌与小说、劳动者、古典诗歌、家乡文化、整本书阅读、说理文章和写景散文展开，建立高中语文的文学鉴赏、实用阅读、古诗文积累和研究性学习基础。
- **阅读能力**：从意象、人物、叙事、论点、论据、文言实词和写景结构等角度解读文本；能在整本书中建立概念、人物和观点网络。
- **表达任务**：诗歌创作、家乡文化调查、乡土中国阅读、词语积累、议论与写景表达。

| 单元 | 主要内容 | 本单元教会的知识 | 学完后的明确能力 |
|---|---|---|---|
| 第一单元 | 青春诗歌、小说 | 意象、叙事和青春价值 | 能赏析诗歌和小说形象 |
| 第二单元 | 劳动者、工匠与劳动诗 | 新闻/通讯、议论、古诗劳动书写 | 能写人物通讯式片段 |

## 二、目录与章节重点

### 第一单元：青春与文学

- **沁园春·长沙**：通过独立寒秋、湘江秋景、峥嵘岁月和问苍茫大地写青年革命者的胸襟与抱负；“万山红遍、层林尽染”由景入情，“谁主沉浮”转入责任。
- **立在地球边上放号、红烛、峨日朵雪峰之侧、致云雀**：分别以地球、红烛、雪峰和云雀为核心意象，表达创造、奉献、孤独中的坚持和对自由生命的赞美。
- **百合花**：以战争背景中的通讯员、新媳妇和“我”为叙述中心，借被子、馒头和百合花写军民真情与人性纯美。
- **哦，香雪**：香雪用四十个鸡蛋换铅笔盒，火车和铅笔盒象征现代文明与少女尊严，乡村环境和人物愿望相互映照。

### 第二至第三单元

- **喜看稻菽千重浪、心有一团火、探界者钟扬**：以通讯和典型事例写袁隆平、张秉贵、钟扬的劳动、责任和创新；人物通讯要有事实、细节和时代意义。
- **以工匠精神雕琢时代品质**：从工匠精神的内涵、现实价值和时代需要论证敬业、专注、创新；议论文要辨识观点和论据。
- **芣苢、插秧歌**：前者用复沓动词写采芣苢人数和劳动热情，后者用动作、环境和对话写插秧辛劳；古诗劳动书写重在动态和节奏。
- **短歌行、归园田居**：曹操以忧人生、求贤才表达建功愿望；陶渊明写归园田的宁静和远离尘俗。比较“入世抱负”和“归隐自守”。
- **梦游天姥吟留别**：梦境奇景、现实失意和“安能摧眉折腰”构成浪漫主义抗争；登高写杜甫身世、秋景和忧国伤己；琵琶行通过音乐描写和人物遭遇表达同病相怜。
- **念奴娇·赤壁怀古、永遇乐·京口北固亭怀古、声声慢**：分别写怀古豪情、忧国用典和个人愁苦；理解景物、典故与作者处境的联系。

### 第四至第八单元

- **家乡文化生活**：记录人物和地方、调查现状、提出建设建议；资料要有来源，调查要有对象、问题、记录和结论。
- **《乡土中国》**：重点概念有乡土本色、文字下乡、差序格局、礼治秩序、无讼、无为政治和长老统治；阅读要把概念、论据和现实例子对应起来。
- **劝学、师说**：荀子以学习和积累说明后天学习的重要性；韩愈以教师职责、师生关系和士大夫不从师批评社会风气。
- **反对党八股、拿来主义**：分别批评空话套话和对待文化遗产的错误态度；“破—立”结构、比喻和反语服务于论点。
- **读书：目的和前提、上图书馆**：从个人经历和文化空间讨论读书、求知和精神成长。
- **故都的秋、荷塘月色**：通过色彩、声音、光影和空间写景，景物选择与作者情绪一致。
- **我与地坛**：由地坛、母亲、时间和生命回忆思考苦难与生存；赤壁赋以主客问答写变与不变、人生有限与精神超越。
- **词语积累**：词语要放入语境判断感情色彩、适用对象、搭配和语体，不凭近义词字面替换。

## 三、必备知识点

- **诗歌鉴赏**：意象、意境、手法、情感、时代背景；典故要说明来源和在文本中的作用。
- **人物通讯**：事实真实、细节典型、结构清楚、人物与时代相连。
- **议论文**：中心论点、分论点、论据、论证方式、论证结构和语言特点。
- **整本书阅读**：概念表、人物表、论证链和现实联系四条线并读。
- **文言文**：通假、古今异义、一词多义、词类活用、特殊句式和文化语境。
- **词语使用**：辨析词义范围、感情色彩、搭配对象、语体和语境。

## 四、必备公式/定理

- **诗歌赏析规则**：意象/典故 + 画面 + 手法 + 情感 + 时代/人物处境。
- **人物通讯规则**：人物身份 + 典型事件 + 细节证据 + 精神品质 + 时代意义。
- **议论文规则**：论点 + 论据 + 论证方式 + 逻辑关系 + 结论。
- **文言翻译规则**：实词义项 + 虚词关系 + 活用还原 + 句式调整 + 语气。
- **词语辨析规则**：词义范围 + 感情色彩 + 搭配对象 + 语体 + 上下文。

### 默写标准

- 古诗词、文言文：写对篇名、作者或出处、原文、标点和易错字；文言句要能解释关键词。
- 现代文：严格按教材指定自然段背诵，能够复述段落内容、句间关系和关键表达作用。
- 每篇完成“背诵—遮挡默写—逐字核对—订正再写”四步；不会写的字单独列入错字表。


## 七、易错点与掌握边界
- 诗歌意象不能只翻译名词，要说明它在具体情境中的情感作用。
- 《乡土中国》的概念不能当作标签，必须说明概念内容、论据和现实例子。
- 议论文中“有道理”不等于“论证充分”，还要看论据与论点的对应关系。
- 文言“所以、师、假、而、之”等必须结合句法和语境判断。
- 词语辨析不能只看近义词词典，要看搭配对象、语体和褒贬色彩。

## 八、独立学习验收

- 能分析一首诗的意象、手法、情感和作者处境。
- 能用概念—论据—现实例子说明《乡土中国》中的一个概念。
- 能写一篇观点明确、论据充分的议论文。
- 能翻译重点文言句子并准确使用本册词语。
