## 一、本册学习地图

本册由哲学、社会历史与人生价值、文化三条相连主线组成。第一单元学习唯物论和辩证法，回答世界是什么、怎样变化；第二单元学习认识论和历史唯物主义，回答认识怎样形成、社会怎样发展、人生价值怎样实现；第三单元转向文化的功能、传承、交流和发展。哲学原理须结合条件分析，文化判断须区分事实、评价与规范主张。

| 单元 | 知识主线 | 核心应用 |
|---|---|---|
| 探索世界与把握规律 | 哲学基本问题、物质运动、联系发展和矛盾 | 用客观规律、联系、发展和矛盾分析现象 |
| 认识社会与价值选择 | 实践认识、社会发展、人民群众、价值实现 | 解释认识来源、社会变迁和人生选择 |
| 文化传承与文化创新 | 文化功能、传统文化、文化交流与发展 | 分析文化传承、借鉴和创新的关系 |

## 二、目录与章节重点

### 第一单元 探索世界与把握规律

#### 第一课 时代精神的精华

- **追求智慧的学问**：哲学是关于世界观的学问，是系统化、理论化的世界观；世界观决定方法论，方法论体现世界观。哲学不是零散常识，也不能代替各门具体科学；具体科学提供材料，哲学对具体科学作概括和指导。
- **哲学的基本问题**：思维和存在的关系问题，包含何者为本原、思维能否正确认识存在两个方面。唯物主义认为物质是本原，唯心主义认为意识是本原；可知论承认思维能够正确认识存在。辨认派别要看其对本原问题的回答。
- **科学的世界观和方法论**：马克思主义哲学实现了唯物主义与辩证法、唯物辩证的自然观与历史观的统一，是科学的世界观和方法论；其中国化时代化成果把基本原理同中国具体实际相结合。

#### 第二课 探究世界的本质

- **世界的物质性**：物质是不依赖于人的意识、并能为人的意识所反映的客观实在。自然界独立于人的意识存在；人类社会是物质世界长期发展的产物，其存在发展受物质生活条件制约。
- **运动的规律性**：运动是物质的根本属性和存在方式，物质是运动的承担者；运动与静止相互区别又相互联系。规律是事物运动过程中固有的、本质的、必然的、稳定的联系，具有客观性和普遍性。
- 意识是人脑对客观存在的反映，具有目的性、自觉选择性和能动创造性。正确发挥主观能动性必须尊重客观规律；夸大意识作用会陷入唯意志论，否认意识作用则会陷入机械论。

#### 第三课 把握世界的规律

- **世界是普遍联系的**：联系是事物之间及其内部要素之间相互影响、相互制约的关系，具有普遍性、客观性、多样性。联系有条件；分析问题要从整体出发统筹全局，也要关注关键部分对整体的影响。普遍联系不等于任何两事物都有直接联系。
- **世界是永恒发展的**：发展是事物的前进和上升，是新事物产生、旧事物灭亡。新事物符合客观规律、具有强大生命力和远大前途；判断新旧不能只看出现时间或表面形式。量变是数量增减或场所变更，质变是根本性质变化；量变积累到一定程度会引起质变，质变又开启新的量变。
- **唯物辩证法的实质与核心**：矛盾是事物发展的源泉和动力，具有同一性和斗争性。矛盾普遍性要求承认和分析矛盾，特殊性要求具体问题具体分析；普遍性与特殊性相互联结。主要矛盾影响事物发展进程，主要方面影响事物性质，须结合具体阶段辨认主次。

#### 综合探究 坚持唯物辩证法 反对形而上学

形而上学孤立、静止、片面地看问题；唯物辩证法从联系、发展和矛盾角度分析。面对“某政策解决了一个问题”的论断，还要检查它同其他领域的联系、实施阶段和矛盾主次变化，避免用单一因素代替整体评价。

### 第二单元 认识社会与价值选择

#### 第四课 探索认识的奥秘

- **人的认识从何而来**：实践是人们改造客观世界的物质性活动，具有客观物质性、主观能动性、社会历史性。实践是认识的来源、认识发展的动力、检验认识真理性的唯一标准，也是认识的目的。学习可获得间接经验，但其根本来源仍是实践。
- **在实践中追求和发展真理**：真理是对客观事物及其规律的正确反映，具有客观性；真理是具体的、有条件的，超出适用条件可能转化为谬误。认识具有反复性、无限性和上升性，实践发展推动认识深化，认识还须回到实践指导行动。

#### 第五课 寻觅社会的真谛

- **社会历史的本质**：社会生活在本质上是实践的。社会存在是社会生活的物质方面，社会意识是精神方面；社会存在决定社会意识，社会意识具有相对独立性并能反作用于社会存在。
- **社会历史的发展**：生产力与生产关系、经济基础与上层建筑的矛盾运动推动社会发展。生产关系一定要适合生产力状况、上层建筑一定要适合经济基础状况，是社会发展的基本规律。阶级社会的基本矛盾通过阶级斗争解决；社会主义社会通过改革解决发展中的体制机制问题。
- **社会历史的主体**：人民群众是社会历史的主体，是社会物质财富和精神财富的创造者，是社会变革的决定力量。群众观点和群众路线要求从群众实践和利益出发、依靠群众并接受群众检验；个别人物的作用不能代替人民群众的历史作用。

#### 第六课 实现人生的价值

- **价值与价值观**：哲学意义上的价值是客体对主体需要的积极意义；人的价值主要在于通过劳动和贡献满足社会、他人需要，也体现在社会承认和个人发展中。价值观是对事物价值的总的看法和根本观点，对认识和行为具有导向作用。
- **价值判断与价值选择**：价值判断是在事实判断基础上作出的价值评价，价值选择是在判断基础上的行为取舍。正确判断应遵循社会发展客观规律，站在最广大人民立场上，并统筹个人、他人和社会利益。
- **价值的创造和实现**：人在劳动和奉献中创造价值，在个人与社会统一中实现价值，并通过砥砺自我、增长才干和坚定理想实现人生价值。社会提供客观条件，个人努力发挥主观作用；不能把个人成就完全归因于个人或社会单方。

#### 综合探究 坚持历史唯物主义 反对历史虚无主义

评价历史人物和社会制度应依据具体历史条件、社会关系和实践结果，既避免脱离背景作道德化判断，也避免以个别现象否定整体历史进程。历史材料须辨明来源、时间和语境，史实判断与价值评价分开论证。

### 第三单元 文化传承与文化创新

#### 第七课 继承发展中华优秀传统文化

- **文化的内涵与功能**：文化是相对于经济、政治而言的人类全部精神现象，包含意识形态性质的内容，也包含自然科学和技术等非意识形态内容。文化由人创造并通过实践传播，具有引领风尚、教育人民、服务社会、推动发展的功能；文化影响人的交往行为、认识活动和实践活动。
- **正确认识中华传统文化**：中华优秀传统文化源远流长、博大精深，形成于中华民族长期实践。对传统文化要取其精华、去其糟粕，批判继承、古为今用；传统文化兼具历史价值与历史局限，不能全盘肯定或否定。
- **弘扬中华优秀传统文化与民族精神**：创造性转化是把有借鉴意义的传统内涵改造为符合当代特点的表达；创新性发展是拓展、完善传统文化内涵。中华民族精神以爱国主义为核心，包含伟大创造、奋斗、团结、梦想精神，并随时代发展而丰富。

#### 第八课 学习借鉴外来文化的有益成果

- **文化的民族性与多样性**：民族文化是民族区别于其他民族的独特标识，受经济、政治、历史和地理条件影响。文化多样性是人类社会基本特征和文化创新的重要基础；尊重差异不意味着放弃民族文化主体性。
- **文化交流与文化交融**：交流推动文化传播和相互理解；交融推动借鉴吸收、丰富本民族文化。交流不等于同化，交融不意味着文化差异消失。
- **正确对待外来文化**：面向世界、博采众长，立足国情，坚持以我为主、为我所用；吸收外来文化有益成果须经辨析和实践检验。文化发展不能全盘西化，也不能封闭排外。

#### 第九课 发展中国特色社会主义文化

- **文化发展的必然选择**：中国特色社会主义文化植根于中国特色社会主义伟大实践，源自中华优秀传统文化，熔铸于革命文化和社会主义先进文化。坚持马克思主义指导，坚持为人民服务、为社会主义服务，坚持百花齐放、百家争鸣。
- **文化发展的基本路径**：坚定理想信念、坚持以人民为中心；立足时代之基、回答时代问题；融通不同资源、实现综合创新。评价文化产品要看其是否回应人民精神文化需求、是否经得起实践和社会评价。
- **文化强国与文化自信**：文化自信是对自身文化价值的充分肯定和对文化生命力的坚定信念。建设文化强国要弘扬主旋律、传播正能量，发展文化事业和文化产业，提升公共文化服务及传播能力；文化自信不等于排斥外来文化。

#### 综合探究 坚持以马克思主义为指导 发展中国特色社会主义文化

分析文化现象时，区分文化事实、价值评价和发展路径；确认文化内容源自何种实践，判断其社会功能，再说明如何传承、借鉴或创新。评价传统文化要同时考虑历史语境和当代价值。

## 三、必备知识点

- 哲学基本问题是思维和存在的关系问题；物质决定意识，意识对物质有能动作用，正确发挥作用须尊重规律。
- 联系具有普遍性、客观性、多样性；发展是新事物产生、旧事物灭亡；矛盾分析要区分普遍性、特殊性、主要矛盾和主要方面。
- 实践是认识的基础；真理具有客观性、具体性和条件性，认识在实践中反复、无限、上升发展。
- 社会存在决定社会意识；社会基本矛盾运动推动社会发展，人民群众是历史主体。
- 正确价值判断和选择应遵循规律、站稳人民立场；价值在劳动奉献、个人与社会统一、砥砺自我中实现。
- 传统文化要批判继承、创造性转化和创新性发展；借鉴外来文化要立足国情、以我为主、为我所用。

## 四、必备公式/定理

本册无计算公式。唯物辩证分析可依次检查客观事实与条件、主要矛盾及其主要方面、联系和发展变化，再形成有条件的结论；此为思考路径，不是替代论证的固定答案。

## 五、必备单词/术语

| 术语 | 确切含义 | 易混边界 |
|---|---|---|
| 世界观 | 人们对整个世界及人与世界关系的总的看法和根本观点 | 哲学是系统化、理论化的世界观 |
| 规律 | 事物运动过程中固有的、本质的、必然的、稳定的联系 | 人能认识和利用规律，不能创造或消灭客观规律 |
| 实践 | 人们改造客观世界的物质性活动 | 纯粹思考不是实践，实践具有直接现实性 |
| 真理 | 对客观事物及其规律的正确反映 | 真理具体、有条件，不表示所有观点都正确 |
| 社会存在 | 社会生活的物质方面 | 生产方式是社会存在和发展的基础 |
| 价值判断 | 对事物能否满足主体需要及其意义作出的评价 | 应建立在事实判断上并说明评价标准 |
| 文化交融 | 不同文化相互借鉴吸收并丰富发展的过程 | 不等于文化同化或差异消失 |
| 创造性转化 | 将传统文化有借鉴意义的内涵改造为符合当代特点的表达 | 着重表达形式和实现方式适应当代 |
| 创新性发展 | 对传统文化内涵加以补充、拓展和完善 | 着重丰富发展文化内涵 |

## 六、熟记内容

- 哲学基本问题是思维和存在的关系问题，包含何者为本原、思维能否正确认识存在两个方面。
- 实践是认识的来源、发展动力、检验认识真理性的唯一标准和认识的目的。
- 社会存在决定社会意识；生产力与生产关系、经济基础与上层建筑的矛盾运动推动社会发展。
- 正确价值判断和价值选择应自觉遵循社会发展客观规律，自觉站在最广大人民立场上。
- 中华民族精神以爱国主义为核心，包含伟大创造、奋斗、团结、梦想精神。

## 七、易错点与掌握边界

| 易错理解 | 正确结论 |
|---|---|
| 意识能动作用意味着可随意改变规律 | 意识作用以尊重客观规律和客观条件为前提 |
| 联系普遍意味着任意两事物都有直接联系 | 联系有条件，具体联系须由事实证明 |
| 量变必然立即发生质变 | 量变积累到一定程度才引起质变，适度量变不改变根本性质 |
| 真理具体有条件就意味着真理是主观的 | 真理内容客观，适用范围和条件具体 |
| 社会意识总是落后于社会存在 | 社会意识有相对独立性，可能先于或落后于社会存在变化 |
| 尊重传统等于全盘接受 | 要区分精华与糟粕，批判继承并结合当代实践发展 |
| 文化自信意味着拒绝外来文化 | 文化自信与开放交流相容，借鉴须辨析并立足自身实践 |

## 八、综合应用示例

某地把传统节庆民俗改编为面向青少年的公共文化活动。先指出节庆习俗属于文化事实；再分析活动保留了哪些传统内涵、采用了哪些当代表达方式；最后依据参与反馈和文化教育功能评价效果。若只是更换舞台包装而未传递原有文化意义，不能据此认定实现了有效传承。
