# 思想政治必修2《经济与社会》重点笔记

> 对应教材：[普通高中教科书·思想政治必修2《经济与社会》](<09-思想政治-普通高中教科书·思想政治必修2 经济与社会.pdf>)｜本册70页

## 一、本册学习地图

本册解释我国经济制度如何组织生产、市场与政府怎样配置资源、发展方式如何转向高质量，以及收入如何分配、社会保障怎样发挥作用。第一单元从所有制基础进入市场经济体制；第二单元从发展理念进入收入分配和社会保障。分析经济现象时，区分制度安排、主体行为、运行机制和结果，避免把一个现象归因于单一因素。

| 课次 | 本课知识主线 | 学完能够解释 |
|---|---|---|
| 第一课 | 公有制为主体、多种所有制经济共同发展；坚持“两个毫不动摇” | 所有制结构与不同所有制经济的功能 |
| 第二课 | 市场配置资源；政府宏观调控 | 市场机制、市场失灵及政府作用 |
| 第三课 | 新发展理念；现代化经济体系 | 高质量发展需要解决的结构性问题 |
| 第四课 | 个人收入分配；社会保障 | 收入来源差异及社会保障的调节功能 |

## 二、目录与章节重点

### 第一单元 生产资料所有制与经济体制

#### 第一课 我国的生产资料所有制

- **公有制为主体**：公有制经济包括国有经济、集体经济以及混合所有制经济中的国有成分和集体成分。公有制主体地位体现在公有资产在社会总资产中占优势（这是就全国而言，有的地方、有的产业可以有所差别），国有经济控制国民经济命脉、对经济发展起主导作用。国有经济的主导作用主要体现在控制力，不等于国有经济在每个行业都占数量优势。
- **多种所有制经济共同发展**：非公有制经济包括个体经济、私营经济、外资经济等，是社会主义市场经济的重要组成部分。非公有制经济在支撑经济增长、促进创新、扩大就业、增加税收等方面发挥作用。公有制经济与非公有制经济依法平等使用生产要素、公平参与市场竞争、同等受到法律保护。
- **基本经济制度**：公有制为主体、多种所有制经济共同发展，按劳分配为主体、多种分配方式并存，社会主义市场经济体制，构成社会主义基本经济制度的重要内容。生产资料所有制决定社会基本经济制度的基础，也影响生产、交换、分配和消费。

#### 第一课 坚持“两个毫不动摇”

- 毫不动摇巩固和发展公有制经济，需要深化国有企业改革、完善中国特色现代企业制度，推进国有经济布局优化和结构调整；发展壮大农村集体经济要完善农村基本经营制度、发展新型农村集体经济。
- 毫不动摇鼓励、支持、引导非公有制经济发展，要求营造公平竞争环境、依法保护产权和企业家权益、完善融资等支持政策，同时引导企业守法经营、诚信经营、承担社会责任。
- 企业经营成功受多种因素影响：制定正确经营战略、提高自主创新能力、依靠技术进步和科学管理形成竞争优势、诚信经营树立信誉。市场竞争激烈或外部环境变化时，经营者还须依法防范风险。

#### 第二课 使市场在资源配置中起决定性作用

- 资源有限而需求多样，需要通过配置实现资源有效利用。计划和市场是资源配置的两种基本手段；市场通过价格、供求和竞争机制引导资源流动。价格上涨通常会引导供给增加、需求减少，价格下降通常会产生相反激励，但实际反应受成本、替代品、预期等条件影响。
- 市场配置资源具有及时反映供求变化、激励竞争和提高效率等优点；市场调节也存在自发性、盲目性、滞后性，可能造成垄断、公共物品供给不足、外部性和信息不对称等问题，因此不能把市场机制等同于万能机制。
- 统一开放、竞争有序的市场体系需要完善市场规则，规范市场准入、竞争和交易秩序，反对地方保护、垄断和不正当竞争；经营主体须遵守法律法规和商业道德，消费者依法维护权益。

#### 第二课 更好发挥政府作用

- 社会主义市场经济体制把社会主义制度与市场经济结合起来：市场在资源配置中起决定性作用，政府实行科学宏观调控、有效政府治理，弥补市场调节不足并维护公平竞争。
- 宏观调控主要目标包括促进经济增长、增加就业、稳定物价、保持国际收支平衡；常用经济手段包括财政政策和货币政策，也可依法使用必要的行政手段。选择工具要根据经济运行状态，不能把某项政策工具说成任何时期都同向、同强度使用。
- 政府通过发展战略和规划、市场监管、公共服务、环境保护等履行经济职能。有效治理应依法行政、尊重市场规律、保持政策连续性并提高政策协同，避免越位、缺位或以行政命令替代市场主体决策。

#### 综合探究 加快完善社会主义市场经济体制

完善体制要同时处理有效市场与有为政府的关系：市场竞争形成效率和创新激励，政府维护规则、弥补市场失灵、提供公共服务。观察某项改革时，可依次确认资源配置中存在的问题、市场机制能解决的部分、公共治理需补足的部分，再检查政策是否符合公平竞争和法治原则。

### 第二单元 经济发展与社会进步

#### 第三课 坚持新发展理念

- 创新发展解决发展动力问题；协调发展解决发展不平衡问题；绿色发展解决人与自然和谐共生问题；开放发展解决内外联动问题；共享发展解决社会公平正义问题。五大发展理念相互贯通，不能将某一理念简化为单一指标。
- 高质量发展以新发展理念为引领，要求发展方式、经济结构和增长动力转变，推动质量变革、效率变革、动力变革。增长速度本身不能代表发展质量；评价发展要结合创新能力、资源环境、区域协调、民生改善等维度。

#### 第三课 建设现代化经济体系

- 现代化经济体系包括创新引领、协同发展的产业体系，统一开放、竞争有序的市场体系，体现效率、促进公平的收入分配体系，彰显优势、协调联动的城乡区域发展体系，资源节约、环境友好的绿色发展体系，多元平衡、安全高效的全面开放体系，以及充分发挥市场作用、更好发挥政府作用的经济体制。
- 建设现代化经济体系要建设创新引领、协同发展的产业体系，推动实体经济、科技创新、现代金融、人力资源协同发展；实施乡村振兴和区域协调发展战略，推进城乡融合；发展开放型经济并维护产业链供应链安全。
- 产业升级不能只追求扩大规模，还要提高全要素生产率、创新能力和资源利用效率；城乡协调不是城乡发展水平完全相同，而是促进要素双向流动和基本公共服务均等化。

#### 第四课 我国的个人收入分配

- 我国实行按劳分配为主体、多种分配方式并存的分配制度，由生产资料所有制决定。按劳分配适用于公有制经济，基本要求是以劳动者向社会提供的劳动（数量和质量）为尺度分配个人消费品，多劳多得、少劳少得；它既调动劳动积极性，也体现社会主义生产关系。
- 居民收入来源包括劳动性收入、财产性收入、经营性收入和转移性收入。按生产要素分配包括劳动、资本、土地、知识、技术、管理、数据等要素参与分配；各类收入的合法性及具体形成机制须结合制度和法律条件分析。
- 完善个人收入分配要坚持居民收入增长和经济增长基本同步、劳动报酬提高和劳动生产率提高基本同步；初次分配、再分配、第三次分配协调配套。税收、社会保障、转移支付等调节收入差距；慈善等第三次分配发挥补充作用，不能替代政府再分配责任。

#### 第四课 我国的社会保障

- 社会保障通过国民收入再分配调节不同社会群体利益关系，保障基本生活、维护社会公平、促进社会和谐。社会保障水平应与经济社会发展水平相适应，既要尽力而为，也要量力而行。
- 社会保险包括基本养老保险、基本医疗保险、失业保险、工伤保险和生育保险，由政府、单位和个人依法分担相应筹资责任，面向符合条件的参保人提供保障；社会救助保障因自然灾害或其他原因陷入基本生活困境的公民，是社会保障体系的最后一道防线；社会福利面向社会成员提供更广泛的福利服务；社会优抚保障现役军人、退役军人及其家属等特定群体。各险种参保资格和待遇依现行规定适用。
- 完善社会保障要覆盖全民、统筹城乡、公平统一、安全规范、可持续，并处理权利义务、互助共济与个人责任之间的关系。社会保险待遇、缴费和资格有具体法律政策规定，不能用教材概括取代当地现行办事规则。

#### 综合探究 践行社会责任 促进社会进步

分析经济发展与民生问题时，先分清事实数据和价值判断，再识别生产、分配、交换、消费中的制度机制，最后说明政策作用对象和可能边界。例如，讨论提高最低工资应同时分析劳动者收入保障、企业成本和就业影响，不能仅凭单一案例推断整体效果。

## 三、必备知识点

- 我国基本经济制度包含所有制、分配制度和社会主义市场经济体制；所有制结构是生产关系的重要基础。
- 公有制主体地位与国有经济主导作用是两个相关但不同的判断；前者看公有资产总体优势，后者看国有经济控制力。
- 市场通过价格、供求、竞争配置资源；市场失灵需要政府依法调控和公共治理补充。
- 五大发展理念分别回应动力、平衡、人与自然、内外联动和公平共享问题，共同服务高质量发展。
- 居民收入由多种渠道构成；按劳分配适用于公有制经济，其他合法收入形成机制需依收入来源判断。
- 初次分配、再分配、第三次分配功能不同；社会保险、社会救助、社会福利、社会优抚对象和机制不同。

## 四、必备公式/定理

本册无统一计算公式。市场分析关系：供求变化影响价格，价格信号影响生产者和消费者决策，决策变化再反馈供求；这一机制受竞争程度、信息质量、公共政策和外部性等条件限制。

## 五、必备单词/术语

| 术语 | 含义 | 区分要点 |
|---|---|---|
| 公有制主体地位 | 公有资产在社会总资产中占优势，国有经济发挥主导作用 | “占优势”是总体判断，不要求每个行业公有资产都占多数 |
| 按劳分配 | 在公有制经济中以劳动者提供的劳动为尺度分配个人消费品 | 与按资本、技术等要素分配不同 |
| 市场失灵 | 市场机制无法有效配置资源或实现社会目标的情形 | 垄断、公共物品、外部性、信息不对称是常见原因 |
| 宏观调控 | 政府运用政策工具调节经济运行 | 目标、工具与经济形势要匹配，不能机械套用 |
| 初次分配 | 生产过程中形成、主要由市场和生产要素贡献影响的收入分配 | 发生在国民收入初次形成环节 |
| 再分配 | 政府通过税收、社会保障、转移支付等调节收入 | 主要承担公共调节和公平保障功能 |
| 第三次分配 | 个人、企业和社会组织自愿参与的公益慈善分配 | 属于补充机制，不能替代初次分配和政府再分配 |

## 六、熟记内容

- 市场在资源配置中起决定性作用，政府实行科学宏观调控、有效政府治理。
- 新发展理念是创新、协调、绿色、开放、共享；对应动力、平衡、人与自然、内外联动和公平共享问题。
- 我国实行按劳分配为主体、多种分配方式并存的分配制度。
- 社会保险、社会救助、社会福利、社会优抚构成社会保障的重要形式，各有保障对象和功能。

## 七、易错点与掌握边界

| 易错理解 | 正确结论 |
|---|---|
| 国有经济主导就意味着国有经济在所有行业数量占多数 | 主导作用主要体现为控制力，行业结构可有差异 |
| 市场决定资源配置就意味着政府不应干预 | 政府需维护规则、弥补市场失灵并提供公共服务 |
| 市场价格上涨一定代表短缺，且所有需求都会减少 | 价格受多因素影响，需求反应还取决于收入、替代品和预期 |
| 按劳分配适用于所有劳动者 | 按劳分配是公有制经济中的分配方式，不等同于一切劳动收入 |
| 慈善捐赠可以替代社会保障 | 第三次分配具有补充性，政府保障责任仍然存在 |
| 社会保障待遇与缴费、资格在各地完全相同 | 具体标准依现行法律政策和统筹地区规则，需查当地正式文件 |

## 八、综合应用示例

某地对小微企业提供融资服务，同时加强产品质量监管。融资服务降低企业获得资金的障碍，体现政府优化营商环境、支持经营主体；质量监管维护公平竞争和消费者权益，弥补单靠市场声誉可能无法及时解决的信息问题。分析时要区分政策事实和效果评价；若要断言就业或产量增长，必须有实施前后可比数据，不能由政策出台直接推出实际效果。
