## 一、本册学习地图

## 二、目录与章节重点

### 第一章 物质及其变化

#### 第一节 物质的分类及转化

- **纯净物与混合物**：纯净物由一种物质组成，组成固定；混合物由两种或多种物质组成，各成分保留原有性质，可用物理方法分离。空气、海水是混合物，蒸馏水和纯氧是纯净物。
- **单质与化合物**：单质只含一种元素，化合物含两种或多种元素且组成固定。氧化物是由两种元素组成、其中一种为氧元素的化合物；酸、碱、盐按组成和电离特点分类，不能按俗名判断。
- **分散系**：溶液、胶体、浊液的区别在分散质粒子尺度及分散状态。胶体能产生丁达尔效应；用光束照射时可见光路，溶液通常没有明显光路。
- **物质转化**：酸可与碱发生中和反应；酸与活泼金属反应可生成盐和氢气；盐之间的复分解反应通常需生成沉淀、气体或弱电解质。书写转化关系时必须核对反应物状态、反应条件和生成物。

#### 第二节 离子反应

- **电解质与电离**：在水溶液中或熔融状态下能导电的化合物为电解质；导电原因是存在能自由移动的离子。NaCl 固体中离子不能自由移动，熔融 NaCl 或 NaCl 溶液能导电。电离方程式表示溶液中离子来源，不表示反应。
- **离子反应**：有离子参加或生成的反应。书写离子方程式先写正确的化学方程式，再拆分易溶且完全电离的强电解质，删去旁观离子，最后检查原子和电荷守恒。
- **反应发生条件**：离子互换后形成沉淀、气体或水等弱电解质时，反应可向生成物方向进行。例如 `Ba²⁺ + SO₄²⁻ = BaSO₄↓`；强酸强碱中和的本质为 `H⁺ + OH⁻ = H₂O`。
- **边界**：难溶物、气体、弱电解质和单质不能随意拆写成离子；离子方程式必须同时满足质量守恒和电荷守恒。

#### 第三节 氧化还原反应

- **判据与本质**：反应前后有元素化合价变化的反应是氧化还原反应；本质是电子转移或共用电子对偏移。化合价升高表示失电子、被氧化；化合价降低表示得电子、被还原。
- **氧化剂与还原剂**：氧化剂得到电子并被还原，表现氧化性；还原剂失去电子并被氧化，表现还原性。两者在同一氧化还原反应中同时出现。
- **示例**：`Zn + CuSO₄ = ZnSO₄ + Cu` 中 Zn 从 0 价升为 +2 价，是还原剂；Cu²⁺从 +2 价降为 0 价，是氧化剂。电子转移数和化合价变化必须与方程式系数对应。

### 第二章 海水中的重要元素——钠和氯

#### 第一节 钠及其化合物

- **钠的性质**：钠质软、银白、密度小于水，化学性质活泼，实验室通常保存在煤油中。钠与水反应生成 NaOH 和 H₂，放热并产生气体；操作必须由教师按实验规范完成，不能接触皮肤或自行实验。
- **氧化物**：Na₂O 是碱性氧化物；Na₂O₂中氧为 −1 价，能与水或 CO₂反应生成 O₂，可用于呼吸面具等供氧情境。两者组成和氧化还原性质不同，不能混称。
- **碳酸钠与碳酸氢钠**：Na₂CO₃俗称纯碱，是盐；NaHCO₃俗称小苏打。二者均能与酸放出 CO₂；NaHCO₃受热可分解，Na₂CO₃热稳定性较高。侯氏制碱法以食盐、氨、二氧化碳和水为原料，利用 NaHCO₃溶解度较小而析出。
- **焰色试验**：用于定性识别部分金属元素；钠呈黄色、钾呈紫色（观察钾时需隔蓝色钴玻璃滤去黄光干扰）。焰色是元素的特征，不等同于该盐溶液本身颜色。

#### 第二节 氯及其化合物

- **氯气**：黄绿色、有刺激性气味、有毒，密度大于空气，能溶于水。氯气与金属、氢气等反应时体现强氧化性；氯气不能用排水法收集。
- **氯水与漂白**：氯气溶于水发生可逆反应 `Cl₂ + H₂O ⇌ HCl + HClO`。HClO具有漂白性和强氧化性，光照易分解；干燥氯气不能使干燥有色物质漂白。漂白实质取决于是否生成 HClO，而非氯元素名称。
- **氯离子检验**：向待测液先加稀硝酸酸化，再滴加 AgNO₃，出现白色 AgCl 沉淀可支持 Cl⁻存在；不能用盐酸酸化，以免引入 Cl⁻。
- **安全与用途**：氯气可用于制盐酸、消毒和制漂白剂；有毒气体实验需密闭或在通风橱中进行，尾气用碱液吸收。

#### 第三节 物质的量

- **物质的量** `n` 的单位为 mol，1 mol 粒子约含 `6.02×10²³` 个粒子。粒子对象须明确，如 1 mol H₂O 指水分子，不能把物质的量与质量或粒子数混为一谈。
- **摩尔质量**：`M = m/n`，单位常用 g·mol⁻¹；数值上等于该粒子的相对原子质量或相对分子质量，但两者单位不同。
- **气体摩尔体积**：`Vₘ = V/n`。只有在相同温度和压强下比较气体时，才能使用相同的摩尔体积；标准状况下约为 22.4 L·mol⁻¹，不能在任意条件套用。
- **物质的量浓度**：`c = n/V`，体积 `V` 必须是溶液体积，常用 L；稀释时溶质物质的量不变，满足 `c₁V₁=c₂V₂`。
- **配制一定物质的量浓度溶液**：计算溶质质量→称量→溶解并冷却→转移至容量瓶→洗涤转入→定容至刻度→摇匀。容量瓶不能用于溶解、加热或长期贮存；仰视/俯视刻度会造成系统误差。

### 第三章 铁 金属材料

#### 第一节 铁及其化合物

- 铁与氧气、水等反应可形成铁锈；铁锈疏松，不能保护内部铁。隔绝水和氧、涂层或合金化可减缓腐蚀。
- Fe²⁺与 Fe³⁺可相互转化：Fe²⁺易被氧化为 Fe³⁺，Fe³⁺可被较强还原剂还原为 Fe²⁺。检验 Fe³⁺可观察其溶液颜色或用 SCN⁻形成血红色配合物；检验 Fe²⁺时应避免样品被空气氧化。
- 铁与稀酸反应通常生成 Fe²⁺和 H₂；铁与 Cu²⁺反应生成 Fe²⁺和 Cu。写方程式时需结合氧化还原关系确定产物价态。

#### 第二节 金属材料

- 合金由金属与其他元素熔合而成，性能通常不同于各成分纯金属；钢是铁碳合金，不锈钢通过加入合金元素提高耐蚀性。材料选择依据用途需要的强度、硬度、密度、耐腐蚀性和成本。
- 金属冶炼是把矿石中的金属元素转化为金属单质；金属活动性不同，冶炼方法和能耗不同。资源利用需兼顾回收、腐蚀防护与环境影响。
- 铁及其化合物性质实验要分别观察颜色、沉淀与价态变化；实验废液按含重金属废液要求收集。

### 第四章 物质结构 元素周期律

#### 第一节 原子结构与元素周期表

- 原子由原子核和核外电子构成；核电荷数等于质子数，原子序数等于质子数。质量数 `A=Z+N`，其中 `Z` 为质子数、`N` 为中子数。质子数相同、中子数不同的原子互为同位素。
- 核外电子按能量由低到高分层排布；前 18 号元素常用电子排布表示为各层电子数。元素周期表横行为周期、纵列为族；周期序数与电子层数相对应，主族序数与最外层电子数有联系（氦等例外需单独识别）。
- 同周期、同主族元素性质递变可由有效核电荷、电子层数及原子半径变化解释，不应只背结论而忽略比较对象和趋势范围。

#### 第二节 元素周期律

- 元素性质随原子序数递增呈周期性变化，体现为原子半径、主要化合价、元素金属性和非金属性等规律性变化。
- 同周期从左到右，原子半径总体减小，金属性减弱、非金属性增强；同主族从上到下，电子层数增多、原子半径增大，金属性总体增强，非金属性总体减弱。趋势是“总体”，具体比较需结合元素和实验事实。
- 最高价氧化物对应水化物的酸碱性可帮助比较元素非金属性或金属性，但必须是同周期/同主族可比元素，且不得把不稳定或不存在的化合物强行类推。

#### 第三节 化学键

- 离子键由阴、阳离子间静电作用形成，常见于活泼金属与活泼非金属构成的离子化合物；共价键由原子间共用电子对形成。电子式展示价电子和成键关系，化学式只表示组成，不能替代空间结构。
- 共用电子对偏向吸引能力较强的原子时形成极性共价键；同种原子间共价键通常为非极性键。分子是否有极性还取决于空间结构，不能只看键是否极性。
- 化学反应的本质涉及旧化学键断裂与新化学键形成；元素原子重新组合，原子种类和数目守恒。

## 三、必备知识点

1. 物质分类必须依据组成；化学反应判断离子、氧化还原两种视角可同时使用。
2. 离子方程式删去旁观离子后仍须保持原子和电荷守恒，沉淀、气体、弱电解质不得拆写。
3. 钠、氯、铁代表物性质来自原子结构和反应条件；同元素不同价态化合物具有不同氧化还原能力。
4. 物质的量把粒子数与可称量的质量、气体体积、溶液浓度联系起来；公式中的对象、单位、温度和体积定义必须一致。
5. 元素周期律由原子结构变化导致，周期表位置可用于解释和有限度预测元素性质。

## 四、必备公式/定理

| 关系 | 量与单位 | 适用条件/例子 |
|---|---|---|
| `n=N/N_A` | `N` 为粒子数，`N_A≈6.02×10²³ mol⁻¹` | 指明粒子种类；1 mol Na⁺含约 `6.02×10²³` 个 Na⁺ |
| `n=m/M` | `m` 为质量(g)，`M` 为摩尔质量(g·mol⁻¹) | 纯物质；`18 g H₂O` 为 1 mol |
| `n=V/Vₘ` | `V` 与 `Vₘ` 使用相同体积单位 | 同温同压气体；仅标准状况可近似用 `Vₘ=22.4 L·mol⁻¹` |
| `c=n/V` | `V` 是溶液体积(L)，`c` 单位 mol·L⁻¹ | 计算溶液浓度，不能把溶剂体积当溶液体积 |
| `c₁V₁=c₂V₂` | 稀释前后溶质物质的量相等 | 无化学反应、无溶质损失 |
| `A=Z+N` | 质量数=质子数+中子数 | 用于表示核素，不是相对原子质量公式 |

## 五、必备单词/术语

| 词语/符号 | 类别 | 中文释义 | 使用提醒与例子 |
|---|---|---|---|
| 胶体 | 分散系 | 分散质粒子处于胶体尺度的分散体系 | 可出现丁达尔效应；胶体不是溶液 |
| 电解质 | 物质类别 | 在水溶液或熔融状态能导电的化合物 | 固态 NaCl 不导电，熔融 NaCl 导电 |
| 氧化剂/还原剂 | 氧化还原 | 得电子并被还原者/失电子并被氧化者 | 需在具体反应中判定，不能按物质名称固定 |
| 物质的量 `n` | 物理量 | 衡量微观粒子集合体的基本物理量 | 单位 mol；须注明粒子对象 |
| 摩尔质量 `M` | 物理量 | 单位物质的量物质的质量 | 单位 g·mol⁻¹，与相对分子质量数值相同但单位不同 |
| 物质的量浓度 `c` | 溶液量 | 单位体积溶液中溶质的物质的量 | 体积用 L，不能写成每升溶剂 |
| 同位素 | 原子结构 | 质子数相同、中子数不同的同元素原子 | 例如氢的不同核素 |

## 六、熟记内容

- 强酸强碱中和的离子方程式：`H⁺ + OH⁻ = H₂O`。
- 钠与水：`2Na + 2H₂O = 2NaOH + H₂↑`；氯气与水：`Cl₂ + H₂O ⇌ HCl + HClO`。
- 物质的量核心换算：`n=N/N_A=m/M=V/Vₘ`（各式适用对象分别为粒子、质量、气体体积）；溶液浓度 `c=n/V`。
- 熟记同周期、同主族性质变化的比较前提和趋势，不将趋势当作无条件定律。

## 七、易错点与掌握边界

| 易错说法 | 正确结论 | 例证 |
|---|---|---|
| 固体 NaCl 是电解质，所以固体能导电 | 电解质定义看溶液或熔融状态；固态离子不能自由移动 | 熔融 NaCl 导电，NaCl 晶体不导电 |
| 离子方程式把所有物质都拆成离子 | 沉淀、气体、弱电解质、单质等保留化学式 | `H⁺+OH⁻=H₂O` |
| 标准状况气体摩尔体积任何条件都适用 | 温度、压强改变时气体摩尔体积改变 | 22.4 L·mol⁻¹仅为标准状况近似 |
| 分子有极性键就一定是极性分子 | 分子空间结构会使键偶极相互抵消或不抵消 | 需结合结构判断 |

## 八、综合应用示例

将 5.85 g NaCl 配成 500 mL 溶液，求物质的量浓度。`M(NaCl)=58.5 g·mol⁻¹`，`n=5.85/58.5=0.100 mol`；溶液体积为 `0.500 L`，故 `c=0.100/0.500=0.200 mol·L⁻¹`。计算中不能把 500 mL 改作 0.500 mL，也不能用加水体积代替最终溶液体积。
