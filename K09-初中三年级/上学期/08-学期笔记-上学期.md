# 九年级上学期学习汇总

本学期七科进入初中课程综合阶段。数学将特殊四边形、方程、相似、三角函数和二次函数连成代数几何主线；物理从功和能推进到电路定量关系；化学建立微粒模型、化学用语和守恒；世界历史追踪古代文明至工业革命；道德与法治讨论国家发展、民主法治、文化生态与民族复兴。英语为全年共用教材，此处保留全年入口和知识脉络，不把单元人为切割为官方上下学期进度。

## 二、必备知识点

### 语文

- 诗歌分析从意象、节奏、语气和转折找证据；象征意义须由全篇语境支持。《乡愁》以邮票、船票、坟墓、海峡递进乡愁对象和空间阻隔。
- 议论文区分中心论点、分论点、事实/道理论据和论证方式；驳论须准确指出对方主张及论证问题。《岳阳楼记》以阴晴景象引发迁客骚人之悲喜，再提出“不以物喜，不以己悲”和“先忧后乐”的政治理想。
- 小说人物须放在社会环境和冲突中分析；缩写要保留主要事件、因果与转折，删减修辞细节不能改变事实。

### 数学

- 矩形、菱形、正方形均属于平行四边形的特殊情形，性质和判定各有前提。判别式决定一元二次方程根的情况；求根之后需检查实际问题限制。
- 相似三角形对应角相等、对应边成比例；边长比为 k 时面积比为 k²。正弦、余弦、正切相对选定锐角定义，使用特殊角值解直角三角形。
- 二次函数的开口、对称轴、顶点和与 x 轴交点揭示增减、最值和对应方程根；实际最值必须受自变量定义域约束。概率用列表或树状图避免重复遗漏，频率可估计但不等于理论概率。

### 英语（全年共用）

- Unit 1–3 训练 by + doing 学习方法、节日宾语从句和礼貌问路；Unit 4–6 表达过去变化、产品被制造及发明；Unit 7–9 谈规则、根据线索推断和作品偏好；Unit 10–12 讲习俗、情绪影响和过去先后；Unit 13–14 讨论环保、校园回忆与未来。
- 宾语从句用陈述语序；被动语态突出动作承受者；used to 表示过去习惯/状态；情态动词后接原形；定语从句修饰先行词；过去完成时表示相对于过去参照点更早发生的动作。

### 道德与法治

- 改革开放和创新推动发展，共同富裕是共享发展成果，不是结果完全平均。民主参与包括选举、协商、决策、管理和监督，参与须依法依程序。
- 法治要求立法、执法、司法、守法相衔接；中华文化、民族精神与社会主义核心价值观支撑社会凝聚；绿色发展须考虑资源环境承载力。
- 民族团结、国家统一和中国梦关联国家发展；个人将理想落实于学习、劳动和社会参与。

### 历史

- 古代埃及、两河流域和印度文明与大河农业、国家组织有关；希腊城邦、罗马法与政体构成古典欧洲文明。中世纪庄园、封君封臣、城市与大学呈现欧洲社会结构变化；日本大化改新加强中央集权，阿拉伯帝国连接欧亚非交流。
- 文艺复兴以人文主义关注人的价值；新航路开辟扩展全球联系并伴随殖民掠夺。英国、美国、法国革命分别形成不同制度和政治文件，须比较背景、诉求、结果与局限。
- 工业革命以机器生产和工厂制度改变生产、城市与阶级关系；1848年《共产党宣言》标志马克思主义诞生。技术变迁带来生产力提升，也伴随劳动、城市和社会问题。

### 物理

- 做功须同时有力和沿力方向的位移；功率表示做功快慢，机械效率是有用功占总功的比例，任何机械都不能省功。动能与质量、速度有关，重力势能与质量和高度有关。
- 做功和热传递都能改变内能；比热容描述单位质量物质温度改变时吸放热的能力。串联电流处处相等、电压分配；并联各支路电压相等、干路电流为各支路之和。
- 欧姆定律需保持导体温度等状态不变；电功率既可由额定值也可按实际电压、电流计算。焦耳热按电流、电阻和时间确定。

### 化学

- 物理变化不生成新物质，化学变化生成新物质；实验结论要以观察现象及控制条件为依据。空气主要成分约氮气78%、氧气21%。氧气支持燃烧但本身不燃烧。
- 分子由原子构成，原子由原子核和核外电子组成；元素以质子数（核电荷数）区分。水电解生成氢气和氧气，体积比约2:1。
- 化学式说明组成，化学方程式说明反应物、生成物、条件及粒子比例；配平依原子守恒。二氧化碳不燃烧且不支持燃烧，一氧化碳有毒、可燃且具有还原性。

## 三、必备公式/定理

| 科目 | 关系式/定理 | 含义与适用条件 |
|---|---|---|
| 数学 | `x=(-b±√(b²-4ac))/(2a)` | `ax²+bx+c=0` 且 `a≠0`；判别式 `b²-4ac` 决定实根情况。 |
| 数学 | 两根和 `-b/a`，两根积 `c/a` | 对上述一元二次方程的两根适用。 |
| 数学 | 相似面积比 `=k²` | 相似图形对应边长比为 k。 |
| 数学 | `sinθ=对边/斜边`；`cosθ=邻边/斜边`；`tanθ=对边/邻边` | θ 为直角三角形锐角；“对边/邻边”随所选角而定。 |
| 数学 | `y=a(x-h)²+k` 顶点为 `(h,k)` | `a≠0`；开口方向由 a 正负决定，最值需结合定义域。 |
| 物理 | `W=Fs`；`P=W/t=Fv` | 力与位移同向时 W；F 与 v 同向时 P=Fv。 |
| 物理 | `η=W有/W总×100%` | 同一工作过程定义有用功和总功。 |
| 物理 | `Q=cmΔT`；`Q=mq` | 前式不含物态变化；后式适用于燃料完全燃烧。 |
| 物理 | `I=U/R`；`P=UI`；`Q=I²Rt` | 欧姆定律保持温度等状态不变；纯电阻可用 `P=I²R=U²/R`。 |
| 化学 | `相对分子质量=Σ(相对原子质量×原子个数)` | 依化学式计算；化学方程式配平使反应前后各元素原子数相同。 |

## 六、易错点与知识联系

- 特殊平行四边形的判定不能丢掉平行四边形基础条件；相似面积比必须平方；二次函数顶点最值若不在允许区间，实际最值可能出现在端点。
- 英语宾语从句用陈述语序：`where the station is`；`must/might/can't` 后不加 to；现在完成时不与明确过去时点连用；`look forward to` 中 to 为介词，后接名词或动名词。
- 文艺复兴与启蒙运动所处时代和思想内容不同；英国、美国、法国革命制度结果不可互换。工业革命改变生产方式，不等于立即解决社会矛盾。
- 机械效率不是“机械省下的功”；电功、电功率和电热含义不同；额定值与实际工作状态值不能混用。
- 氧气是助燃物而非可燃物；一氧化碳与二氧化碳性质不同；配平只改化学式前系数，不能改化学式中的下标。
