## 一、本册学习地图

本册从人类早期文明讲到工业革命和马克思主义诞生。历史主线是：大河流域孕育古代文明，区域交流和帝国扩展促进文明传播；中古时期欧洲、亚洲和非洲各自发展；近代商业扩张、文艺复兴和思想解放推动资本主义制度确立；工业革命改造生产并带来新的阶级关系与社会思想。

| 单元 | 真实学习内容 | 单元之间的联系 |
|---|---|---|
| 古代亚非文明 | 埃及、两河流域、印度文明 | 农业灌溉、国家形成和文字法律发展 |
| 古代欧洲文明 | 希腊城邦、罗马政权及古典文化 | 城邦政治和罗马法律文化影响后世 |
| 封建时代的欧洲 | 基督教、法兰克王国、庄园、城市大学、拜占庭 | 封建秩序与城市复兴并存，逐渐走向近代 |
| 封建时代的亚洲国家 | 日本、阿拉伯帝国 | 政治制度、宗教和跨区域知识交流 |
| 走向近代 | 西欧经济变化、文艺复兴、新航路、殖民掠夺 | 商品经济和全球扩张推动近代转型 |
| 资本主义制度的初步确立 | 英国、美国、法国革命 | 启蒙思想转化为不同的政治制度实践 |
| 工业革命和国际共产主义运动的兴起 | 工业化、工人阶级、马克思主义 | 生产革命重塑社会关系并催生新思想 |

## 二、目录与章节重点

### 第一单元　古代亚非文明

#### 第1课 古代埃及

- 尼罗河定期泛滥带来肥沃土壤，支撑农业和统一治理；约公元前3100年古埃及初步统一。法老是最高统治者，金字塔是法老陵墓和古埃及文明象征。
- 象形文字、太阳历和木乃伊制作反映古埃及宗教、数学与医学知识。金字塔规模体现国家组织能力，不应只理解为建筑奇观。

#### 第2课 古代两河流域

- 两河流域苏美尔人建立城邦并发明楔形文字；古巴比伦王国汉谟拉比时期强盛。《汉谟拉比法典》以楔形文字刻在石柱上，维护等级社会和私有财产秩序。
- 法典按身份规定不同惩罚，说明古代法律与社会等级相连；它不是现代意义上人人平等的法律。

#### 第3课 古代印度

- 印度河流域出现哈拉帕、摩亨佐·达罗等早期城市；雅利安人进入后形成种姓制度，把社会分为婆罗门、刹帝利、吠舍、首陀罗等等级，贱民处于体系之外。
- 佛教创立于公元前6世纪左右，反对婆罗门特权和种姓压迫，主张众生平等、因果轮回；后传播至亚洲多地。

### 第二单元　古代欧洲文明

#### 第4课 希腊城邦和亚历山大帝国

- 古希腊多山少平原，形成众多城邦；雅典民主政治在成年男性公民范围内实行，妇女、奴隶和外邦人无公民权。斯巴达以军事训练和寡头统治著称。
- 亚历山大东征建立横跨欧亚非的大帝国，传播希腊文化并促进东西方交流，也伴随战争和征服。希腊化是文化互动，不等于当地传统消失。

#### 第5课 罗马城邦和罗马帝国

- 罗马从城邦共和国扩张为地中海霸权；共和时期执政官、元老院和公民大会分掌权力。公元前27年屋大维建立元首制，罗马进入帝国时期。
- 罗马法逐步发展，成为治理帝国的重要工具；395年罗马帝国分裂，476年西罗马帝国灭亡，东罗马（拜占庭）继续存在。

#### 第6课 希腊罗马古典文化

- 希腊哲学、戏剧、雕塑和建筑强调理性探究与人体美；苏格拉底、柏拉图、亚里士多德代表古希腊哲学。罗马在法律、建筑和历法方面发展显著。
- 古典文化通过教育、法律、建筑和后世文艺复兴持续产生影响；区分希腊贡献与罗马继承、发展。

### 第三单元　封建时代的欧洲

#### 第7课 基督教的兴起和法兰克王国

- 基督教1世纪产生于巴勒斯坦地区，4世纪末成为罗马帝国国教。西罗马灭亡后法兰克王国崛起，克洛维皈依基督教并扩张。
- 查理曼帝国分裂后，封君封臣关系发展，土地和军事义务构成西欧封建关系基础；基督教会对政治、文化和日常生活影响广泛。

#### 第8课 西欧庄园

- 9世纪起庄园成为西欧中世纪农村基本经济和社会单位；庄园土地分领主自营地和农民份地，农民承担劳役、地租等义务。
- 庄园法庭处理内部纠纷，维护领主利益；庄园经济以自给自足为主但并非完全隔绝外界。

#### 第9课 中世纪城市和大学的兴起

- 农业生产力提高和商业复兴推动城市兴起，城市居民通过赎买、武装斗争取得自治权；市民阶层发展，为资本主义萌芽提供社会条件。
- 大学由教会学校和城市学校发展而来，课程包括文法、修辞、逻辑、算术、几何、音乐、天文；大学自治和学术训练影响后世高等教育。

#### 第10课 拜占庭帝国和《查士丁尼法典》

- 东罗马帝国以君士坦丁堡为中心，长期保存罗马法和希腊文化。查士丁尼主持编纂《罗马民法大全》，包括《查士丁尼法典》《法学汇纂》《法理概要》《新法典》。
- 法典系统整理罗马法律，对欧洲法律传统影响深远；1453年奥斯曼帝国攻占君士坦丁堡，拜占庭帝国灭亡。

### 第四单元　封建时代的亚洲国家

#### 第11课 古代日本

- 5世纪大和政权基本统一日本；646年孝德天皇颁布改新诏书，学习隋唐制度，建立中央集权国家，史称大化改新。改革有利于日本从奴隶制社会向封建社会转型。
- 12世纪末起幕府掌握实权，天皇保留名义地位；武士集团和幕府政治成为日本中世政治特征。

#### 第12课 阿拉伯帝国

- 7世纪穆罕默德创立伊斯兰教并统一阿拉伯半岛；倭马亚、阿拔斯王朝扩张，建立地跨亚非欧的大帝国。阿拉伯商人连接欧亚非贸易。
- 阿拉伯学者翻译、保存并发展古希腊、印度和波斯知识，数学、医学、天文学成果经阿拉伯世界传播。

### 第五单元　走向近代

#### 第13课 西欧经济和社会的发展

- 农业技术改进、垦殖和租地农场发展，农村出现资本主义生产关系；手工业中分散手工工场向集中的手工工场转变，雇佣劳动扩大。
- 富裕农民、骑士和市民阶层发展，封建庄园经济逐渐瓦解，为文艺复兴和新航路开辟提供经济、社会条件。

#### 第14课 文艺复兴运动

- 14世纪起源于意大利，资产阶级借复兴古希腊罗马文化表达新思想；人文主义肯定人的价值和现世生活，反对教会禁欲观念。
- 但丁《神曲》、达·芬奇《最后的晚餐》《蒙娜丽莎》、莎士比亚戏剧体现人文主义。文艺复兴不是单纯复古，而是借古典文化发展新思想。

#### 第15课 探寻新航路

- 欧洲商品经济发展、寻金热、传统商路受阻和航海技术进步推动远洋探索。迪亚士抵达好望角，达·伽马到达印度，哥伦布抵达美洲，麦哲伦船队完成环球航行。
- 新航路开辟促成世界市场和全球联系初步形成，也推动欧洲殖民扩张、奴隶贸易和美洲人口灾难，影响具有双重性。

#### 第16课 早期殖民掠夺

- 葡萄牙、西班牙先行建立殖民帝国；英国、法国、荷兰后来扩张。殖民者掠夺金银、建立种植园并贩卖奴隶，形成跨大西洋“三角贸易”。
- 殖民掠夺推动欧洲资本原始积累，同时给非洲、美洲带来人口损失、社会破坏和经济依附；财富积累与受害后果须并列分析。

### 第六单元　资本主义制度的初步确立

#### 第17课 君主立宪制的英国

- 17世纪英国议会与王权冲突引发革命；1640年议会重新召开成为革命开始标志，查理一世被处死后经历共和国、护国政体和王政复辟。1688年光荣革命后政局转向。
- 1689年《权利法案》限制王权、确立议会权力，英国逐步形成君主立宪制；制度形成是长期政治斗争结果。

#### 第18课 美国的独立

- 英国对北美殖民地征税引发抗议，1775年独立战争爆发；1776年《独立宣言》宣布殖民地独立，1783年英国承认美国独立。
- 1787年宪法确立联邦制、三权分立和总统制；当时奴隶制及妇女、原住民权利受限，宣言平等原则未立即覆盖全体人口。

#### 第19课 法国大革命和拿破仑帝国

- 财政危机、等级特权和启蒙思想推动1789年法国大革命；《人权宣言》提出自由、平等、主权在民。革命废除君主制、处死路易十六并建立共和国。
- 拿破仑建立帝国并颁布《民法典》，巩固革命成果中的法律平等与财产制度；对外战争扩张引发反抗，帝国最终失败。革命影响传播欧洲并重塑政治秩序。

### 第七单元　工业革命和国际共产主义运动的兴起

#### 第20课 第一次工业革命

- 18世纪60年代英国开始工业革命，纺织机械、瓦特改良蒸汽机和机器生产推动工厂制形成；蒸汽机车和蒸汽船扩大运输。英国成为世界上第一个工业国家。
- 工业革命提高生产效率、加速城市化并形成工业资产阶级和无产阶级；工人劳动时间长、环境恶劣、贫富差距扩大，促成社会改革和工人运动。

#### 第21课 马克思主义的诞生和国际共产主义运动的兴起

- 工业化发展暴露资本主义矛盾，空想社会主义无法提出实现方案；马克思、恩格斯总结工人运动经验并发展科学社会主义理论。
- 1848年《共产党宣言》发表，标志马克思主义诞生；1864年第一国际成立，巴黎公社（1871年）是无产阶级建立政权的尝试。

#### 第22课 活动课：唱响《国际歌》

- 《国际歌》歌词由欧仁·鲍狄埃创作于巴黎公社失败后，皮埃尔·狄盖特谱曲。作品表达工人阶级团结和争取解放的理想，理解歌词需联系公社和国际工人运动背景。

## 三、必备知识点

- 古代文明依托农业和国家组织形成，希腊罗马政治文化、西亚法律和亚洲宗教文化通过交流影响后世。
- 中古欧洲庄园与封君封臣制度构成封建秩序；城市、大学和商品经济复兴为近代转型创造条件。
- 人文主义、宗教改革、科学革命和启蒙运动推动思想变化；资产阶级革命建立不同形式资本主义制度，工业革命改变生产和阶级结构。

## 四、必备公式/定理

本册无独立数值公式；本节列出必须掌握的年代时序和历史分析规则。

- 文明比较至少用相同维度：地理与生产、政治组织、社会等级、文字法律、宗教文化；避免以单一文明为所有地区的发展模板。
- 关键时序：前3100年左右埃及统一；前27年罗马帝国建立；476年西罗马灭亡；646年大化改新；1453年拜占庭灭亡；1492年哥伦布抵达美洲；1640英国革命开始；1689《权利法案》；1776《独立宣言》；1789法国大革命；1848《共产党宣言》。

## 五、必备单词/术语

| 术语 | 含义 |
|---|---|
| 城邦 | 以城市为中心、拥有独立政治组织的国家形态。 |
| 种姓制度 | 古印度按出生划分社会等级、限制职业和交往的制度。 |
| 封君封臣制 | 中古西欧领主与附庸以土地、效忠和军事义务建立的关系。 |
| 人文主义 | 强调人的价值、尊严、理性和现世生活的思想。 |
| 君主立宪制 | 以宪法和议会限制君主权力、君主仍为国家元首的制度。 |
| 三角贸易 | 欧洲、非洲、美洲之间以商品、奴隶和殖民产品构成的大西洋贸易体系。 |
| 工业革命 | 机器生产和工厂制度取代手工劳动、推动经济结构转型的过程。 |

## 七、易错点与掌握边界

| 易错点 | 准确结论 |
|---|---|
| 把雅典民主说成全体居民平等参政 | 只有成年男性公民有政治权利，妇女、奴隶和外邦人被排除。 |
| 把文艺复兴说成简单复古 | 它借古典文化表达新兴资产阶级的人文主义思想。 |
| 认为新航路只带来贸易增长 | 全球联系扩大的同时也有殖民掠夺、奴隶贸易和原住民灾难。 |
| 认为工业革命只改善生活 | 它提高生产力，也带来阶级矛盾、恶劣劳动条件和城市问题。 |

## 八、综合应用示例

解释工业革命怎样推动社会变化：英国具备资本、劳动力、市场和技术等条件，18世纪60年代开始机器化生产，蒸汽动力推动工厂与交通发展。商品产量和市场规模扩大，人口向城市集中，工业资产阶级和无产阶级成为重要社会力量。劳动者长时间工作、工资低和城市拥挤引发劳工组织及社会改革，马克思主义在批判资本主义矛盾的背景下形成。由此可见，技术变革经由生产组织和阶级结构变化影响政治思想。
