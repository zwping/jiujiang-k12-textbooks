# 九年级上册语文重点笔记

> 对应教材：义务教育教科书《语文》九年级上册（人教统编版）
> 编排依据：篇目、单元与活动按仓库现有教材目录核对；正文知识及明确的背诵要求据仓库现有教材文本整理，目录星号不作为背诵要求的依据。

## 一、本册学习地图

本册按诗歌、议论性文章、文言山水、小说和古典小说组织阅读。读诗要由意象和语言进入情感；读议论文要区分观点、论据和推理；读小说要把人物放回冲突与社会环境；读文言文要结合句式和语境。写作训练对应缩写、观点表达、论证和创意表达。

- **阅读能力**：比较诗歌意象和表达；辨析作者主张与证据；解释文言写景结构；分析小说人物变化、叙述视角和讽刺效果。
- **表达能力**：保留核心信息进行缩写；提出明确观点；用相关证据进行论证；改写故事而不破坏情节因果。
- **六单元主线**：诗歌活动 → 议论文章 → 古典诗文 → 小说 → 论说文 → 古典小说。

## 二、目录与章节重点

- **第一单元：诗歌活动·探究**
  - **任务一《学习鉴赏》**：先读准节奏和重音，再辨认意象、语气和情感；将理解落实到词句，不用主题标签替代文本分析。
  - **1《沁园春·雪》**：上阕写北国雪景，下阕评说历史人物并转向当代；空间铺展、动静比拟和古今对照形成宏大气势。
  - **2《我爱这土地》**：诗中“鸟”以歌唱承受土地、河流和风的苦难，最终飞向黎明；设问和反复将个体生命与祖国命运相连。
  - **3*《乡愁》**：邮票、船票、坟墓、海峡依次对应人生阶段和空间阻隔；相同句式重复，情感由亲人离别推至家国分离。
  - **4*《你是人间的四月天》**：用春天、光、云烟等意象描绘生命的明亮与温柔；音乐性来自节奏、复沓和意象组合。
  - **5《我看》**：风、飞鸟、春草等自然形象引出青春、生命与自然交融的感受；诗歌由外部景物转入内心体验。
  - **任务二《诗歌朗诵》、任务三《尝试创作》**：朗诵依语义安排停连；创作从具体对象和感受出发，使用可感意象而非抽象口号。
  - **名著《艾青诗选》**：关注土地、太阳、光明等反复出现的意象，联系创作年代理解诗歌情感。
- **第二单元：议论性文章**
  - **6《敬业与乐业》**：梁启超从有业、敬业、乐业层层论述合理生活；引用经典、解释观点并结合职业经验，论点和分论点需分清。
  - **7《就英法联军远征中国致巴特勒上尉的信》**：雨果先赞美圆明园，再谴责侵略者掠夺；反语和强烈对比揭示文明自诩与暴行之间的矛盾。
  - **8*《论教养》**：以日常待人行为辨别真正教养与表面礼貌；举例和对照让抽象品质落实为具体行为。
  - **9《精神的三间小屋》**：以三间精神居所分别讨论爱、事业和自我；比喻结构帮助组织抽象论述，段落推进由情感到生活再到自我认识。
  - **写作《观点要明确》**：观点应是可判断、可论证的完整句子；全文材料和分论点围绕同一中心，避免题目、观点和材料各说各话。
  - **综合性学习《君子自强不息》**：从人物事例、经典语句和现实行动理解自强；陈述时说明事例怎样证明观点。
- **第三单元：古典山水文章与诗词**
  - **10《岳阳楼记》**：先写重修岳阳楼和迁客骚人览物之情，再以“不以物喜，不以己悲”转出古仁人胸襟，结尾提出先忧后乐的政治理想；悲景、乐景服务于议论转折。
  - **11《醉翁亭记》**：按环滁、酿泉、亭名、朝暮四时、宴游和太守之乐铺展；“乐”由山水、宴饮、百姓生活层层推进到与民同乐。
  - **12*《湖心亭看雪》**：以极简白描写大雪后湖心亭、舟、人；“一痕、一点、一芥、两三粒”把天地辽阔和人物渺小并置。
  - **13《诗词三首》**：李白《行路难》写理想受阻后的信念；刘禹锡《酬乐天扬州初逢席上见赠》由贬谪感慨转向积极心境；苏轼《水调歌头》由望月怀人转向对离合的旷达理解。
  - **写作《议论要言之有据》**：论据真实、典型、与论点相关；事实之后补充解释，说明它证明论点的哪一层。
- **第四单元：小说与人物命运**
  - **14《故乡》**：成年“我”回乡见闰土、杨二嫂及下一代；过去与现在的对照呈现农村社会变化，“希望本无所谓有……”将个人离乡感受推向对未来的思考。
  - **15《我的叔叔于勒》**：菲利普夫妇对待于勒的态度随其经济状况想象而变；船上相遇让亲情被金钱计算取代，儿童视角和结尾反转形成讽刺。
  - **16*《孤独之旅》**：杜小康在芦苇荡放鸭，经历孤独、暴风雨和鸭群变化后成长；环境不只是背景，也把人物心理变化外化。
  - **写作《学习缩写》**：保留主要人物、关键事件、因果关系和主题证据；删去次要描写时不能改变原作立场或结果。
  - **综合性学习《走进小说天地》**：讨论人物、情节和环境时，用原文细节作依据，不凭影视改编替代原文。
- **第五单元：论证与创造**
  - **17《中国人失掉自信力了吗》**：鲁迅辨析“自信力”与“他信力”，先批驳对方论据和推理，再列举历史与现实中的“中国的脊梁”立论；驳论中有立论。
  - **18《怀疑与学问》**：把怀疑视作辨伪和建设新学说的起点；引用古训、举历史实例，说明怀疑需有证据和求真的目的。
  - **19*《谈创造性思维》**：创造性思维并非少数人的专利，关键在于是否有自信、是否追问和是否从多角度思考；事例用于证明训练可能性。
  - **20*《创造宣言》**：陶行知反驳“不能创造”的借口，以教育实践、环境和行动论证人人可参与创造；排比和反问加强演讲语势。
  - **写作《论证要合理》**：观点、证据和解释之间必须有逻辑桥梁；不能只堆事例，也不能把相关性当作因果。
- **第六单元：古典小说阅读**
  - **21《智取生辰纲》**：杨志押送、吴用等设局，押送队伍内部矛盾和酷热环境使计谋得逞；明暗两条线交织，人物选择推动情节。
  - **22《范进中举》**：中举前后范进及乡邻态度剧变；夸张、对比和细节刻画科举制度对人性的扭曲及社会势利。
  - **23《三顾茅庐》**：刘备求贤的耐心与诸葛亮出山的审慎通过行动和对话呈现；人物评价依托礼贤下士、胸怀抱负等情节证据。
  - **24《刘姥姥进大观园》**：刘姥姥的言行与贾府生活形成反差；众人笑态、观察视角和饮食场面既制造喜剧，也显出人物身份和生活差异。
  - **写作《创意表达》**：创意可以改变视角、结构或媒介，但须保留表达对象、核心意思和可理解的逻辑。

## 三、必备知识点

- **诗歌**：从意象组合、反复、节奏和语气解释情感变化；象征意义必须由诗句和整体语境支持。
- **议论文**：分清中心论点、分论点、事实论据、道理论据和论证方式；分析驳论时指出对方主张、被驳部分和作者的新论证。
- **小说**：人物在环境中的行动形成情节；叙述视角、对比、反复和结局共同塑造主题，评价须有细节证据。
- **文言写景**：关注时间、空间、视线和情感；古今异义词按句中语义理解。
- **缩写**：保留主要事件链与因果，不保留原文每个修辞和细节；缩短文字不能改写事实。

## 四、表达方法与结构

- **观点论证**：明确观点 → 选择匹配证据 → 解释证据与观点的关系 → 处理反例/限制 → 得出结论。
- **小说分析**：人物目标 → 环境限制 → 行动和冲突 → 变化/结局 → 由细节支持主题判断。
- **诗歌鉴赏**：意象与词句 → 形成的画面/语气 → 表达的情感 → 全诗主题；每一步都要有文本依据。
- **缩写**：标出主线事件 → 保留因果和关键转折 → 合并重复信息 → 检查人物立场和结局未变。

#### 《沁园春·雪》
背诵范围：全文背诵。

> 北国风光，千里冰封，万里雪飘。
> 望长城内外，惟余莽莽；大河上下，顿失滔滔。

#### 《乡愁》
背诵范围：全文背诵。

> 小时候，乡愁是一枚小小的邮票，我在这头，母亲在那头。

> 后来啊，乡愁是一方矮矮的坟墓，我在外头，母亲在里头。

### 默写标准

- 古诗词、文言文：写对篇名、作者或出处、原文、标点和易错字；文言句要能解释关键词。
- 现代文：严格按教材指定自然段背诵，能够复述段落内容、句间关系和关键表达作用。
- 每篇完成“背诵—遮挡默写—逐字核对—订正再写”四步；不会写的字单独列入错字表。


## 七、易错点与掌握边界

- 《岳阳楼记》的“不以物喜，不以己悲”是对古仁人境界的概括；“先忧后乐”与全文政治理想相连。
- 小说主题不能只根据人物身份判断；需结合行为、环境、叙述角度和结局。
- 驳论并非把对方骂倒，而要准确复述对方观点、指出论证问题并提供自己的证据。
- 文言文的“迁客骚人”中“迁”与现代常用义不同；翻译须查清上下文。
- 缩写不是逐句删字；主线因果和关键转折必须保留。
