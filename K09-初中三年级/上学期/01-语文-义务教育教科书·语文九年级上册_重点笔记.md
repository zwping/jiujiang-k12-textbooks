# 九年级上册语文重点笔记

> 对应教材：义务教育教科书·语文九年级上册
> 版本：人教统编版　|　学段：初中三年级上学期

## 一、本册学习地图

### 本册到底教什么

- **教材主线**：本册从诗歌鉴赏、议论表达、古典散文、小说、议论文和古典名著入手，系统训练意象、观点、论据、论证、人物、情节和改写。
- **表达任务**：诗歌朗诵与创作、观点明确、议论有据、学习缩写、论证合理、讨论和学习改写；名著为《艾青诗选》和《水浒传》。

| 单元 | 主要内容 | 本单元教会的知识 | 学完后的明确能力 |
|---|---|---|---|
| 第一单元 | 新诗、敬业、教养 | 意象、节奏和观点 | 能鉴赏诗歌并明确观点 |
| 第二单元 | 岳阳楼记、醉翁亭记、诗词 | 写景抒情和议论有据 | 能用景物和证据表达态度 |
| 第三单元 | 故乡、于勒、孤独之旅 | 小说人物、情节和环境 | 能缩写小说并分析人物 |
| 第四单元 | 议论文与论证 | 怀疑、创造和论证结构 | 能写有合理论证的文章 |
| 第五单元 | 议论名篇、讨论 | 论点、论据、论证方式 | 能参与讨论并回应观点 |
| 第六单元 | 水浒、范进、三顾茅庐 | 古典小说阅读和改写 | 能改写片段并分析讽刺 |

## 二、目录与章节重点

### 第一单元：诗歌与观点

- **沁园春·雪**：描写北国雪景，评论历代帝王，转入歌颂无产阶级革命领袖；意象宏大，境界开阔。
- **周总理，你在哪里**：通过“你在哪里”的反复和不同地点的回声追寻周总理，表现人民怀念和崇敬。
- **我爱这土地**：以鸟、土地、河流、风和黎明表达对苦难祖国的深沉爱；“为什么我的眼里常含泪水”直抒情感。
- **乡愁**：用邮票、船票、坟墓、海峡四个意象对应人生阶段和空间阻隔，结构整齐，主题由个人乡愁升华为家国乡愁。
- **你是人间的四月天、我看**：分别用春日意象歌颂爱与生命，以春风、飞鸟、草地表达青春和自然哲思。
- 诗歌鉴赏要抓意象、画面、节奏、修辞和感情基调；朗诵要用重音、停连和语速传达情感。

### 第二单元：议论与古典写景

- **敬业与乐业**：梁启超提出敬业和乐业是人类合理生活的基础，用引用、道理论证和生活事例说理。
- **就英法联军远征中国致巴特勒上尉的信**：雨果赞美圆明园、谴责英法联军，反语和对比增强讽刺力量。
- **论教养、精神的三间小屋**：分别讨论真正教养的表现和精神世界的构建，观点多通过生活现象和比喻展开。
- **岳阳楼记**：以迁客骚人的悲喜对比“不以物喜，不以己悲”，表达先忧后乐的政治抱负。
- **醉翁亭记**：按环滁—酿泉—醉翁亭—四时—宴饮—太守醉写景叙事，表现与民同乐。
- **湖心亭看雪**：写西湖雪夜偶遇知己，白描、对比和“痴”表现孤高情怀。
- **议论要言之有据**：材料必须真实、典型、能证明观点；事实论据和道理论据要与论点对应。

### 第三至第六单元

- **故乡**：闰土和杨二嫂的变化、宏儿水生的希望构成现实与未来对照；“希望本无所谓有”表达探索之路的思考。
- **我的叔叔于勒**：菲利普夫妇因金钱对待于勒前后不同，船上相遇揭示金钱关系和小市民的势利。
- **孤独之旅**：杜小康在芦苇荡放鸭中经历孤独、暴风雨和成长，环境成为人物成长的见证。
- **中国人失掉自信力了吗、怀疑与学问、谈创造性思维、创造宣言**：分别训练反驳、因果论证、举例论证和创造条件分析。
- **智取生辰纲**：杨志押送、吴用设局、白胜卖酒，矛盾来自军汉与杨志、智取与防范；环境和心理推动情节。
- **范进中举**：中举前后人物和乡邻态度剧变，以夸张和对比讽刺科举制度及社会势利。
- **三顾茅庐、刘姥姥进大观园**：前者以诚意和谋略塑造人物，后者以乡村妇人与贵族生活的反差制造幽默和讽刺。
- **学习改写**：保留原作核心人物和冲突，改变叙述角度、语言、场景或结局，但因果必须成立。

## 三、必备知识点

- **诗歌**：意象构图，意境传情，节奏和反复强化语气，象征和对比提升主题。
- **议论文**：中心论点、分论点、事实/道理论据、举例/道理/对比/比喻论证；论证要有逻辑。
- **古典散文**：写景、叙事、议论和抒情相互结合；文言翻译要结合语境和句式。
- **小说**：人物欲望、冲突、环境、情节转折和结局共同揭示主题。
- **改写**：改变形式不改变核心事实和人物逻辑；新增内容要有文本依据或合理补充。

## 四、必备公式/定理

- **诗歌鉴赏规则**：意象 + 画面 + 手法 + 情感 + 主题。
- **议论文规则**：论点 + 论据 + 论证方式 + 逻辑关系 + 结论。
- **小说分析规则**：人物目标 + 阻力/冲突 + 环境作用 + 情节结果 + 主题。
- **改写规则**：核心情节不变 + 叙述角度变化 + 语言形式变化 + 因果自洽。

### 默写标准

- 古诗词、文言文：写对篇名、作者或出处、原文、标点和易错字；文言句要能解释关键词。
- 现代文：严格按教材指定自然段背诵，能够复述段落内容、句间关系和关键表达作用。
- 每篇完成“背诵—遮挡默写—逐字核对—订正再写”四步；不会写的字单独列入错字表。


## 七、易错点与掌握边界
- 议论文的论点必须是可判断、可论证的观点，不是口号或材料复述。
- 反驳不是简单否定，要指出对方论证的漏洞，再提出事实或道理。
- 古典散文的“醉”常有情感和政治寄托，不能只解释为喝酒。
- 小说人物评价要结合前后变化和社会环境，不能只用“好/坏”概括。
- 改写不是续写新故事，核心人物和冲突应保留，创新要服务主题。

## 八、独立学习验收

- 能用五项结构分析一首诗的意象和情感。
- 能写出一篇论点明确、论据恰当、论证合理的短议论文。
- 能翻译重点古文并说明景情关系。
- 能从小说人物前后变化中解释作品的社会主题。
