# 九年级下学期学习汇总

本学期六科以综合运用和世界视野收束初中阶段。数学将三角函数、二次函数、圆、统计、投影和反比例函数统合；物理解释电磁装置、家庭电路、通信和能源；化学从金属、溶液进入酸碱盐及生活材料；世界历史梳理近代改革、世界大战、冷战与当代发展。英语九年级全一册全年共用，本汇总保留其完整入口，不把教材单元人为分成上下学期教学进度。

## 二、必备知识点

### 语文

- 小说阅读把人物放在情节冲突与社会环境中分析；视角决定读者掌握的信息，反复、反差和结局可产生讽刺效果。戏剧冲突来自人物目标和处境的对立，舞台说明也是理解行动与关系的证据。
- 《鱼我所欲也》用生存选择论证“义”重于不义之利；《曹刿论战》从民心、战机和战场观察解释取胜；《邹忌讽齐王纳谏》用家事类比揭示齐王受蒙蔽并引出纳谏措施。
- 辩论反驳观点和论据，不攻击对方人格；诗歌象征与典故须结合全篇语境。扩写可丰富细节，但不能改变原有冲突和因果。

### 数学

- 直角三角函数把锐角与边长比关联，用于测高、仰角和俯角；二次函数图象交点对应方程实根，顶点对应函数极值，但须检查实际区间。
- 圆的几何关系围绕圆心、弦、弧、圆周角和切线展开：垂径定理涉及过圆心且垂直弦的直线；切线垂直过切点的半径；圆周角与同弧圆心角存在倍数关系。
- 平均数、中位数、众数描述数据中心的不同方面，极差等描述离散程度；投影和三视图依赖观察方向。反比例函数图象由 `k` 符号决定所在象限，定义域不含 0。

### 道德与法治

- 经济全球化带动生产和贸易联系，也会传递风险；文化多样性应在平等尊重中交流互鉴。国家关系既合作又竞争，全球问题需要共同治理。
- 中国参与国际事务要立足国情、维护正当利益并承担相应责任；合作不等于放弃自身利益。青少年应尊重劳动，持续学习，结合兴趣、能力、社会需要和现实条件规划职业，并随成长调整。

### 历史

- 19世纪改革与民族解放运动回应殖民压迫及资本主义扩展；第二次工业革命推动电力、内燃机和新产业发展，也加剧垄断和国际竞争。
- 一战后凡尔赛—华盛顿体系未解决矛盾；俄国十月革命建立社会主义国家，经济大危机冲击资本主义社会，法西斯侵略导致二战。反法西斯同盟协同作战，1945年二战结束。
- 战后形成美苏冷战和两极格局；去殖民化改变世界政治版图，资本主义、社会主义国家分别经历发展变化。苏联解体后格局走向多极化，全球化加深但发展和安全问题仍在。

### 物理

- 电流周围存在磁场；电磁铁磁性随电流大小、线圈匝数和铁芯等因素变化。通电导体在磁场中受力是电动机原理，闭合电路中导体切割磁感线产生感应电流是发电机原理。
- 家庭电路用电器并联，电能表计量消耗电能；开关应接在火线上，熔断/保护装置需按规范连接，金属外壳用电器采取保护接地。湿手操作和接触裸露带电体会增加触电危险。
- 电磁波可在真空传播并携带信息；能量守恒表示能量转移和转化前后总量不变，但实际装置有热、声等非目标输出，能源利用需考虑效率与环境影响。

### 化学

- 金属活动性顺序用于预测常见置换反应；金属与酸反应的条件及盐溶液置换需看活动性先后，钾、钙、钠不能简单按普通金属置换实验处理。
- 溶液由溶质和溶剂构成；溶解度限定温度并以100 g溶剂为基准，溶质质量分数以溶液总质量为分母。酸碱中和本质是 H⁺ 与 OH⁻ 结合生成水；盐溶液不一定呈中性。
- 酸、碱、盐按组成分类；Na₂CO₃ 是盐，俗名“纯碱”不使其成为碱。化肥按营养元素和功能识别，使用须兼顾作物需求和环境影响；营养物质与有机合成材料联系生活化学。

## 三、必备公式/定理

| 科目 | 关系式/定理 | 含义与适用条件 |
|---|---|---|
| 数学 | `sinθ=对边/斜边`；`cosθ=邻边/斜边`；`tanθ=对边/邻边` | θ 为直角三角形锐角；测量问题须明确水平线和观测点。 |
| 数学 | 弧长 `l=(θ/360°)·2πr`；扇形面积 `S=(θ/360°)·πr²` | θ 为圆心角度数，r 为半径；长度和面积单位分别为长度、平方单位。 |
| 数学 | `y=k/x (k≠0, x≠0)` | 反比例函数；k>0时图象在一、三象限，k<0时在二、四象限。 |
| 数学 | `y=a(x-h)²+k` 顶点 `(h,k)` | a≠0；极值受自变量范围约束。 |
| 数学 | 同弧圆周角 `=` 同弧圆心角的 `1/2` | 圆周角顶点在圆上，圆心角顶点在圆心。 |
| 物理 | `v=fλ` | 波速、频率、波长关系；真空电磁波速度约 `3.0×10⁸ m/s`。 |
| 物理 | `W=Pt` | 功/电能、功率、时间单位须匹配；电费常用 kW·h。 |
| 物理 | `E输入=E有用输出+E其他输出` | 选定系统和完整过程的能量守恒表达；效率 `η=E有用/E输入×100%`。 |
| 化学 | `w=m溶质/m溶液×100%` | 溶液均匀、质量单位一致；溶液质量=溶质质量+溶剂质量（无损失时）。 |
| 化学 | 金属活动性顺序；原子守恒 | 在教材限定的常见水溶液条件预测置换倾向；方程式配平前后各元素原子数相等。 |

## 五、熟记内容

- **语文**：按单本笔记范围背《鱼我所欲也》《送东阳马生序》《曹刿论战》《邹忌讽齐王纳谏》《出师表》《词四首》《诗词曲五首》及指定现代文段落。重点句：“小大之狱，虽不能察，必以情。”“一鼓作气，再而衰，三而竭。”“受任于败军之际，奉命于危难之间。”
- **数学**：特殊角三角函数值；圆周角与圆心角关系；弧长及扇形面积式；反比例函数定义域和象限；二次函数顶点式及图象判读。
- **英语（全年共用）**：复习全年句型，尤其宾语从句陈述语序、过去/现在被动、used to、情态推断、定语从句、过去完成时和 `look forward to + doing`。示例：`I wonder where the station is.`（我想知道车站在哪里。）
- **历史时序**：1861俄国农奴制改革与美国内战；1868明治维新；1914一战；1917十月革命；1929经济大危机；1939二战全面爆发；1945二战结束、联合国成立；1991苏联解体。区分一战、二战起因及战后安排。
- **物理**：电动机靠通电导体在磁场中受力，发电机靠电磁感应；用电器并联、开关接火线、金属外壳保护接地；能量既不能凭空产生也不能凭空消失。
- **化学**：背熟金属活动性顺序及常见沉淀（AgCl、BaSO₄白色；Cu(OH)₂蓝色；Fe(OH)₃红褐色）、酸碱指示剂与 pH 范围。反应：`Fe+CuSO₄=FeSO₄+Cu`；`Zn+2HCl=ZnCl₂+H₂↑`；`HCl+NaOH=NaCl+H₂O`。

## 六、易错点与知识联系

- 三角函数的对边、邻边随所选角改变；弧长公式和扇形面积公式中的 θ 必须是圆心角；平均数相同不代表数据离散程度相同。
- 九年级英语全一册是全年教材，不把本汇总列出的主题误认为官方学期分册；宾语从句、被动语态等语言规则在全年文本中逐步复现。
- 罗斯福新政不是废除资本主义；冷战不是美苏直接全面战争；联合国与WTO职能不同。历史时间先后不自动证明因果。
- 电动机与发电机的能量转换方向相反；电磁波无需介质，声波需要介质；家庭电路安全不可只靠断路器替代正确接线和保护接地。
- 溶解度和溶质质量分数的基准不同；溶液浓度计算分母不是溶剂质量；纯碱 Na₂CO₃ 属盐；酸碱中和不代表所有盐溶液均为中性。
