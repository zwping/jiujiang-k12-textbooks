# 七年级下册语文重点笔记

> 对应教材：义务教育教科书《语文》七年级下册（人教统编版）
> 编排依据：篇目、单元与写作/综合活动按仓库现有教材目录核对；正文知识据教材文本整理，目录星号不作为背诵要求的依据。

## 一、本册学习地图

本册以人物精神、家国情感、凡人品格、传统文化、生命体验和探险故事为阅读线索。写作训练由写人物、抒情、写细节、选材、文从字顺到简明表达逐步推进；阅读的共同要求是用文本中的事件、细节、语言和结构支持判断。

- **阅读能力**：从小标题和典型事件概括人物；分析抒情对象与表达方式；用事实证据解释说明、议论和文言叙事；区分科学事实与文学想象。
- **写作能力**：人物特点由事件体现；抒情有具体依托；细节写得准确；材料围绕中心取舍；句子通顺、意思简明。
- **六单元主线**：人物精神 → 家国抒情 → 凡人真情 → 修养与文言 → 生命感悟 → 探险、科学与推理。

## 二、目录与章节重点

- **第一单元：人物精神**
  - **1《邓稼先》**：以历史背景和典型事例写科学家对国家的贡献；六个小标题组织材料，人物评价由核事业、艰苦环境和人格细节共同支撑。
  - **2《说和做——记闻一多先生言行片段》**：闻一多前期埋头研究、后期投入民主运动；“做了再说/做了不说”与“说了就做”概括其言行一致，叙述和议论交替推进。
  - **3*《回忆鲁迅先生》**：以笑声、走路、待客、工作等日常片段写鲁迅的率真、热情与勤勉；平常细节让人物脱离抽象标签。
  - **4《孙权劝学》**：孙权劝吕蒙读书，鲁肃见其学识变化而结友；对话推动情节，侧面反映学习效果，“士别三日”强调人的变化。
  - **写作《写出人物的精神》**：从人物身上选最能说明精神品质的事件，再安排动作、语言、环境或对比细节；评价必须由事例落地。
- **第二单元：家国与抒情**
  - **5《黄河颂》**：以黄河的自然形象连接民族历史和民族精神；朗诵时区分序曲、主体和反复呼告，重音与节奏服务赞颂语气。
  - **6《老山界》**：按红军翻越老山界的行程写夜行、宿营和登山；险峻环境与战士的乐观相对照，行程顺序使困难逐步加深。
  - **7《谁是最可爱的人》**：以松骨峰战斗、马玉祥救朝鲜儿童等事例表现志愿军的革命英雄主义、国际主义和爱国主义；事例之后的抒情把读者带到人物情感中。
  - **8*《土地的誓言》**：端木蕻良用东北土地、物产和生活记忆写故乡之爱与收复失地的愿望；排比、呼告和强烈词语构成情感递进。
  - **9《木兰诗》**：按代父从军、出征、征战、还乡、同伴惊异写木兰；详写出征前、归家和身份揭示，略写十年战争，以详略突出孝勇与机敏。
  - **写作《学习抒情》**：直接抒情表明态度，间接抒情借景物、事件、人物和细节传情；情感强度要与材料相称。
  - **综合性学习《天下国家》**：从人物、历史事件和诗文中提取国家情感的具体表现，表达要有事实或文本依据。
- **第三单元：凡人真情与品格**
  - **10《阿长与〈山海经〉》**：由对阿长的不耐烦写到她买来《山海经》后的敬意和怀念；欲扬先抑，人物转变由关键事件触发。
  - **11《老王》**：送冰、送医、送鸡蛋香油等事件写老王的善良与艰难；“我”的愧怍来自回看自己受赠时的态度，文章由人物小事引出伦理反思。
  - **12《台阶》**：父亲造高台阶以实现生活目标；台阶建成后父亲的衰老与失落显示愿望达成的代价，台阶兼具实物和尊严象征。
  - **13《卖油翁》**：陈尧咨以射技自矜，卖油翁通过酌油展示熟练；“无他，但手熟尔”把结果归因于反复练习，不能读成天赋毫无作用的普遍结论。
  - **写作《抓住细节》**：挑选能推动情节、表现性格或承载情感的细节；动作、神态、声音和物件均须准确，不用无关细节堆长篇。
  - **名著《骆驼祥子》**：关注祥子从希望、自立到屡受打击的变化，把个人命运与城市底层生活、社会环境联系起来。
- **第四单元：修养、责任与传统表达**
  - **14《叶圣陶先生二三事》**：待人宽厚与律己严谨分别由具体小事呈现；叙述语言平实克制，与被写人物的朴实作风相应。
  - **15《驿路梨花》**：山中小屋由不同人物接力照料，误会层层揭开；梨花既是自然景物，也是助人为乐精神的象征。
  - **16《最苦与最乐》**：以“负责任是人生最大痛苦，尽责任是人生最大快乐”为中心展开，层层解释责任与人生感受的关系。
  - **17《短文两篇》**：《陋室铭》借居室写安贫乐道和高洁志趣；《爱莲说》以莲的生长环境、形态和气质比喻君子品格，属于托物言志。
  - **写作《怎样选材》**：材料需真实、典型且能表现中心；同一主题下选不同侧面的事例，避免重复证明同一点。
  - **综合性学习《孝亲敬老，从我做起》**：把尊敬落实为倾听、分担家务、关心健康和理解长辈处境等行动，不停留在口号。
- **第五单元：生命与观察**
  - **18《紫藤萝瀑布》**：眼前繁盛的紫藤萝触发对十多年前花朵衰败的回忆，再回到眼前花瀑；生命状态的对比引出生命长河不止的感悟。
  - **19《一棵小桃树》**：小桃树的成长受风雨摧折，与“我”的成长挫折交织；“我”从怜惜小桃树中看见坚持和希望。
  - **20《外国诗二首》**：《假如生活欺骗了你》劝人以平静和信念面对逆境；《未选择的路》以林中岔路写人生选择及其不可重来的意味。
  - **写作《文从字顺》**：词语搭配准确、句间关系明确、语序合乎表达重点；修改时先查意思，再查句子和衔接。
- **第六单元：探险、科学与推理**
  - **21《伟大的悲剧》**：斯科特一行抵达南极后发现阿蒙森先到，返程遇难；悲剧结局与诚实、坚毅和责任感共同构成“伟大”的评价。
  - **22《太空一日》**：杨利伟按飞行阶段记录身体感受、飞船异常和地面操作；第一人称现场细节让航天经历可感，同时体现严谨的科学态度。
  - **23《带上她的眼睛》**：地航飞行员被困地心，借“我”的观察和通信揭示她仍热爱地表生活；科幻设定服务于人物情感与生命意识。
  - **24《河中石兽》**：石兽落水后，僧人、讲学家和老河兵提出不同判断；老河兵结合水流、泥沙和石兽重量推理，实践经验与条件分析纠正空谈。
  - **写作《语言简明》**：删去重复、空泛和不影响理解的信息；指代明确，一句话集中表达一个主要意思。
  - **综合性学习《我的语文生活》**：从招牌、广告、网络用语等真实语言现象中辨析规范、效果和误用。

## 三、必备知识点

- **人物传记/回忆性散文**：用可靠事实和典型事件写人；作者态度由细节、材料排列和议论体现，不能只据赞美词判断。
- **叙事抒情**：事件承载情感，景物或反复句强化情感；分析时指出具体触发点和情感变化。
- **托物言志与象征**：具体事物的特征要与人物志趣或抽象意义建立对应，并有全文语境支撑。
- **论说文**：先找中心观点，再区分事例、解释与结论；证据必须与观点相关。
- **文言文**：掌握通假、古今异义、一词多义和省略句；译文须保留人物关系、动作先后和语气。
- **科学说明/推理**：列出已知现象和适用条件，再说明规律如何推出结论；不能把文学设定当作科学事实。

## 四、表达方法与结构

- **写人物**：特点 → 典型事件 → 动作/语言/环境细节 → 由证据得出的评价。
- **抒情**：情感对象 → 触发事件或意象 → 情感推进 → 与材料相称的表达。
- **议论**：中心观点 → 相关事实/道理 → 解释证据怎样支持观点 → 回扣观点。
- **推理**：现象 → 条件 → 适用规律 → 推导过程 → 结论及边界。

## 五、必备字词与术语

| 字词/术语 | 读音 | 含义与本册用法 |
|---|---|---|
| 锲而不舍 | qiè ér bù shě | 一直刻下去而不停止；《说和做》借以表现闻一多治学坚持。 |
| 校补 | jiào bǔ | 《说和做》中指闻一多研究《楚辞》后写成的《楚辞校补》，不是“校订补正”这一动作。 |
| 愧怍 | kuì zuò | 惭愧；《老王》中“我”回看与老王交往时的内疚。 |
| 斑斓 | bān lán | 灿烂多彩；用于描绘景物色彩。 |
| 扑朔迷离 | pū shuò mí lí | 形容事情错综复杂、难以辨别；来自《木兰诗》结尾双兔的比喻。 |
| 托物言志 | tuō wù yán zhì | 借具体事物的特征表达志趣；《陋室铭》《爱莲说》均使用此法。 |
| 负责任 | fù zé rèn | 对自己承担的事务负责；《最苦与最乐》的论述核心。 |
| 欲扬先抑 | yù yáng xiān yì | 先写人物令人不满或不解之处，再写其可敬之处；《阿长与〈山海经〉》以此呈现“我”对阿长态度的转变。 |

> 康肃问曰：“汝亦知射乎？吾射不亦精乎？”翁曰：“无他，但手熟尔。”康肃忿然曰：“尔安敢轻吾射！”翁曰：“以我酌油知之。”乃取一葫芦置于地，以钱覆其口，徐以杓酌油沥之，自钱孔入，而钱不湿。因曰：“我亦无他，惟手熟尔。”康肃笑而遣之。

### 默写标准

- 古诗词、文言文：写对篇名、作者或出处、原文、标点和易错字；文言句要能解释关键词。
- 现代文：严格按教材指定自然段背诵，能够复述段落内容、句间关系和关键表达作用。
- 每篇完成“背诵—遮挡默写—逐字核对—订正再写”四步；不会写的字单独列入错字表。


## 七、易错点与掌握边界

- 《孙权劝学》写劝学、学习和交友的变化，不应把“吕蒙读书”简化为只靠天赋突然变聪明。
- 《木兰诗》的详略安排有表达目的；不能因战争写得简略就误认为战争不重要。
- 《老王》的“愧怍”是叙述者的反思，不等于老王指责她。
- 《最苦与最乐》论述的是责任承担，不是说生活中的所有痛苦都能自动变成快乐。
- 《河中石兽》的结论建立在特定河床、水流和石兽条件上，不可脱离条件泛化成“经验永远正确”。
