# 七年级上册语文重点笔记

> 对应教材：义务教育教科书《语文》七年级上册（人教统编版）
> 编排依据：篇目、单元按仓库现有教材目录核对；正文知识据教材文本整理，目录星号不作为背诵要求的依据。

## 一、本册学习地图

本册先训练朗读、写景和记事，再学习从细节认识人物、从事件提炼观点，最后进入动物叙事、神话与寓言。阅读时需要把“文本写了什么”与“作者怎样写、为什么这样写”连起来；写作则由真实观察出发，做到事件完整、人物可感、中心清楚。

- **阅读能力**：朗读时处理重音、停连和语气；默读时圈画中心句、转折和照应；叙事阅读梳理人物、事件、变化；文言阅读结合语境解释词句。
- **表达能力**：写生活中的真实事件；通过动作、语言、外貌和心理细节写人；写景时安排观察顺序；记事时交代起因、经过、结果和感受。
- **本册结构**：六个单元依次涉及四季与诗歌、亲情与友情、童年与经典、人物与责任、动物、想象与寓言。

## 二、目录与章节重点

- **第一单元：四季景物与诗歌**
  - **1《春》**：由盼春进入春草、春花、春风、春雨和迎春图；动词、叠词、比喻、拟人和多感官描写共同写出春的生机。景物不是逐项罗列，而是由局部铺展到人的活动。
  - **2《济南的冬天》**：以“温晴”为总特点，依次写阳光下的小山、薄雪覆盖的山和水；“小摇篮”等比喻把地形和温暖感受连在一起，景物描写含有作者的喜爱。
  - **3《雨的四季》**：按春、夏、秋、冬展开，雨的声音、形态、气味和季节环境各不相同；拟人化语言将雨写成有性格的生命，贯穿全文的是对雨与自然的喜爱。
  - **4《古代诗歌四首》**：曹操《观沧海》以海景写开阔胸襟；李白《闻王昌龄左迁龙标遥有此寄》借明月寄托牵挂；王湾《次北固山下》以“海日生残夜，江春入旧年”写时序更新；马致远《天净沙·秋思》用名词性意象并置表现羁旅愁思。
  - **写作《热爱生活，热爱写作》**：把观察到的人、事、景、物变成材料；具体写“看见、听见、做了什么”，避免只写抽象感受。
- **第二单元：亲情、友情与记事**
  - **5《秋天的怀念》**：母亲隐瞒病情、央求儿子看花、临终牵挂孩子，几次“好好儿活”串联起母爱与“我”的悔恨；菊花在结尾承接母亲的愿望。
  - **6《散步》**：一家人在田野散步，路线分歧引出照顾老人和孩子的选择；结尾“背”起两代人的画面，把亲情落实为家庭责任。
  - **7《散文诗二首》**：《金色花》以孩子变成花的想象写陪伴母亲；《荷叶·母亲》由荷叶护红莲联想到母亲保护孩子，借具体景物转写亲情。
  - **8《〈世说新语〉二则》**：《咏雪》把飞雪比作盐和柳絮，比较的不只是形状，也包括轻盈、动态与诗意；《陈太丘与友期行》以“无信”“无礼”构成元方批评友人的理由，叙事短而对话有力。
  - **写作《学会记事》**：用时间顺序交代事件，以关键细节放慢叙述，在结尾写出事件对自己的意义；不靠“非常感动”等评价代替过程。
  - **综合性学习《有朋自远方来》**：介绍自己时选能表现个性的经历和特点；交友表达重在真诚、倾听与尊重差异。
- **第三单元：童年、成长与经典**
  - **9《从百草园到三味书屋》**：百草园的景物、捕鸟活动与三味书屋的读书生活形成对照；空间转换呈现童年经验的变化，具体动词使回忆鲜活。
  - **10《再塑生命的人》**：莎莉文老师通过触觉和反复体验让海伦理解“水”与词语的联系；“水”这一事件写出语言如何使感觉、概念和世界建立联系。
  - **11《〈论语〉十二章》**：内容围绕学习方法、学习态度、修身和交友；“学而不思则罔，思而不学则殆”说明学习与思考相互补充，“三人行”强调择善改过。
  - **写作《写人要抓住特点》**：不堆砌外貌形容词；选择最能区分此人的外形、语言、动作或习惯，并让细节在事件中出现。
  - **名著《朝花夕拾》**：阅读时区分童年回忆、人物描写和成年后的反思；把篇章内容、叙述视角和作者态度联系起来。
- **第四单元：人物品格、责任与阅读**
  - **12《纪念白求恩》**：以白求恩的国际主义、毫不利己专门利人和对技术精益求精为论述内容；叙述事迹提供事实，议论说明其价值，形成夹叙夹议。
  - **13《植树的牧羊人》**：牧羊人长期植树使荒地恢复生机；时间跨度和反复行动突出坚忍，环境前后变化是人物品格的证据。
  - **14《走一步，再走一步》**：悬崖困境由害怕、停滞到按父亲指引分步脱险；题目中的“走一步”对应把整体困难分解成当前可完成的小行动。
  - **15《诫子书》**：诸葛亮从修身、治学和立志劝诫儿子；“静”与“学”、“志”与“成学”构成递进关系，骄慢、急躁则与治学修身相反。
  - **写作《思路要清晰》**：先确定中心，再按时间、空间或逻辑安排材料；段落顺序应让读者看出事情如何发展或观点如何推出。
  - **综合性学习《少年正是读书时》**：用可比较的数据描述阅读状况，再结合阅读内容与习惯提出具体改进办法。
- **第五单元：动物与观察**
  - **16《猫》**：三只猫的外形、性情、家庭地位和结局形成比较；第三只猫被误认偷鸟而遭惩罚，促使“我”反思偏见、证据不足和伤害责任。
  - **17《动物笑谈》**：作者以亲身观察写水鸭和鹦鹉的行为，也写自己为观察动物而做出的滑稽举动；幽默来自科学观察与日常身份之间的反差。
  - **18《狼》**：屠户从退让、受困到利用空隙反击，动作顺序构成故事转折；结尾由杀狼事件推出对狡诈的评议，文言叙事简洁而因果清楚。
  - **写作《如何突出中心》**：中心决定选材和详略；与中心关系最紧的事件写具体，次要材料压缩或删去。
- **第六单元：想象、神话与寓言**
  - **19《皇帝的新装》**：骗子利用皇帝虚荣和群体从众心理行骗；官员、皇帝和百姓的反应层层推进，孩子说出真相形成揭穿骗局的转折。
  - **20《天上的街市》**：诗人由街灯联想到明星，再想象牛郎织女自由幸福的生活；联想有现实触发点，想象承载对美好生活的愿望。
  - **21《女娲造人》**：神话用揉泥、繁衍等想象解释人类起源；女娲的行动和情感赋予创世故事以亲切的人情味。
  - **22《寓言四则》**：《赫耳墨斯和雕像者》《蚊子和狮子》讽刺自我估价过高和胜后骄傲；《穿井得一人》写传话失真；《杞人忧天》区分无根据的忧虑与合理担心。
  - **写作《发挥联想和想象》**：联想由相似、相关或相反建立连接；想象补出新情境。新增内容须与原有对象、情节和情感相合。

## 三、必备知识点

- **叙事阅读**：按“人物—目标/处境—行动—变化—结果”梳理情节；用动作、对话和环境作为人物判断的依据。
- **写景阅读**：标出观察对象与顺序，再看感官细节、修辞和情感如何配合；景物特点必须能从具体描写中找到证据。
- **文言词句**：以本句语境确定义项；通假、古今异义和省略不能只套现代常用义。翻译先落实关键词，再理顺句式。
- **诗歌阅读**：把意象还原成画面，结合动词、色彩、空间和声音判断情感；不可只凭单个意象套主题。
- **人物写作**：用典型事件承载特点，以动作、语言和细节证明判断；外貌描写只有与人物特征相关才保留。

## 四、表达方法与结构

- **记事结构**：交代情境 → 写清关键行动和变化 → 点明感受或意义；高潮处用细节，不平均铺叙。
- **写人结构**：人物特点 → 典型事件 → 有区分度的细节 → 读者可验证的性格判断。
- **写景结构**：确定观察点 → 按空间/时间铺展 → 用感官细节表现特征 → 让情感从景物中自然显出。
- **文言翻译**：关键词义项准确 + 句式关系清楚 + 省略成分补足 + 现代汉语通顺。

背诵范围：第4自然段背诵。

> 元方时年七岁，门外戏。客问元方：“尊君在不？”答曰：“待君久不至，已去。”
> 友人便怒曰：“非人哉！与人期行，相委而去。”元方曰：“君与家君期日中。日中不至，则是无信；对子骂父，则是无礼。”
> 友人惭，下车引之。元方入门不顾。

### 默写标准

- 古诗词、文言文：写对篇名、作者或出处、原文、标点和易错字；文言句要能解释关键词。
- 现代文：严格按教材指定自然段背诵，能够复述段落内容、句间关系和关键表达作用。
- 每篇完成“背诵—遮挡默写—逐字核对—订正再写”四步；不会写的字单独列入错字表。


## 七、易错点与掌握边界

- 《春》的修辞判断要落实到词句和描写对象，不能把所有生动表达一概称作拟人。
- 《散步》的主题由人物选择和结尾承担，不只是“家庭很温馨”。
- 《论语》十二章各章内容不同；学习方法、学习态度和修身语句不要混为一条空泛道理。
- 《猫》中的第三只猫是“我”根据不完整证据作出错误判断，不能把怀疑当成事实。
- 寓言的寓意应由情节和结局推出；《穿井得一人》批评的是传话失真，不是挖井本身。
