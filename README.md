## 笔记生成规则

### 核心原则：笔记必须直接呈现确定性知识

重点笔记的正文必须让读者不翻教材即可学习，不得用“本节写出……”“请完成……”“结合本节……”“一个关键词、一个规则/公式或一条证据”等学习指令、空泛任务或模板句代替知识。数学直接写出公式、定义、适用条件、推导关系和结论；语文直接写出课文主旨、重点字词、表达作用和背诵内容；英语直接写出词义、词性、搭配、句型和中文使用提醒；物理、化学、生物、地理、历史、政治等直接写出概念、规律、条件、实验/材料证据、因果关系和结论。

目录章节中的内容应使用陈述句，例如“等式两边同时加、减同一个数，等式仍成立”，不得写成“本节写出等式性质并完成一道题”。本轮已删除笔记正文中的自测清单、疑问式提示和空泛训练指令；复习动作只保留在学期/阶段导航中，不能替代知识正文。

### 1. 目录边界

- 每本笔记必须严格服从对应教材的实际目录，只整理该册、该学期的内容，不把其他年级、其他册次或超纲知识混入正文。
- 可以联网查找官方教材目录、教师教学用书、公开课程资源和权威知识讲解，用于补充定义、公式、例题类型和易错点；网络资料只能服务于当前教材目录，不能扩展目录范围。
- PDF 可提取文字优先以 PDF 为事实来源；扫描版或文字层不完整时，先核对目录和页码，再使用公开资料补足，并在笔记中注明“待 OCR/人工核对”的部分。

### 2. 单本教材笔记结构

每本教材旁生成一个同名 `_重点笔记.md`，至少包含以下部分：

1. **教材信息**：年级、册次、科目、版本、对应 PDF 链接。
2. **目录与章节重点**：按教材原目录逐章列出学习目标、核心概念、关键词和典型题型。
3. **必备知识点**：必须单独设小节并完整列出本册需要掌握的概念、规律、方法、实验、事实、时间线、答题角度或交际场景；不能只在章节正文中零散出现。
4. **必备公式/定理**：必须单独设小节并列出本册全部核心公式、定理、单位、字母含义、适用条件、常见变式和易错提醒；没有公式的学科要明确写“本册无独立计算公式”，并列出需要记忆的规则、结构或表达式。
5. **必备单词/术语**：必须单独设小节。英语列核心单词、词义、词性、音标或读音提示、常用搭配和教材句型；语文列重点字词；其他学科列学科术语、符号、专有名词和关键词。没有传统“单词”的学科也必须列出本册术语清单，不能省略。
6. **背诵内容**：需要背诵的课文、诗词、定义、定理、公式、英语句型或原文短句，直接贴在 Markdown 中，避免复习时反复翻 PDF。涉及较长作品时保留教材标题、背诵范围和关键原文，避免无关全文堆积。
7. **易错点**：说明错误表现、产生原因、正确做法和一个最小示例。
8. **易错点与掌握边界**：直接写出容易混淆的概念、条件、错误表现和正确结论；不使用“请完成”“能否说出”等提示句代替知识。

每一个教材重点笔记都必须出现并保持同名的三个固定栏目：`必备知识点`、`必备公式/定理`、`必备单词/术语`。栏目内容必须对应当前教材目录，不得用“见正文”“同上”或空标题代替；确实没有对应内容时，写明“本册无独立公式/无英语单词”，并改列本学科应掌握的规则、表达式或术语。

已清理历史生成内容中的统一套话（如“先说清核心概念……”），目录项只保留真实的单元、课文、章节或知识条目；具体知识点、公式、单词/术语和背诵内容必须写在对应栏目中。前序增量审计曾重建 146 份教材笔记；21 份学期/阶段汇总也已重新组织为“学科主线—必备内容—学习动作—教材入口”。最终结果以“最新增量复核”一节的 152 份全量校验为准。

重复内容判断规则：标题、固定栏目名、相同公式和术语表属于必要重复；“建议按目录补充”“用一页纸整理”“掌握本节目录”等流程性套话属于无效重复，必须改成当前科目的具体学习任务、适用条件、证据、例题类型或背诵要求。

英语术语表中的“释义或使用提醒”优先使用中文解释和中文使用场景；只有固定搭配、句型、例式或中文难以准确替代的表达才保留英文，并放在中文说明之后。

目录数字编排规则：只有“数字 + 课名”的前置数字才解释为课文序号；年份、日期、统计数字和实验数据必须保留原语义。末尾独立数字是教材页码，笔记中统一改为“第 N 课 课名（教材页码：P）”，页码不再混入课名。单元标题也将页码单独标注；正文如保留学习动作，只引用清晰课名，不重复原始数字串。

前序版本曾重新编排 63 份教材笔记中的 747 个目录条目，其中 502 个条目补充了独立的教材页码标注；本次全量复核进一步检查了所有教材笔记的层级和章节内容。

重复语句清理规则：不得使用“一个关键词、一个规则/公式或一条证据”这类跨学科空泛自测句，也不得在多个章节重复同一套“写出定义—完成例题—再检查”的模板。章节正文不重复堆叠完整课名；无法独立说明知识含义的句子直接删除，不能用“本节”或“回到章节举例”遮盖信息缺失。

本轮增量清理覆盖 173 份 Markdown：删除了 152 个自测/阶段检查段、1,214 条泛化章节句、904 条空提醒、108 个疑问或列表碎片条目、68 个 OCR/地址/页码碎片条目，并恢复 113 份笔记中被误删的术语表数据行；随后又删除 19 个残留自测段、130 条复选框任务、45 条“请写出定义/完成例题”占位句、9 条无法还原语义的乱码式章节句、66 条同文件重复句和 24 个空标题。英语核心问句、语文背诵原文和公式中的问号未删除，因为它们属于教材知识；中文提示式问句已移除。

知识陈述规则：目录章节下不得写“本节写出”“请完成”“结合本节”“写出一个最小例题”等学习指令，也不得留下回看后无法判断主语、对象、条件或结论的句子。数学必须直接给出运算顺序、等式性质、公式、统计关系和解题流程；其他学科直接陈述概念、规律、条件、证据、因果关系、词句或背诵内容。

### 重中之重：重点笔记必须脱离教材独立使用

任何一本重点笔记单独打开时，读者都应能据此复习本册的核心内容，不需要再猜“本节要学什么”、不需要回到 PDF 查找被省略的结论，也不能依赖其他 MD 才能理解。每个章节至少直接给出具体对象、确定结论、必要条件和适用范围；语文补充篇目主旨/表达作用/疑难字和背诵原文，数学补充公式及字母含义，英语补充词义/词性/搭配/中文提醒和句型，理科与文科补充规律、证据、因果和结论。无法从当前教材或可靠资料确认的内容宁可删除并标记待核对，不填充套话。

### 3. 数学公式和定理规则

- 公式不能只罗列名称，必须写清“公式内容—字母含义—适用条件—常见变式—易错提醒”。
- 定理必须说明结论、前提和使用场景；几何定理要标出图形条件，不能把结论当成无条件公式使用。
- 重要公式至少配一个教材目录内的典型应用；例题重在说明思路和关键步骤，不只给最终答案。
- 小学以数量关系、周长面积体积、时间速度和基础运算为主；初中增加代数恒等式、函数、几何定理、物理化学计算；高中按必修和选择性必修分层整理。
- 公式按教材出现顺序编号，避免把不同年级的同名公式混在一个章节中。

### 4. 背诵与掌握标准

- “背诵”与“理解”分开标注：背诵项必须能脱稿复述或默写，理解项必须能解释、计算或迁移。
- 每个背诵项采用“原文/公式 → 关键词解释 → 使用情境”的顺序；不在正文追加空泛自测题。
- 英语优先保留教材核心句型和短对话原句，并给出可替换词槽；数学公式、单位和定理条件必须原样准确。
- 每个教材 Markdown 的“必备知识点、必备公式/定理、必备单词/术语”栏目都要能独立用于考前复习，不能只写章节标题或泛化提示。
- 学期/阶段汇总不重复粘贴所有单本笔记，而是集中列出本学期或本阶段必背、必会、必练和易错内容，并链接回单本笔记的详细位置。

### 5. 学期汇总规则

小学、初中各学期目录，以及高中 `03-综合复习` 的全年阶段汇总，内容包括：

- 本学期或本阶段教材清单，以及每本 PDF 和重点笔记的配对链接；
- 按语文、数学、英语、道德与法治/思想政治、历史、地理、物理、化学、生物学/科学的口语化顺序排列；
- 各科本学期或本阶段主线、必背内容、必备公式/定理、综合能力和复习顺序；
- 汇总本身也必须单独列出“必备知识点、必备公式/定理、必备单词/术语”三栏；单科没有公式或单词时，明确写无并列出对应术语/规则，不得留空；
- 阶段学习顺序、教材入口和薄弱点回炉安排；不把检查清单写成知识正文。

### 6. 疑难字/术语表规则

- 每本教材笔记文末统一增加“疑难字/术语表”；语文列字形、拼音、释义和篇目，英语列核心单词、读法、词义和搭配，数学/物理/化学列符号、读法、含义和适用提醒，其他学科列容易混淆的专有名词和概念。
- 每份学期/阶段汇总文末增加“疑难字/术语总表”，用于跨学科快速复习，并链接回对应教材笔记获取完整解释。
- 表格内容必须服务于当前教材目录，不用无关的超纲词汇替代本册重点；复习时按“看词条→读出/解释→回到章节应用”检查掌握情况。
